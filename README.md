# RFNote

射频知识库：面向**手机射频自动化测试开发**的通用知识库——基础概念、测试指标，以及按标准组织整理的规范库（当前收录 3GPP）。

- 规模：**28** 篇主题笔记 + **7** 个域索引 + 规范库（当前收录 3GPP 14 份规范，文档约 330 MB；原始 zip 不入库，按需下载）
- 组织方式：**7 个域**，每个域一个 `00 X索引.md`；`03 规范与标准` 下再按标准组织分目录
- 命名与标签约定见 [00 标签与命名规范](<00 标签与命名规范.md>)
- 个人学习计划、进度与面试材料不入库，只保留在本地 `_local/`（已忽略）

## 约定

1. **知识文档只放知识**；个人学习计划、进度、面试材料放本地 `_local/`，不写进仓库。
2. 限值数字只作**量级参考**，判定以 3GPP 原文表格 + 平台/客户配置为准（平台常在规范上放宽或收紧）。
3. **一篇一主题**：超过 300 行或出现两个独立主题就拆分，两边互链。
4. 新指标按「测量基础 / 功率 / 频谱 / 调制质量 / 接收」归入 `02 测试指标/` 对应文档；系统与自动化进 `05`，故障排查进 `06`；课程、自测与面试话术放 `_local/`，不写进文档。
5. 图片放笔记同级 `assets/`，相对路径引用，不引外部图床。
6. 不写真实敏感信息：内网地址、账号、客户名、测试机名一律用占位符。
7. 规范原始包（当前为 3GPP，`*.zip`）**不入库**，用 `tools/3gpp/fetch.py` 按需下载，本地副本保留；改完章节文件跑一次 `tools/3gpp/index.py` 重建索引。

## 关于本库

- 2026-11 重组成独立 Git 仓库；只保留通用知识内容，个人材料不进入版本库。
- 仓库跟踪约 330 MB（docx 文档为主），全量 clone 仍偏大；只要笔记可以用 sparse-checkout 只取 `01`–`02`：

  ```bash
  git clone --filter=blob:none --sparse <仓库地址> RFNote
  cd RFNote && git sparse-checkout set "01 基础概念" "02 测试指标"
  ```
- 原始 zip（约 128 MB）不入库，下载后留在各自的规范目录即可，不会出现在 `git status` 里：见 [00 3GPP检索索引](<03 规范与标准/3GPP/00 3GPP检索索引.md>) 与 [tools/3gpp/fetch.py](tools/3gpp/fetch.py)。
