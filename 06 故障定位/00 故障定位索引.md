# 故障定位索引

> 共 **5** 篇。定位：射频测试失败时，用**分层、二分、对照**把问题从「一个 FAIL」收敛到「一个可验证的根因」。
> 边界：指标定义看 [测试指标](<../02 测试指标/00 测试指标索引.md>)，仪表与系统看 [仪表与设备](<../04 仪表与设备/00 仪表与设备索引.md>) 与 [测试系统与自动化](<../05 测试系统与自动化/00 测试系统与自动化索引.md>)，限值条款看 [3GPP 检索索引](<../03 规范与标准/3GPP/00 3GPP检索索引.md>)。
> 本域只讲排查方法与案例，不重复指标正文；案例均匿名化，不写客户名、测试机名与内网地址。

## 排查顺序

```text
复现 → 定范围（band/信道/工位/机型）→ 建基线（golden sample）
     → 先排测量系统（校准/线缆/仪表/触发）
     → 再排 DUT（配置/测试态/电源/温度/软件）
     → 二分/替换验证 → 闭环（改什么、怎么防再发）
```

三条铁律：

1. **先证明测试系统没问题**，再怀疑 DUT；否则会把校准误差当成设计缺陷。
2. **一次只改一个变量**；同时换线、换手机、改脚本，最后不知道是谁修好的。
3. **没有证据不算根因**；至少要有「改回去故障复现、改回来故障消失」的闭环。

## 阅读路径

- **第一次遇到 FAIL**：方法论 §3 四步法 → 对应链路的「症状 → 根因」表。
- **怀疑仪表/线缆**：仪表与链路故障 §2 的替换顺序。
- **要做复盘**：典型案例的「现象/证据/根因/动作/预防」结构。
- **写测试报告**：方法论 §6 的记录模板。
