# 发射链路故障

> 发射类失败通常表现为：功率不够、频谱超限、EVM 差、频率偏、开关瞬态不过。先分清是「DUT 发不好」还是「系统测不准」，再沿 PA → 滤波/开关 → 天线 → 电源/控制逐段查。
> 指标定义见 [功率类](<../02 测试指标/02 功率类指标.md>)、[频谱类](<../02 测试指标/03 频谱类指标.md>)、[调制质量类](<../02 测试指标/04 调制质量类指标.md>)；通用方法见 [排查方法论](<01 排查方法论.md>)。

## 1. 先分类

| 类别 | 典型指标 | 先看什么 |
|---|---|---|
| 功率 | MOP、最小功率、TPC、TX OFF | 功率计/综测仪读数、功率档、线损 |
| 频谱 | OBW、SEM、ACLR、杂散、发射互调 | 频谱形状、压缩、滤波器、屏蔽 |
| 调制 | 频率误差、EVM、载波泄漏、IQ 不平衡 | 星座、频偏、LO、IQ 补偿 |
| 瞬态 | 开关时间、功率斜坡、TPC 步进 | 触发/窗口、时域 trace |

## 2. 通用顺序

1. 确认测试条件：band/信道/带宽/RB/调制/功率档/天线。
2. 确认路径损耗：功率计校到 DUT 端口；换端口要换校准表。
3. 看原始 trace，不只看 PASS/FAIL。
4. 降功率/换信道/换调制，看是否随功率/频率变化。
5. 换 golden sample，区分 DUT 与系统。
6. 再动 DUT 的校准/匹配/软件。

## 3. 功率类

### 3.1 功率偏低

| 可能 | 机制 | 验证 |
|---|---|---|
| 路径损耗没算/算多 | 仪表读数比 DUT 实际低 | 功率计校到端口 |
| 没到最大功率档 | 软件/TPC 没拉满 | 回读功率档、TPC 命令 |
| PA 供电跌落 | 大电流时电压降 | 测 PA 供电、换稳压源 |
| 负载失配 | tuner/天线/开关失配，PA 保护 | 查 S11、换负载、看保护日志 |
| PA 压缩/保护 | 温度/驻波触发降功率 | 看温度、驻波、PA 电流 |
| 校准表错 | 功率控制表偏差 | 对比多个信道、查校准版本 |
| 线缆/开关坏 | 插损变大 | 换线、直连、逐段测 |

先看「所有信道都低」还是「某信道低」：全低偏系统/功率档，某信道偏匹配/滤波器/校准。

### 3.2 功率偏高

- 功率档/TPC 配置错；
- 校准表把损耗补多了；
- 测试态没有按预期降功率；
- 天线/负载失配导致功率计读数异常（驻波）。
- 先确认不是测量误差，再查功率控制/校准。

### 3.3 TX OFF / 瞬态

- 窗口压在开关瞬态上：调整触发/延迟，看时域；
- DUT 关断不彻底：PA 使能/偏置漏电；
- 测试系统噪声底/泄漏：断开 DUT 看底噪；
- TPC 步进不对：查命令序列、状态机、校准表。

## 4. 频谱类

### 4.1 ACLR 差

| 机制 | 现象 | 验证 |
|---|---|---|
| PA 压缩 | 功率越高越差 | 降功率看是否改善 |
| DPD 没开/失配 | 高阶调制差 | 查 DPD 配置/反馈 |
| 滤波器抑制不足 | 邻道/远端超限 | 查滤波器 S21、换信道 |
| IQ 镜像/LO 泄漏 | 不对称 | 看频谱形状、IQ 补偿 |
| 开关/双工器非线性 | 大功率下差 | 换开关、查隔离 |
| 测试系统互调 | 两路信号/强功率 | 换衰减、查合路器 |

先看 ACLR 随功率的变化：**降功率明显改善 → DUT 线性度/DPD；不改善 → 滤波器/系统**。

### 4.2 SEM / 杂散

- 谐波：PA/开关非线性，滤波器抑制不够；
- 混频/时钟杂散：LO、ADC/DAC 时钟、DC-DC；
- 环境干扰：断开 DUT 仍有 → 外部；
- 屏蔽/接地：手靠近/换屏蔽箱变化 → 辐射耦合；
- 测试系统自身杂散：换频谱仪/加衰减验证。

### 4.3 OBW 超限

- 配置带宽/RB 错；
- 滤波器/DPD 把频谱展宽；
- 调制/削峰设置；
- 仪表 RBW/积分带宽设置错。

### 4.4 发射互调

- 双音/双载波在 PA 产生 IM3；
- 测试系统合路器/仪表自身互调；
- 隔离不足、功率过高；
- 先降功率、换合路器，再查 DUT。

## 5. 调制质量

### 5.1 频率误差

- 参考时钟（TCXO/晶振）精度/温漂；
- 校准/ AFC；
- 仪表参考未共享/未锁定；
- 先看是否所有信道同向偏：同向偏 → 参考；随机 → 锁定/干扰。

### 5.2 EVM 差

| 可能 | 验证 |
|---|---|
| PA 压缩 | 降功率看改善 |
| LO 相噪 | 看星座旋转/相位噪声 |
| IQ 不平衡 | 看镜像/星座椭圆 |
| 均衡/解调设置 | 换仪表设置/参考信号 |
| 时钟/触发 | 看符号定时、频偏 |
| 测试系统 EVM 底 | 环回/已知好信号源 |

EVM 要把「DUT 的 EVM」和「仪表解调 EVM 底」分开；仪表底噪不够时，测不出来。

### 5.3 载波泄漏 / IQ 不平衡

- LO 泄漏/DC 偏置；
- IQ 增益/相位失配；
- 校准表/温度；
- 低 RB/中心 RB 配置更容易暴露。

## 6. 测试系统混淆项

| 现象 | 系统可能原因 |
|---|---|
| 所有 DUT 同项差 | 校准/线缆/仪表设置 |
| 某工位差 | 开关路径/夹具 |
| 高功率才差 | 衰减不够/仪表压缩/合路器互调 |
| 低频/高频端差 | 校准只做单点/滤波器边沿 |
| 结果抖动 | 触发/参考/环境干扰 |

## 7. 快速检查表

- [ ] 条件与配置回读一致。
- [ ] 路径损耗按端口/频点校准。
- [ ] 降功率/换信道/换调制做过对比。
- [ ] golden sample 结果正常。
- [ ] 原始 trace/星座/时域已保存。
- [ ] 仪表错误队列为空、参考/触发正常。
