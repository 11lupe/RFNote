# 仪表与链路故障

> 射频测试里最贵的错误，是把「线缆/校准/触发」的问题当成 DUT 设计缺陷。本文给一条从 DUT 端口往外推的替换顺序，先把测量系统排除干净。
> 系统架构见 [测试系统架构](<../05 测试系统与自动化/01 测试系统架构.md>)；校准细节见 [路径损耗与夹具校准](<../05 测试系统与自动化/04 路径损耗与夹具校准.md>)。

## 1. 先问三个问题

1. **是所有 DUT 都差，还是只有这一台？** 都差 → 系统；单台 → DUT。
2. **是所有 band/信道都差，还是某一段？** 全段 → 校准/线缆；某段 → 滤波器/接头/频响。
3. **是只有这个工位差，还是所有工位？** 单工位 → 开关路径/夹具；全工位 → 仪表/参考/软件。

## 2. 替换顺序（从便宜到贵）

```text
DUT 端口
  ↑ 1. 换夹具/探针/耦合器
  ↑ 2. 换线缆（已知好线）
  ↑ 3. 换衰减器/滤波器（确认方向/功率）
  ↑ 4. 换开关矩阵路径/端口
  ↑ 5. 换仪表端口（RF1 → RF2）
  ↑ 6. 换仪表/参考/触发源
  ↑ 7. 换测试脚本/驱动版本
```

每换一步，复测同一条件并记录；不要一次换两样。

## 3. 线缆与接头

| 现象 | 可能 | 检查 |
|---|---|---|
| 全频段损耗大 | 线缆弯折/压伤/接头松 | 换线、看回波/插损 |
| 某频点尖峰 | 接头污染/氧化/中心针歪 | 清洁/换接头、显微镜看 |
| 结果随触碰变化 | 接触不良/屏蔽破 | 摇线测试、换线 |
| 高功率发热 | 线缆/接头功率容量不够 | 换大功率线、加衰减 |
| 相位不稳定 | 线缆移动/温度 | 固定走线、稳相线 |

接头要按扭矩拧紧，不要徒手硬拧；反复插拔会磨损，测试端口要定期检查/更换。

## 4. 衰减器、滤波器、功分/合路

- 衰减器方向/功率容量错：烧仪表或压缩；
- 滤波器通带/抑制装反：有用信号被滤掉；
- 功分/合路器隔离不够：两路互相泄漏，互调/ACS 假失败；
- 合路器自身互调：强信号下产生 IM3，被当成 DUT 互调；
- 直流偏置：需要 DC block 时没加，仪表输入端偏置。

验证：用 VNA 测 S21/S11，用两台信号源做互调底测试。

## 5. 开关矩阵

- 每条路径损耗不同：必须逐路校准；
- 继电器寿命/接触电阻：反复切换后损耗漂；
- 隔离不足：相邻通道泄漏，导致「测 A 串 B」；
- 切换后未稳定：等继电器 settle 再触发；
- 矩阵控制/驱动错：实际路径与软件显示不一致。

检查：切到已知直通路径，测插损；切到隔离路径，测泄漏；记录切换次数。

## 6. 参考与触发

| 现象 | 可能 |
|---|---|
| 频率误差所有 DUT 同向偏 | 参考时钟未共享/未锁定 |
| EVM/星座旋转 | 参考频偏/相位噪声 |
| 吞吐统计抖动 | 帧/时隙触发不稳 |
| 多仪表结果对不上 | 各自自由运行，未共参考/触发 |
| 测量窗口错位 | 触发延迟/极性设置错 |

多仪表系统必须共 10 MHz 参考；触发线要接对方向（谁输出、谁输入），并在软件里选对外部触发。

## 7. 仪表与驱动

- 仪表固件/选件与脚本不匹配：报 `unsupported`/参数被忽略；
- 远程 vs 本地状态：前面板设置被脚本覆盖，或脚本没进远程；
- 错误队列有旧错误：配置后没 `*CLS`/没读 `SYST:ERR?`；
- 超时/重连：网络/USB 不稳，读到上一次结果；
- 校准状态过期：仪表自校准/外部校准超期。

检查：`*IDN?`、`*OPT?`、错误队列、参考锁定状态、校准日期。

## 8. 环境与屏蔽

- 环境干扰：断开 DUT 仍有杂散/底噪抬高；
- 屏蔽箱缝隙/线缆入口：手靠近/关门变化；
- 接地环路：USB/网线/电源共地，低频噪声；
- 温度：长时间测试漂移，空调/风道影响；
- 振动/接触：夹具探针压力不够。

验证：换屏蔽箱、电池供电、断开 USB/网线、近场探头定位。

## 9. 快速检查表

- [ ] 全 DUT/全 band/全工位三个维度已定位。
- [ ] 路径损耗按端口/频点校准且未过期。
- [ ] 线缆/接头/衰减器/滤波器方向与容量正确。
- [ ] 开关路径逐路校准，隔离足够。
- [ ] 参考/触发共享且锁定。
- [ ] 仪表错误队列为空、选件/固件匹配。
- [ ] golden sample 同条件通过。
