# 接收链路故障

> 接收失败的共同表现是「吞吐/BLER 不达标」，但根因可能在测试系统、干扰源、DUT 前端、电源/共存，甚至统计样本不够。先确认「测的是不是接收机」，再分层。
> 指标定义见 [接收类指标](<../02 测试指标/05 接收类指标.md>)；通用方法见 [排查方法论](<01 排查方法论.md>)。

## 1. 先分清失败类型

| 类型 | 现象 | 首要怀疑 |
|---|---|---|
| 灵敏度差 | 弱信号下吞吐先掉 | 路径损耗、NF、滤波器、天线 |
| ACS 差 | 邻道干扰下掉 | 接收滤波、线性度、干扰源相噪 |
| 阻塞差 | 带外强干扰下掉 | LNA/混频器饱和、滤波抑制 |
| 杂散响应 | 特定频点掉 | 本振/时钟/DC-DC 谐波、镜像 |
| 接收互调 | 双干扰下掉 | LNA/混频器线性度、合路器 |
| Desense | 开某功能后灵敏度变差 | TX 泄漏、共存、电源/地 |
| 吞吐低但灵敏度正常 | 高 MCS/调度/协议 | 信道条件、CQI、调度、仪表配置 |
| OTA 差 | 传导正常、整机差 | 天线效率/失配/手握/暗室校准 |

## 2. 先排除测量系统

按顺序：

1. **路径损耗**：功率计/信号源校到 DUT 端口；换线/换端口重校。
2. **干扰源**：关掉干扰源，看底噪/吞吐是否恢复；干扰源相噪/谐波是否足够低。
3. **合路器/隔离**：有用信号与干扰的隔离、合路器互调。
4. **参考/触发**：仪表参考共享、帧同步；否则吞吐统计会抖。
5. **DUT 状态**：band/带宽/RB/天线/MCS 是否与测试方法一致。

用 golden sample 跑同一条件：golden 也差 → 系统/校准；golden 正常 → DUT。

## 3. 灵敏度差

### 3.1 全 band 都差

- 路径损耗少算/多算；
- 测试系统噪声底高（衰减不够/仪表 NF）；
- 供电噪声、USB/充电干扰；
- DUT 接收态配置错（天线、增益模式、分集）；
- 参考时钟/频率偏差导致解调损失。

先测「仪表输出到 DUT 端口的实际功率」，再看 DUT 上报的 RSRP/RSRQ/SINR 是否与设定一致。

### 3.2 某 band/信道差

- 接收滤波器边沿/抑制；
- 天线/匹配在该频段失配；
- 本振/时钟谐波落在该 band；
- 校准表该频点错；
- 双工器/开关该路径损耗大。

对比同平台/同机型其他 band，查 S 参数与校准表。

### 3.3 只有某带宽/RB 差

- 噪声带宽/AGC 配置；
- 接收机滤波/采样率；
- 测试方法要求的 RB 位置；
- 仪表配置与 DUT 不一致。

## 4. ACS / 阻塞 / 互调

| 现象 | 机制 | 验证 |
|---|---|---|
| ACS 差 | 邻道滤波抑制不足、混频器/ADC 阻塞 | 降干扰功率看是否线性；换干扰源 |
| 阻塞差 | LNA 饱和、带外抑制不足 | 扫频找敏感频点；加外置滤波 |
| 杂散响应 | LO/时钟谐波、镜像 | 改时钟/屏蔽；逐点扫 |
| 接收互调 | 双干扰三阶产物 | 降功率、换合路器、查隔离 |

共同点：**先确认干扰源本身干净**。干扰源相噪差/谐波大，会把「仪器问题」测成「DUT 问题」。

## 5. Desense

排查顺序：

1. 关所有非必要功能，测基线灵敏度/吞吐。
2. 逐个打开：TX、Wi-Fi、BT、GNSS、充电、屏幕、摄像头、USB。
3. 每次只开一个，记录灵敏度变化；变化出现即锁定功能。
4. 判断传导还是辐射：换屏蔽箱、断开天线、加磁珠/滤波、换电源。
5. 查 TX 泄漏：TX 功率/信道/band 变化时 desense 是否跟随；双工器隔离、PA 谐波、PCB 耦合。
6. 查共存：Wi-Fi/BT 信道与蜂窝 band 的谐波/互调关系；DFS/信道切换。

Desense 不是 3GPP 单一指标，别用「规范没要求」结案；用户感知的是实际吞吐。

## 6. 吞吐低但灵敏度正常

- MCS/CQI 上报低：信道条件、干扰、DUT 调度；
- 仪表配置：带宽、MIMO 层数、TDD 配比、调度算法；
- 传输参数：TCP 窗口、iperf 参数、服务器瓶颈；
- BLER 统计：样本不够、重传、误码分布；
- DUT 热降频/省电模式。

先看 PHY 吞吐 vs 应用层吞吐，再看 BLER/CQI/MCS 时间序列。

## 7. OTA 与传导差异

| 差异 | 可能 |
|---|---|
| 传导好、OTA 差 | 天线效率/失配、壳体、手握、SAR 降功率 |
| OTA 好、传导差 | 夹具/探针损耗、参考面错 |
| 某方位差 | 天线方向图/极化/暗室校准 |
| 毫米波波动 | 波束对准、位置误差、阵列增益 |

OTA 要单独校暗室参考点，不能拿传导路径损耗代替。

## 8. 快速检查表

- [ ] 条件/配置回读一致（band、带宽、RB、MCS、天线）。
- [ ] 路径损耗到 DUT 端口已校。
- [ ] 干扰源关闭后基线正常。
- [ ] golden sample 同条件通过。
- [ ] 失败随功率/频点/功能的变化规律已记录。
- [ ] 原始吞吐/BLER/RSRP/日志已保存。
- [ ] OTA 与传导分别校参考面。
