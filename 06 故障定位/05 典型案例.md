# 典型案例

> 以下案例均匿名化处理，只保留现象、证据链、根因与动作；机型/工位/客户信息不出现。案例用于复盘与培训，不替代具体项目的测试记录。
> 方法框架见 [排查方法论](<01 排查方法论.md>)；指标定义见 [测试指标索引](<../02 测试指标/00 测试指标索引.md>)。

## 案例 1：全工位 ACLR 同时差 3 dB

**现象**：同一机型在所有工位、所有信道 ACLR 都比限值差约 3 dB；功率、EVM 正常；换 golden sample 也差。

**证据**：

- 频谱形状正常，没有明显杂散；
- 降功率 3 dB 后 ACLR 改善，但不线性；
- 仪表错误队列为空，参考锁定正常；
- 路径损耗表是上周的，期间换过一段延长线。

**排查**：

1. 用功率计在 DUT 端口复测，发现实际功率比仪表读数低约 3 dB；
2. 逐段测线缆，发现延长线接头处插损异常；
3. 换已知好线，ACLR 恢复；换回旧线，故障复现。

**根因**：延长线接头损坏，路径损耗少算 3 dB，仪表实际在更高功率下测 ACLR，DUT 被推到更接近压缩点。

**修复**：更换线缆，重校所有工位路径损耗；开班增加功率计抽检。

**预防**：线缆编号/扭矩/更换记录；校准表与物理路径绑定；ACLR 前先确认功率。

**教训**：ACLR 随功率恶化时，先怀疑「实际功率比设定高」，不要先改 DPD。

## 案例 2：只有高信道灵敏度差

**现象**：某 band 低/中信道 REFSENS 正常，高信道差 4–5 dB；TX 指标正常。

**证据**：

- 高信道 RSRP 正常，SINR 偏低；
- 换 golden sample 仍差，换工位仍差；
- 路径损耗表只校了 band 中心频点；
- 高信道靠近接收滤波器边沿。

**排查**：

1. 用信号源 + 功率计在高信道复测路径损耗，发现比中心频点高约 4 dB；
2. 查校准表，只有中心频点一个值，软件按单点补偿；
3. 补高/中/低信道校准后，REFSENS 恢复。

**根因**：校准只做单点，高信道滤波器/线缆损耗被低估，DUT 实际收到的功率更低。

**修复**：按 band 边缘 + 中心多点校准，软件按频率插值。

**预防**：校准表覆盖每个 band 的低/中/高信道；换滤波器/线缆后重校。

**教训**：「只有高信道差」不一定是 DUT 滤波器，也可能是校准表没覆盖边缘。

## 案例 3：TX 打开后 RX 灵敏度掉 8 dB

**现象**：接收灵敏度单独测正常；一旦 TX 同时工作，REFSENS 掉 8 dB；TX 功率越大越差。

**证据**：

- 关 TX 后恢复；换信道/band 后 desense 频率跟随 TX 谐波；
- 传导测试也复现，排除天线耦合；
- 双工器隔离指标正常，但 PA 二次谐波落在 RX band；
- 加外置滤波器后改善。

**排查**：

1. 扫 TX 谐波，确认二次谐波落在 RX 频段；
2. 查双工器在该频点的抑制，发现样品批次抑制不足；
3. 换双工器，desense 从 8 dB 降到 2 dB；再优化 PA 匹配后通过。

**根因**：PA 二次谐波经双工器泄漏到 RX，LNA 输入端非线性/饱和。

**修复**：双工器来料管控 + PA 输出匹配/滤波优化。

**预防**：TX 谐波与 RX band 的对照表；双工器批次抽测；desense 纳入回归。

**教训**：双工器「隔离」是频点相关的，不能只看一个平均值。

## 案例 4：吞吐偶发掉到 0，重跑就过

**现象**：吞吐测试约 5% 概率掉到 0，重跑通过；仪表无报错，DUT 日志正常。

**证据**：

- 失败时仪表显示上次的吞吐值，时间戳未更新；
- 脚本用固定 `sleep` 等测量完成；
- 仪表在忙时查询返回旧结果；
- 换 `*OPC?` + 状态位后不再复现。

**根因**：脚本没有确认本次测量完成，读到了上一次缓存结果；固定延时在仪表忙时不够。

**修复**：改为「发起测量 → 等 OPC/状态位 → 取数 → 校验时间戳/序列号」。

**预防**：所有测量封装完成判定；禁止用固定 sleep 代替同步；失败保存原始返回。

**教训**：`query` 返回成功不等于数据是本次的；同步是自动化第一课。

## 案例 5：OTA EIS 比传导 REFSENS 差 6 dB

**现象**：传导灵敏度正常，OTA EIS 差 6 dB；不同方位差异大。

**证据**：

- 暗室路径损耗用的是上次配置的校准文件；
- 换参考天线复测，暗室损耗偏差约 4 dB；
- 手机天线效率在暗室扫方位时某方向明显低；
- 壳体/手握模拟未固定。

**排查**：

1. 重新校准暗室参考点，偏差降到 1 dB；
2. 固定手机位置/姿态/手握，复测 EIS；
3. 剩余 2 dB 归因于天线效率/匹配，改匹配后改善。

**根因**：暗室校准过期 + 手机位置不固定，导致 OTA 结果不可比。

**修复**：重校暗室，夹具定位销固定姿态；OTA 测试前检查校准日期。

**预防**：OTA 校准有效期/换配置重校；位置/姿态/手握写入作业指导书。

**教训**：OTA 的「校准」不只是线缆，还包括暗室、探头、位置与姿态。

## 案例 6：杂散测试把环境干扰当成 DUT 杂散

**现象**：某频点杂散超限，换信道仍在同一绝对频率；DUT 关机后仍存在。

**证据**：

- 频谱仪接匹配负载仍有该频点；
- 断开 DUT 电源，杂散不消失；
- 近场探头定位到测试架上的开关电源。

**根因**：测试环境/开关电源辐射，被当成 DUT 杂散。

**修复**：更换电源/加屏蔽/滤波，杂散消失。

**预防**：杂散测试前先扫环境底噪；DUT 关机对照；屏蔽箱线缆入口滤波。

**教训**：绝对频率固定的杂散，先怀疑环境，不要先改 DUT。
