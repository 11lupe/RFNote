# 路径损耗与夹具校准

> 射频限值定义在 DUT 天线端口，仪表看到的却是自己的端口。中间每 1 dB 损耗，都会直接变成 1 dB 的判错风险。
> 本文讲传导路径损耗、开关矩阵、夹具与 OTA 参考点的校准方法；测量设置本身见 [测量基础与校准](<../02 测试指标/01 测量基础与校准.md>)。

## 1. 参考平面

```text
仪表端口 ── 线缆 ── 开关 ── 衰减器 ── 夹具 ── DUT 天线端口
   P_inst                                      P_dut
```

- **仪表端口**：功率计/综测仪/信号源的校准面。
- **DUT 端口**：手机天线连接器/天线口，限值定义在这里。
- 路径损耗 `L(f) = P_inst − P_dut`（dB），随频率变化。
- 发射测试：仪表读数减去 `L` 才是 DUT 输出；接收测试：仪表输出加上 `L` 才是 DUT 输入。

OTA 的参考面是暗室参考点/探头口径，不是手机天线口；EIRP/EIS 还要叠加空间损耗、天线增益、极化/方位误差。

## 2. 三种校准方法

| 方法 | 做法 | 适用 | 注意 |
|---|---|---|---|
| 功率计 + 信号源 | 信号源输出已知功率，功率计在 DUT 端读 | 单频/少量频点 | 功率计探头校准因子、失配 |
| VNA S21 | 测整条链路传输系数 | 宽带/多频点 | 端口校准、夹具接入方式 |
| Golden sample | 已知性能样机跑指标，反推系统损耗 | 端到端复核 | 样机本身会漂移，不能替代物理校准 |

工程上常用「功率计逐频点 + VNA 扫频」互相验证；只靠 golden sample 反推，容易把 DUT 差异当成系统损耗。

## 3. 逐段拆解

| 部件 | 损耗/影响 | 校准要点 |
|---|---|---|
| 线缆 | 随频率上升，弯折会变 | 固定走线，记录编号，定期复测 |
| 开关矩阵 | 插入损耗 + 隔离 + 重复性 | 每条路径单独校；继电器寿命 |
| 功分/合路器 | 分配损耗、隔离、相位 | 双向分别校；端口匹配 |
| 衰减器 | 固定衰减、驻波 | 算进链路预算；注意功率容量 |
| 夹具/耦合器 | 耦合损耗、位置敏感 | 每次换夹具/换手机重校 |
| 接头 | 磨损、扭矩、污染 | 扭矩扳手、清洁、定期更换 |
| PCB/弹片 | 阻抗不连续、寄生 | 仿真 + 实测，避免长引出 |

开关矩阵是重灾区：同一台仪表经不同路径到不同工位，损耗可能差 1–3 dB；每条路径必须有独立校准文件。

## 4. 校准表

推荐格式（CSV/JSON）：

```text
path_id, freq_mhz, loss_db, uncertainty_db, measured_at, instrument, notes
P1, 700, 2.35, 0.15, 2026-11-01, power_meter_A, cable#3+switch#2
P1, 900, 2.61, 0.15, ...
P1, 1800, 3.42, 0.18, ...
```

- 按路径 + 频率存；测量频点覆盖 band 边缘与中心。
- 仪表按频率插值，不要用单点损耗代替全 band。
- 记录校准日期、仪表、线缆/开关编号；超期/换件要重校。
- 校准不确定度要写进结果；判定时留 guard band。

## 5. 复核与漂移

- 每天/每班开班用功率计抽测 1–2 个频点，和校准表比对。
- 换线、换夹具、换开关、移动设备后必须重校。
- 发现某频点突然差 0.5 dB 以上，先查接头/线缆，不要先改 DUT。
- 保存「校准前/后」的原始读数，便于追责与复盘。
- 温度变化大的环境，增加复核频次；相位稳定性和幅度稳定性分开看。

## 6. 夹具设计

- 屏蔽：缝隙、线缆入口、面板滤波；屏蔽度不够时环境干扰会伪装成 DUT 杂散。
- 接地：低阻抗、单点/多点按频率设计，避免地环路。
- 定位：手机位置、天线耦合距离、极化、角度要可重复。
- 应力：弹片/探针压力适中，避免损伤天线弹片或壳体。
- 散热：长时间满功率测试要留风道/温度监控。
- 标识：夹具编号、适用机型、校准日期、责任人。

## 7. OTA 参考点

- 暗室校准：参考天线、路径损耗、探头增益、转台角度。
- EIRP/EIS 计算要把暗室损耗、天线增益、极化失配算进去。
- 毫米波还要考虑波束对准、阵列增益、位置误差。
- 每次换暗室配置/夹具/探头都要重新校准；不要用上次的校准文件。

## 8. 常见错误

| 现象 | 根因 | 处理 |
|---|---|---|
| 全 band 差固定 2 dB | 线缆/衰减器没算 | 逐段测，更新校准表 |
| 高/低频差不同 | 只用单点校准 | 多频点校准 + 插值 |
| 某工位结果差 | 开关路径没单独校 | 每路径独立校准 |
| 换夹具后结果跳变 | 耦合/定位/屏蔽变化 | 重校夹具，固定位置 |
| 校准表正确但结果漂 | 接头松动/温度/线缆弯折 | 开班复核、固定走线 |
| OTA 与传导差很多 | 天线/壳体/暗室校准 | 分别校参考点，查极化/方位 |

## 9. 检查清单

- [ ] 每条路径、每个频点都有损耗值，不是平均值。
- [ ] 校准文件含日期、仪表、线缆/开关编号、不确定度。
- [ ] 开班/换件/移动后复核。
- [ ] 夹具位置、耦合、屏蔽可重复。
- [ ] OTA 参考点单独校准，不用传导值代替。
- [ ] 结果判定留 guard band。
