# DUT 控制与测试模式

> 射频自动化的一半时间花在「让手机听话」：进测试态、锁 band、控功率、切天线、取日志、异常恢复。控制通道不稳，测量结果就不可信。
> 本文讲通用方法；具体命令/工具随平台、固件、权限变化，必须以项目文档和授权为准。

## 1. 控制通道

| 通道 | 典型用途 | 优点 | 风险 |
|---|---|---|---|
| ADB | shell、推文件、日志、部分测试命令 | 通用、易脚本化 | 需授权/调试开关；重启后失效 |
| AT 口 | 模组/手机 AT 命令 | 简单、实时 | 命令集因平台而异；可能被占用 |
| QMI / Diag | 高通平台诊断、NV、日志 | 能力强 | 需专用工具/驱动；误写 NV 风险高 |
| 串口 | 模组、电源、夹具控制 | 稳定、独立 | 接线/波特率/流控 |
| 厂商 SDK/工具 | 测试态、校准、产线 | 功能完整 | 版本绑定、许可、黑盒 |

选择原则：

- 能用标准 ADB/AT 解决的，不轻易上诊断工具；
- 需要读写 NV/校准参数时，必须有授权、备份和回滚方案；
- 产线与研发用不同权限，产线不开放调试口。

## 2. 进测试态

典型顺序（具体命令替换为项目实际）：

1. 确认设备在线：`adb devices` 返回 `device`，不是 `unauthorized`/`offline`。
2. 开飞行模式/关 Wi-Fi/蓝牙/GNSS，排除共存干扰；需要测共存时再逐项打开。
3. 进厂商测试模式/诊断模式；确认返回成功，不是「命令回了 OK 但没生效」。
4. 锁 band、信道、带宽、RB、调制、天线；逐项回读。
5. 设发射功率/功率控制模式；确认 DUT 实际输出与设置一致（用功率计/综测仪核对）。
6. 跑一条短测量，确认链路通；再进正式序列。
7. 测试结束复位：退测试态、恢复飞行/网络、清日志、重启（按需）。

## 3. 状态回读比命令返回重要

`OK`/`success` 只代表命令被接收，不代表状态生效。每条关键配置都要回读：

| 配置 | 回读内容 |
|---|---|
| band / 信道 | 当前 band、EARFCN/ARFCN、中心频率 |
| 带宽 / SCS | 带宽、子载波间隔、RB 数 |
| 调制 / MCS | 当前调制、MCS、层数 |
| 发射功率 | 目标功率、实际功率、功率档 |
| 天线 | 发射/接收天线、分集状态 |
| 测试态 | 测试模式标志、连接状态 |

回读不一致时，先重试一次；仍不一致就报错并保存现场，不要带着错误配置继续测。

## 4. 功率与天线控制

- 非信令测试通常由 DUT 内部功率控制/测试命令设定目标功率；综测仪只测量。
- 信令测试由网络（综测仪）发 TPC 命令，DUT 跟随；要确认 TPC 步进/累积模式。
- 天线切换要确认：SISO/MIMO、发射天线、接收分集；切换后留 settle。
- 功率校准表/NV 是 DUT 的私有数据；测试脚本只读不写，除非明确授权。
- 大功率测试注意 DUT 发热与电池电压；长时间满功率会触发降功率/保护。

## 5. 电源、温度与稳定性

| 因素 | 影响 | 控制 |
|---|---|---|
| 电池电量 | 低电量降功率/关机 | 固定电量或外部电源 |
| 温度 | PA 增益/频率漂移 | 预热、温度监控、避免阳光直射 |
| USB 供电 | 噪声/电压跌落 | 独立电源、屏蔽、去耦 |
| 充电 | 开关噪声、desense | 测试时禁充或固定充电状态 |
| 屏幕/背光 | 噪声、电流 | 固定亮度/熄灭 |

测试序列开始前留预热时间；长时间测试要记录温度/电压，异常点要能复现。

## 6. 日志与现场

每次失败至少保存：

- DUT 型号、固件、序列号、测试态截图/状态回读；
- 测试脚本版本、配置、仪表设置、校准文件版本；
- DUT 日志（radio log、kernel log、测试工具日志）；
- 失败时的功率/频谱/吞吐原始数据；
- 环境（温度、电源、工位、时间）。

日志要能回答「当时 DUT 在什么状态、收到什么、回了什么」，而不是只有一句 `FAIL`。

## 7. 异常恢复

- 命令超时：先查 DUT 是否离线/重启，再重连；不要无限重试。
- 测试态丢失：重新进测试态、重配 band/功率，再重跑当前步骤。
- ADB 掉线：重启 adb server、换线、换口；记录发生频率。
- DUT 死机/无响应：断电重启，保存日志；连续出现要停线排查。
- 仪表/DUT 状态污染：复位 DUT、复位仪表、重跑基线。

## 8. 安全与合规

- 不写未授权的 NV/校准区；必须写时先备份，记录原始值，提供回滚。
- 不绕过温度/电流/电压保护；不长时间超规格发射。
- 不把客户设备、账号、内网地址写进脚本或文档；用占位符。
- 测试结束恢复 DUT 到可交付状态（退测试态、恢复网络/安全设置）。

## 9. 检查清单

- [ ] 设备在线且授权，测试态进入成功。
- [ ] band/信道/带宽/调制/天线/功率逐项回读一致。
- [ ] 电源、温度、充电状态固定并记录。
- [ ] 失败保存 DUT 日志 + 仪表设置 + 原始数据。
- [ ] 有超时、掉线、死机的恢复路径。
- [ ] 不写未授权 NV；测试后恢复 DUT 状态。
