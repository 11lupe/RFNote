# 法规与行业认证

> 法规认证是产品合法上市的前提，关注的是「不干扰别人、不被别人干扰、对人体安全、电气安全」。它与 GCF/PTCRB 的互操作认证是两条线，不能互相替代。具体法规、限值与流程以目标市场官方最新文本为准。

## 1. 认证类别

| 类别 | 关注点 | 典型项目 |
|---|---|---|
| 射频/频谱 | 发射功率、杂散、占用带宽 | 传导/辐射杂散、功率、频率误差 |
| EMC | 电磁兼容 | 辐射发射、传导发射、抗扰度 |
| SAR/健康 | 人体暴露 | 头/身体/四肢 SAR、功率密度 |
| 安全 | 电气/电池 | 绝缘、温升、电池滥用、充电 |
| 无线接入 | 制式/频段许可 | 当地频率划分、发射许可 |

## 2. 常见市场与体系（示例）

| 市场  | 典型体系        | 备注                    |
| --- | ----------- | --------------------- |
| 欧盟  | CE / RED    | 射频、EMC、安全、健康综合        |
| 美国  | FCC         | Part 15/22/24/27 等按制式 |
| 中国  | SRRC / CTA  | 无线电型号核准 + 进网          |
| 加拿大 | ISED        | 与 FCC 部分测试可复用         |
| 日本  | MIC / TELEC | 技术适合性认证               |
| 韩国  | KC          | 广播通信设备认证              |
| 澳洲  | RCM         | 供应商符合性声明              |

同一产品多市场销售时，测试项目有重叠但**限值、频段、标签、报告格式**不同，不能直接套用。

## 3. 典型流程

```text
确定目标市场
  → 识别适用法规与标准
  → 选择认可实验室
  → 样机/固件/天线状态冻结
  → 预测试（EMC/射频/SAR）
  → 正式测试
  → 整改与复测
  → 报告/证书
  → 标签/说明书/DoC
  → 上市后变更管理
```

## 4. 关键测试

### 4.1 射频与杂散

- 传导杂散、辐射杂散；
- 最大功率、功率谱密度；
- 频率误差、占用带宽；
- 带边/谐波/互调；
- 接收机杂散（按法规要求）。

### 4.2 EMC

- 辐射发射（RE）、传导发射（CE）；
- 静电放电（ESD）、辐射抗扰（RS）、传导抗扰（CS）；
- 电快速瞬变（EFT）、浪涌、电压跌落；
- 测试布置、线缆、辅助设备对结果影响很大；台架侧的开关矩阵、场强闭环与安全联锁见 [EMCenter](<../04 仪表与设备/07 EMCenter.md>)。

### 4.3 SAR

- 头、身体、四肢/热点模式；
- 多天线/多频段同时发射；
- 功率回退与距离；
- 测试液、探针校准、夹具位置；
- SAR 与天线设计、外壳、手握强相关。

### 4.4 安全与电池

- 绝缘/耐压/接地；
- 温升/异常充电；
- 电池过充/过放/短路/挤压（按标准）；
- 充电器/适配器兼容。

## 5. 样机与状态

- 与量产一致的硬件、天线、外壳、电池；
- 固件版本冻结，发射模式可控；
- 提供测试模式/工程命令，便于强制发射；
- 多 band/多天线配置要能单独控制；
- 预留测试点/射频接口（按实验室要求）。

## 6. 常见失败

- 辐射杂散超限：屏蔽/滤波/接地不足；
- EMC 抗扰失败：复位、死机、误触发；
- SAR 超限：天线距离、功率回退、外壳材料；
- 带边功率超限：滤波器滚降/校准；
- 报告与样机不一致：改版后未重测；
- 标签/说明书不合规：缺 CE/FCC ID、警告语。

## 7. 变更管理

以下变更通常需要评估或重测：

- 天线/外壳/电池/充电器变更；
- PA/滤波器/开关换料；
- 发射功率/频段/带宽调整；
- 固件射频参数变更；
- 新增附件（保护壳、外接天线）。

建立「变更 → 影响 → 是否重测」的判定表，比事后补救便宜。

## 8. 准备清单

- [ ] 目标市场与适用法规已确认。
- [ ] 实验室资质/认可范围覆盖项目。
- [ ] 样机与量产一致，固件可控制。
- [ ] 预测试（EMC/射频/SAR）已完成。
- [ ] 天线/外壳/电池变更已评估。
- [ ] 标签、说明书、DoC 模板已准备。
- [ ] 报告与样机序列号可追溯。
