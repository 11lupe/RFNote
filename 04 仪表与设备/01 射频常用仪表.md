# 射频常用仪表与设备

> 定位：手机射频测试里**真正会接进链路**的仪表与设备——按「测什么 → 用什么 → 看哪个参数 → 怎么踩坑」组织，给搭台、选型、自动化接入一个骨架。
> 边界：本文只讲设备本身。参考电平、衰减、RBW、平均次数怎么设，SCPI 为什么 `write` 不等于测完，见 [测量基础与校准](<../02 测试指标/01 测量基础与校准.md>)；指标判定与限值见 [测试指标索引](<../02 测试指标/00 测试指标索引.md>) 与 [3GPP 检索索引](<../03 规范与标准/3GPP/00 3GPP检索索引.md>)。
> 型号只作示例，含义是「这一类长什么样」，不代表唯一选择；具体能力以厂商当前在售型号、固件与选件为准。

## 1. 先分四层

```text
            激励源（信号从哪来）               测量仪表（数从哪读）
   信号源 / 综测仪下行  ──→  DUT  ──→  综测仪上行 / 频谱仪
   GNSS 模拟器 / 干扰源               └──→  功率计 / VNA（测无源件）
                  ↑ 附件：线缆、衰减器、功分器、开关、夹具、校准件
                  ↑ 环境：屏蔽箱 / 暗室 / 温箱
```

一句话：**激励、测量、环境、附件**四层，任何一层出问题，数据都会「看起来正常但不可信」。自动化测试搭不起来，九成不是脚本写错，而是后两层没管好。

四层与本库各域的分工：

| 层 | 对应知识 |
|---|---|
| 激励 / 测量 | 本文 §2–§3（设备）、[测量基础与校准 §2](<../02 测试指标/01 测量基础与校准.md>)（设置） |
| 环境 / 附件 | 本文 §4（链路与屏蔽）、[测量基础与校准 §4](<../02 测试指标/01 测量基础与校准.md>)（路径校准） |
| 判定 | [测试指标索引](<../02 测试指标/00 测试指标索引.md>) → 3GPP 条款 |

## 3. 主力仪表逐个说

### 3.1 综测仪（UE 综测仪 / 呼叫仪）

**作用**：一台顶一个「假基站」。信令模式负责注册、建链、调度；非信令模式只发/收射频，DUT 由程控（ADB / AT）拉进目标状态。TX 与 RX 指标一次接线全测，是研发与产线的主力。

**选型看什么**：

- 支持的 RAT、band、信道带宽、载波聚合层数——决定这台机器能覆盖几代制式。
- 端口数与多天线能力（4×4 MIMO、毫米波中频口）；TX/RX 能否并行。
- 残余 EVM、功率精度、相位噪声：仪表自己的底噪就是你测量的下限。
- 是否在 GCF/PTCRB 认可清单里（型号 + 固件版本，认证场景硬门槛）。
- **软件选件清单**：band、带宽、CA、MIMO 常常是 license，不是硬件。

**坑**：硬件买了不等于能测，报「unsupported」先查选件；信令模式节拍慢，产线普遍走非信令；各厂商 SCPI 私有头不同，把差异收敛在驱动层，别让用例依赖某个厂商命令。

### 3.2 矢量信号源

**作用**：产生 CW、调制信号、多音与干扰，给 RX 指标提供已知的激励。

**选型看什么**：频率上限、调制带宽、相位噪声、EVM 底、通道数（双音互调与 MIMO 需要两个通道或两台源）、是否内置衰落与 GNSS。

**坑**：源自身也有非线性，双音测互调时源产生的三阶产物会混进结果，合路要加隔离与滤波；源的幅度读数不如功率计准，做绝对电平时用功率计校准。

### 3.3 信号 / 频谱分析仪

**作用**：射频的「万能表」。看频谱形状（SEM、ACLR、OBW）、看杂散与谐波、看功率、看相噪；带矢量解调选件时测 EVM。

**选型看什么**：

- 频率上限要覆盖目标 band 的谐波与规范要求的杂散频段（FR1 常见需要看到 13.6 GHz 量级，毫米波更高）。
- 分析带宽 ≥ 最大信道带宽（NR 单载波 100 MHz，CA 更大），否则宽带信号只能拼扫，瞬态会丢。
- 显示平均噪声电平（DANL）、三阶截点（TOI）、1 dB 压缩点、相位噪声。
- 是否带前置放大器、VSA 选件、EMI 检波器（认证预扫用）。

**坑**：参考电平、RBW、衰减、检波器一变，读数就变（设置口径见 [测量基础与校准](<../02 测试指标/01 测量基础与校准.md>)）；拿频谱仪当功率计用，幅度会差 0.5 dB 以上。

### 3.4 矢量网络分析仪

**作用**：测 S 参数。调匹配、看滤波器/双工器/开关的插损与隔离、量线缆与夹具损耗、做去嵌。

**选型看什么**：频率范围、端口数、动态范围与方向性、扫描速度、校准件（机械件或电子校准 ECal）、是否支持时域与脉冲测量。

**坑**：校准平面必须落在你要判定的位置——校在仪表口，测的就是「线缆 + 夹具 + DUT」；回波损耗很深时读数会被方向性与噪声底限制，看起来很好其实没测到；接头重复性与力矩直接决定一致性。

### 3.5 功率计与功率探头

**作用**：绝对功率的基准。校线损、复核 MOP、抽检产线功率；峰值探头还能看 burst 包络与脉冲。

**选型看什么**：频率与电平范围、上升时间/视频带宽（测 burst 与脉冲）、校准因子与温度补偿、是否 USB 探头直连、主机通道数。

**坑**：探头零漂与温漂、校准因子要按频率选；峰值测量的门控设错会漏掉 burst；频谱仪与功率计差 1 dB 时，先信功率计（绝对精度），再查频谱仪的衰减、RBW 与前端。

### 3.6 相噪、噪声系数、频率计

| 设备 | 测什么 | 要点 |
|---|---|---|
| 相噪分析仪（或频谱仪相噪选件） | 单边带相位噪声 dBc/Hz @ 偏移 | 本振相噪会抬高 EVM、恶化邻道；近端与远端偏移要分开看 |
| 噪声系数分析仪 / 噪声源 | RX 噪声系数与增益 | Y 因子法；前置放大器、线损、夹具都会算进 NF |
| 频率计 / 计数器 | 频率误差、短期稳定度 | 闸门时间决定分辨率；参考时钟要共用 |

### 3.7 示波器与直流电源

- **实时示波器**：看包络、开关瞬态、电源纹波、PA 开启时间。探头带宽与接地方式比示波器本身更容易出问题（地线太长会振铃）。
- **直流电源 / 电池模拟器**：模拟电池内阻与瞬态，测 PA 供电、功耗与电流波形；关注负载瞬态响应，而不是只看输出电压准不准。

### 3.8 OTA 与 GNSS

- **OTA**：暗室 + 转台 + 双极化探头 + 综测仪 + 链路校准，测 TRP/TIS。毫米波用紧凑场（CATR），远场条件按 2D²/λ 估距离。
- **GNSS 模拟器**：给 DUT 已知的卫星信号，测灵敏度（C/N0）、TTFF、定位精度；必须在屏蔽环境里做，否则真实卫星信号会串进来。

## 4. 配套设备：链路与环境

附件不起眼，但它决定「仪表读数能不能换算成 DUT 的性能」。

| 设备 | 作用 | 要点 |
|---|---|---|
| 射频线缆 | 连接 | 损耗按 band 实测，不用标称值；相位稳定、弯曲半径、接头磨损都要管 |
| 转接头 | 接口转换 | N / SMA / 3.5 mm / 2.92 mm / 2.4 mm / 1.85 mm；混接引入失配与磨损，毫米波用同系列精密接头 |
| 衰减器 | 保护前端、改善匹配 | 固定或程控；注意功率容量，衰减量必须计入链路 |
| 功分器 / 合路器 | 多仪表共享、双音合路 | 插损与隔离；合路后每路电平按分路重算 |
| 定向耦合器 | 采样与监测 | 耦合度、方向性、主线插损 |
| 射频开关 / 开关矩阵 | 多口、多天线自动切换 | 插损、隔离、寿命、重复性；矩阵的路径损耗要逐路校准 |
| 屏蔽箱 / 屏蔽室 | 隔离外界与自身辐射 | 屏蔽效能、接地、线缆穿孔处加滤波；灵敏度项的「假失败」多出在这里 |
| 测试夹具 / 射频座 | 把 DUT 接进链路 | 插损与重复性、接触电阻、pogo 压力与寿命；夹具损耗要单独标定 |
| 校准件 | VNA 与功率校准 | 机械件便宜但依赖操作，ECal 快且可重复；校准周期与接头保护 |
| 力矩扳手 | 保护接头、保证重复性 | 常见参考值：SMA 约 0.45 N·m、3.5 mm 约 0.9 N·m、N 型约 1.35 N·m（以厂家规格为准） |
| 温箱 | 高低温验证 | 温度影响功率、频偏、相噪；线缆与夹具也会随温度漂 |
| 直流电源 / 电池模拟器 | 供电 | 内阻、瞬态响应、电流波形；供电不稳会被误判成 DUT 问题 |

## 5. 三种场景的典型组合

| 场景 | 目标 | 典型组合 | 关键约束 |
|---|---|---|---|
| 研发调试 | 看得见、改得快 | 综测仪（非信令）+ 频谱仪 + 信号源 + VNA + 功率计 | 手动换线多，优先可观测性 |
| 自动化回归 / 产线 | 节拍与一致性 | 综测仪 + 开关矩阵 + 屏蔽箱 + 夹具 + 功率计（抽检） | 节拍、重复性、校准周期、失败可复现 |
| 认证 / 入网 | 合规 | GCF/PTCRB 认可的综测仪 + 暗室 + 干扰源 + 校准证书 | 仪表清单与固件版本、用例版本、测量不确定度 |

## 6. 自动化接入

### 6.1 物理接口与资源名

| 接口 | 特点 | 资源名示例 |
|---|---|---|
| LAN（VXI-11 / HiSLIP / raw socket） | 现代仪表主流，速率高、可远程 | `TCPIP0::192.0.2.10::inst0::INSTR`、`TCPIP0::192.0.2.10::hislip0::INSTR` |
| GPIB（IEEE-488） | 老仪表多、稳定，需接口卡 | `GPIB0::20::INSTR` |
| USB-TMC | 便携仪表、无需网口 | `USB0::0x0AAD::0x0119::<序列号>::INSTR` |
| 串口 | 少量电源、温箱、老设备 | `ASRL3::INSTR` |

### 6.2 分层

```text
test case  →  driver（厂商/型号命令、单位换算）  →  VISA session  →  物理接口
```

- 公共命令（`*IDN?`、`*RST`、`*CLS`、`*OPC?`、`SYST:ERR?`）跨厂商通用，先跑通它们再接私有命令。
- 私有命令随型号与固件变化，全部收在 driver 里；用例只调 `measure_power()` 这类语义接口。
- 多仪表系统要共享 10 MHz 参考与触发线，否则谈不上频率准确度和时间对齐。

```python
import pyvisa

rm = pyvisa.ResourceManager()
inst = rm.open_resource("TCPIP0::192.0.2.10::inst0::INSTR")
inst.timeout = 10_000                     # ms；不要无限等
print(inst.query("*IDN?").strip())        # 先确认型号/固件与预期一致
inst.write("*CLS")
inst.write("INIT")                        # 具体命令随仪表与选件不同
if inst.query("*OPC?").strip() != "1":
    raise TimeoutError(inst.query("SYST:ERR?").strip())
```

## 7. 选型与验收清单

- [ ] 频率上限覆盖目标 band 的谐波与规范要求的杂散频段。
- [ ] 分析带宽 ≥ 最大信道带宽（NR 单载波 100 MHz 起，CA 更大）。
- [ ] 电平范围与噪声底能测到灵敏度量级（约 −100 dBm 及以下）。
- [ ] 端口/通道数够不够：MIMO、双音、多天线、多工位。
- [ ] 选件清单逐条核对：band、带宽、CA、MIMO、VSA、GNSS 是不是软件 license。
- [ ] 认证场景：型号 + 固件是否在 GCF/PTCRB 认可清单内。
- [ ] 接口与驱动：LAN/GPIB 可用，SCPI 覆盖所需功能，有可维护的驱动层。
- [ ] 校准：周期、证书、ECal/校准件是否配套。
- [ ] 附件库存：转接头、力矩扳手、备用线缆——比仪表更容易缺。
- [ ] 环境：屏蔽箱/暗室指标、接地、温箱、供配电。

## 8. 坑与边界

1. **拿频谱仪当功率计**：绝对幅度差 0.5 dB 以上，贴着限值就会误判。
2. **综测仪选件没买**：band/带宽/CA 报不支持，是仪表能力问题，不是 DUT 故障。
3. **接头混用、力矩不对**：失配、磨损、重复性差，毫米波尤其明显。
4. **屏蔽与接地不到位**：灵敏度、杂散项偶发 FAIL，换台机器就好了。
5. **固件与驱动版本不一致**：私有 SCPI 行为变化，昨天能跑的脚本今天报错。
6. **校准过期或温度漂移**：整批同向偏移，先查链路与证书。
7. **只看仪表读数、不看参考平面**：仪表口不等于 DUT 口，见 [测量基础与校准 §1](<../02 测试指标/01 测量基础与校准.md>)。
8. **不确定度吃掉余量**：仪表能力不足时，贴着限值的读数不可判。测试系统的允许不确定度是规范性要求，见 TS 38.521-1 Annex F.1、TS 36.521-1 Annex F.1；通过/失败判定规则见 TS 38.521-1 §4.6。
