# Keysight UXM 5G 综测仪

> 定位：5G NR / LTE 的主力综测仪之一，一台机器同时做「假基站 + 信号源 + 分析仪」。重点在 5G NR 信令、吞吐、SA/NSA、MIMO 与载波聚合测试。
> 边界：本文只讲 UXM 这一类设备怎么用；LTE 老制式与 WLAN/BT 的综测需求见 [CMW500](<02 CMW500.md>)，指标定义见 [测试指标索引](<../02 测试指标/00 测试指标索引.md>)，系统搭建见 [测试系统架构](<../05 测试系统与自动化/01 测试系统架构.md>)。
> 文中能力/端口/选件均为量级描述，具体以机型标签、固件与 `*OPT?` 为准；不写内网地址、账号与客户名。

## 1. 它解决什么问题

5G NR 的带宽、MIMO、波束、SA/NSA 状态比 LTE 复杂，普通信号源 + 频谱仪很难把 DUT 拉进「真实通信状态」。UXM 的价值：

- 内置 NR/LTE 协议栈，能让 DUT 注册、建立承载、跑吞吐；
- 多射频端口支持 MIMO/CA 的收发；
- 信令与非信令模式覆盖研发、认证预演、产线；
- 与 Keysight 的测量软件/自动化库配合，适合写测试序列。

| 模式 | DUT 谁控制 | 速度 | 适合 |
|---|---|---|---|
| 信令 | UXM 协议栈 | 慢，秒级/项 | 吞吐、SA/NSA、切换、CA、认证预演 |
| 非信令 | ADB/AT/厂商工具 | 快 | 射频指标、产线、快速回归 |
| 波形/ARB | UXM 播放 | 快 | 干扰、阻塞、ACS 场景 |

## 2. 端口与参考

| 项 | 说明 | 注意 |
|---|---|---|
| RF 端口 | 多路 TX/RX，支持 MIMO/CA | 端口数、MIMO 能力看硬件配置 |
| 参考时钟 | 10 MHz in/out | 多仪表共用参考，避免频偏 |
| 触发 | Trigger in/out | 时隙/帧对齐、并行测试用 |
| LAN/GPIB/USB | 远程控制 | 优先 LAN；确认 VISA 资源串 |
| 毫米波 | 通常外接变频/OTA 暗室 | 不是所有机型/选件都内置 |
| SIM | 内置 SIM 模拟/插卡 | IMSI/Ki/OPc/APN 错一个就注册失败 |

每个端口单独存路径损耗；换端口不换校准表，结果会整体偏。

## 3. 能力与选件

| 维度 | 内容 | 怎么确认 |
|---|---|---|
| 制式 | 5G NR SA/NSA、LTE/LTE-A | 选件 + 实测建链 |
| 带宽 | NR 带宽按选件，常见 100 MHz；更高带宽看机型 | 选件表 |
| MIMO | 下行 4×4、上行 2×2 等，按配置 | 端口清单 + 选件 |
| CA | 多载波聚合，组合按选件 | 选件表 |
| 毫米波 | 外接变频/OTA 方案 | 硬件清单 |
| 衰落 | 信道模拟/衰落选件 | 选件表 |
| 自动化 | SCPI/驱动/软件 API | 帮助与版本说明 |

选件确认：前面板 `Instrument Setup → Options` 或远程 `*OPT?`。**硬件口在 ≠ 功能已授权**；信令、带宽、MIMO、CA、毫米波常分开授权。

## 4. 信令测试流程（NR）

1. 仪表配小区：band、SCS、带宽、PCI、TAC、PLMN、功率。
2. SIM/UE 配置：IMSI、Ki/OPc、APN、UE 能力。
3. DUT 开机/飞行模式关闭，等待注册；确认 RRC 连接与承载建立。
4. 配业务：iperf/内置吞吐、Ping、VoNR（按需）。
5. 跑指标：MOP、ACLR、EVM、REFSENS、吞吐、CA/EN-DC 组合。
6. 记录：小区配置、UE 能力、吞吐、功率、错误日志。

常见建链失败：band/SCS 不支持、SIM 参数错、APN 错、DUT 没开 NR、选件没授权、射频线接错端口。

## 5. 非信令与射频指标

- 非信令模式由 DUT 测试态发固定波形，UXM 只做测量；速度快，适合产线。
- ACLR/SEM/杂散等频谱类指标，UXM 的分析带宽/动态范围有限时，用外接频谱仪更稳。
- EVM 要看 UXM 的解调配置（均衡、相位跟踪、测量带宽），不同设置结果不可直接比。
- 路径损耗、参考电平、触发延迟仍按 [测量基础与校准](<../02 测试指标/01 测量基础与校准.md>) 处理。

## 6. 毫米波与 OTA

- 毫米波通常需要外接上/下变频、探头/暗室；UXM 本身不一定直接出 28/39 GHz。
- OTA 要校准暗室路径、探头增益、极化/方位；EIRP/EIS 的参考面与传导不同。
- 波束对准、阵列增益、位置误差对结果影响大；测试时间也显著变长。

## 7. 自动化接入

- 优先 LAN/VXI-11；确认防火墙、端口、VISA 版本。
- 用驱动/API 封装「配小区、等注册、跑吞吐、读结果」，测试层不拼 SCPI。
- 每次测量记录：机型、固件、选件、端口、路径损耗、小区配置、DUT 状态。
- 超时/断链要保存现场（小区状态、UE 日志、错误队列），再重连。

## 8. 限制与常见坑

| 限制/坑 | 说明 | 处理 |
|---|---|---|
| 不是频谱仪 | ACLR/杂散动态范围/带宽有限 | 外接频谱仪/分析仪 |
| 毫米波要外设 | 变频/暗室/探头 | 按 OTA 方案校准 |
| 选件绑定 | 带宽/MIMO/CA 分开授权 | `*OPT?` 确认 |
| 端口损耗 | 每个端口不同 | 逐端口校准 |
| 固件差异 | 同型号不同固件行为不同 | 固定版本并记录 |
| 信令慢 | 建链/状态迁移耗时 | 非信令做射频，信令做吞吐 |
