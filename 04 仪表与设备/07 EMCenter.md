# EMCenter 模块化射频平台

> 定位：ETS-Lindgren 的 EMCenter™ Modular RF Platform——3U 机箱 + 可插拔功能卡，把 EMC/无线测试里散落的「射频开关矩阵、功率测量、场强探头读取、转台与天线塔控制」收进一台设备，由 PC 软件统一调度。
> 边界：它不产生激励、不解调信号，是测试系统里的**配角与执行机构**；EMC 测什么、限值多少看 [法规与行业认证](<../07 认证与准入/03 法规与行业认证.md>) §4.2 与对应标准。
> 型号与卡片编号随产品线更新，本文数字为量级参考，以随机手册与厂家当前规格为准。

## 1. 它解决什么问题

EMC 暗室里的仪器本来就多：接收机/频谱仪在屏蔽室外，功放在机架里，天线在暗室里，场强探头贴在天线前面，转台和天线塔要动。如果每件都单独拉一根控制线到 PC，测试序列就只能靠人工串。

EMCenter 的做法是把这些「执行与读取」收进一个机箱，用一块背板统一供电、通信和**安全联锁**，再由测试软件按序列调用：

```text
PC（TILE! / EMQuest / 自研脚本）
        │  LAN / USB / RS-232 / GPIB(可选)
        ▼
   EMCenter 3U 机箱（7 槽，背板 + 触摸屏 + 联锁）
        │
   ┌────┼─────────┬──────────┬──────────┐
EMSwitch  EMPower   EMSense    EMControl
(切射频路径) (读功率)  (读场强)   (动转台/天线塔)
   │        │          │          │
天线/功放  功率探头   场强探头   位置设备
```

它带来的三个实际好处：

- **路径集中**：一台综测仪、一台频谱仪、一台功率计可以共用暗室里的天线与线缆，靠开关矩阵切换，不用反复插拔。
- **闭环成为可能**：抗扰度测试里「场强到没到」由 EMSense 读、由软件调功放，比人工看表稳。
- **联锁只有一处**：机箱联锁与每张卡的联锁串联，门一开、激光一断，整条链路同时失效，不需要在每台仪器上各接一遍。

## 2. 机箱、槽位与联锁

| 项 | 说明 |
|---|---|
| 形态 | 3U、19 英寸机架式，也可桌面放置；7 槽机型（7000-001）与 2 槽机型（7000-011，带 GPIB） |
| 槽位 | 槽位编号就是软件里的设备地址；插卡上电后**自动识别、自动初始化**，不需要手工配地址 |
| 前面板 | 7 英寸宽屏彩色 TFT 触摸屏，可直接切通道、看探头读数、手动动转台 |
| 联锁 | 机箱自身联锁与每张卡的联锁**串联**，背后板有联锁接口；断开联锁即切断输出 |
| 远程 | RS-232、LAN、USB 标准配置，GPIB（IEEE-488）为选件 |
| 软件 | ETS-Lindgren TILE!（实验室集成环境）、EMQuest（数据采集与分析），或自研自动化 |

**联锁不是可选项**。辐射抗扰度开着功放、激光探头在通电时，联锁被短接或旁路就是安全事故；调试期为了「省事」把联锁插头拔掉，是这类台架最典型的隐患。

## 3. 四类插卡

| 卡 | 功能 | 典型型号与能力 | 主要用途 |
|---|---|---|---|
| EMSwitch | 多通道 RF 开关矩阵 | 7001-00X；二/四/六路，最高约 18 GHz、100 W 量级 | 天线、功放、仪表之间的路径切换 |
| EMPower | 功率计接口卡 | 7002-00X；一卡 4 个 USB 口，接最多 4 个探头 | 绝对功率、脉冲/突发功率测量 |
| EMSense | 场强探头接口卡 | 7007-001 配电池供电探头，7007-002 配激光供电探头；一卡一探头 | 场强读取、抗扰度闭环 |
| EMControl | 位置控制器卡 | 7006-01；光纤控制，最多两台转台/天线塔，另可控制两台辅助设备 | 转台角度、天线升降与极化 |

### 3.1 EMSwitch：切路径

- 本质是多通道继电器矩阵，用于发射、抗扰、无线测量之间共用天线与仪表。
- 每张卡的 Relay A 可以当**安全联锁继电器**用，接进机箱背板的联锁链。
- 坑：通道之间的插损不同，路径损耗必须**按通道分别标定**；大功率下切换有寿命与温升问题，先断功率再切；隔离度决定两台仪表会不会互相串。

### 3.2 EMPower：读功率

- 卡上四个 USB 口，接 EMPower 系列探头；探头有 RMS 型（CW 与连续波，覆盖 9 kHz–6 GHz 量级）与脉冲/突发型（能测微秒级突发）。
- 坑：探头校准因子按频率查表、零漂要归零；峰值/突发测量要设对门控，否则漏掉脉冲；长时间大功率后读数会漂。

### 3.3 EMSense：读场强

- 一卡一探头，按探头供电方式选卡：电池供电探头用 7007-001，激光供电探头用 7007-002。
- 典型动态范围 0.5–800 V/m 量级，覆盖常用抗扰度场强；各向同性偏差与探头校准是场均匀性误差的主要来源。
- 坑：激光供电探头的光纤不能过度弯折；电池探头要管电量；探头位置变了，场强读数就变了，闭环前先确认探头没被碰到。

### 3.4 EMControl：动位置

- 光纤控制 ETS-Lindgren 的转台与天线塔，最多两台位置设备，另可开关两台辅助设备（如 LISN 的电源）。
- 坑：光纤接头松动会表现为「转台不动但软件无报错」；角度回零与限位要在序列开始前确认。

## 4. 典型接法

### 4.1 辐射发射（RE）

```text
暗室接收天线 → EMSwitch → 接收机 / 频谱仪
EMControl：转台 0–360°、天线塔 1–4 m 扫描
```

软件按标准规定的角度与高度步进，逐个位置采集最大值；EMSwitch 在「天线水平/垂直极化」与「不同频段天线」之间切换。**路径损耗按通道标定**，否则换极化后幅度整体偏。

### 4.2 辐射抗扰（RS）

```text
信号源 → 功放 → EMSwitch → 发射天线
EMSense ← 场强探头（闭环调功放，稳定到目标场强）
EMControl：转台与天线塔按标准步进
联锁：房门、功放、激光探头串在一条链上
```

关键在闭环：场强没到目标值，测试就不成立。探头读数、功放增益、天线增益三者任一没标定，闭环就会「稳在一个错的场强上」。

### 4.3 无线与 EMC 共用台架

一台 DUT 既要跑射频指标又要做 EMC 预扫时，用 EMSwitch 在综测仪、频谱仪、功率计之间切 DUT 的射频口，避免反复插拔与线缆磨损。这时要特别注意**隔离度**：仪表端口之间的串扰会让小信号项（杂散、灵敏度）读出假值。

OTA 暗室里的谐波与边带测法见 [射频基础知识](<../01 基础概念/01 射频基础知识.md>) §8.7。

## 5. 手动与自动化

| 方式 | 适合 | 注意 |
|---|---|---|
| 前面板触摸屏 | 调试、单步确认、故障定位 | 手动改过的通道状态要记下来，否则序列从错误状态开始 |
| TILE! / EMQuest | 标准测试序列、报告 | 序列里的通道映射与物理接线要一起归档 |
| 自研脚本 | 与自家产线/研发流程集成 | 命令集按手册实现；先读槽位与卡型，再发操作命令 |

自动化三条硬规矩：

1. **先枚举、再操作**：上电后读槽位与卡型，确认拓扑和预期一致，再发切换命令。
2. **切换后留稳定时间**：机械继电器与功放都需要建立时间，切完立刻测会读到瞬态。
3. **读回状态**：切换结果与联锁状态都要回读，不能只发命令就当成功。

## 6. 坑

1. **联锁被旁路**：最危险，也最常见；调试时短接联锁插头，正式测试忘了恢复。
2. **通道损耗只标了一条**：换极化、换天线后整体偏移，且看起来「每次都不一样」。
3. **带功率切换**：继电器触点拉弧、寿命骤降，严重时粘连。
4. **槽位改了没更新配置**：换卡、换槽后软件还按旧地址操作，表现为「命令成功但没反应」。
5. **隔离度不足**：共用天线时仪表互串，小信号项读出假值。
6. **探头状态**：电池电量、激光光纤弯折、探头位置被碰，都会让场强闭环失准。
7. **转台无反馈**：光纤或限位问题导致位置不动，序列照跑，数据全错。
8. **散热与灰尘**：机箱长期在暗室环境，风扇与接点积灰后大功率下温升异常。
9. **把开关矩阵当快切用**：机械继电器节拍有限，按毫秒级节拍设计序列会加速磨损。
10. **序列与接线不一致**：软件拓扑和实际接线各改一半，问题只在特定用例暴露。

## 7. 验收与维护清单

- [ ] 槽位与卡型清单，与软件配置逐项对账。
- [ ] 每个 EMSwitch 通道的插损与隔离度实测，形成标定表。
- [ ] 联锁链路逐段验证：拔插头、开房门、断激光，输出必须切断。
- [ ] EMPower 探头校准因子与归零；脉冲门控设置验证。
- [ ] EMSense 探头校准与各向同性偏差；场均匀性按标准布点验证。
- [ ] EMControl 角度回零、限位与两台位置设备的联动。
- [ ] 大功率路径的温升与接触电阻抽查。
- [ ] 固件/软件版本、标定表、序列文件一起归档。
