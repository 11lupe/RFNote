# Anritsu MT8000A 综测仪

> 定位：5G NR / LTE 的主力综测仪之一，常用于 UE 射频、协议、吞吐与运营商准入预演。强项是 5G NR 信令与多端口 MIMO/CA 配置。
> 边界：本文只讲这一类设备怎么用；LTE/2G/3G 的综测需求见 [CMW500](<02 CMW500.md>)，另一家 5G 方案见 [UXM](<05 UXM.md>)，指标定义见 [测试指标索引](<../02 测试指标/00 测试指标索引.md>)。
> 能力/端口/选件以机型标签、固件与选件查询为准；不写内网地址、账号与客户名。

## 1. 它解决什么问题

MT8000A 把「5G 基站 + 信号源 + 分析仪」做进一台盒子，让 DUT 在受控小区里注册、建承载、跑吞吐，再测射频指标。它适合：

- 5G NR SA/NSA 信令测试；
- LTE 锚点 + NR 的 EN-DC 组合；
- MIMO/CA 的吞吐与射频验证；
- 运营商/认证实验室的预测试；
- 产线/研发的非信令快速测试（按配置）。

| 模式 | 控制方 | 速度 | 适合 |
|---|---|---|---|
| 信令 | MT8000A 协议栈 | 慢 | 吞吐、SA/NSA、切换、CA |
| 非信令 | DUT 测试态 | 快 | 射频指标、产线 |
| 波形 | 仪表播放 | 快 | 干扰/阻塞场景 |

## 2. 端口与参考

| 项 | 说明 | 注意 |
|---|---|---|
| RF 端口 | 多路 TX/RX，支持 MIMO/CA | 端口数与 MIMO 能力看配置 |
| 参考时钟 | 10 MHz in/out | 多仪表共用参考 |
| 触发 | Trigger in/out | 帧/时隙对齐 |
| LAN/GPIB/USB | 远程控制 | 优先 LAN，确认 VISA 资源 |
| 毫米波 | 通常外接变频/OTA 暗室 | 按方案校准 |
| SIM | 内置 SIM/插卡 | 参数错会导致注册失败 |

端口路径损耗逐口校准；MIMO 测试要确认每路幅度/相位一致性。

## 3. 能力与选件

| 维度 | 内容 | 怎么确认 |
|---|---|---|
| 制式 | 5G NR SA/NSA、LTE | 选件 + 建链 |
| 带宽 | NR 带宽按选件（常见 100 MHz 量级） | 选件表 |
| MIMO | 下行 4×4、上行 2×2 量级 | 端口/选件 |
| CA | 多载波聚合，组合按选件 | 选件表 |
| 毫米波 | 外接变频/OTA | 硬件清单 |
| 衰落 | 信道模拟选件 | 选件表 |
| 自动化 | SCPI/驱动/软件 | 版本说明 |

选件确认用前面板或远程查询；**端口存在不代表带宽/MIMO/CA 已授权**。

## 4. 信令测试流程

1. 配小区：band、SCS、带宽、PCI、PLMN、功率。
2. 配 SIM/UE：IMSI、Ki/OPc、APN、UE 能力。
3. DUT 注册，确认 RRC/承载建立。
4. 配业务：吞吐、Ping、VoNR（按需）。
5. 跑指标：MOP、ACLR、EVM、REFSENS、吞吐、EN-DC/CA。
6. 存证：小区配置、UE 能力、吞吐、功率、日志。

建链失败先查：band/SCS 支持、SIM 参数、APN、NR 开关、选件、射频端口。

## 5. 非信令与射频指标

- 非信令由 DUT 测试态发波形，仪表测量；速度快，适合产线/回归。
- ACLR/SEM/杂散等对分析带宽/动态范围要求高的项，可能需要外接频谱仪。
- EVM 结果受解调配置影响；记录测量带宽、均衡、相位跟踪设置。
- 路径损耗、参考电平、触发按 [测量基础与校准](<../02 测试指标/01 测量基础与校准.md>) 处理。

## 6. 毫米波与 OTA

- 毫米波通常要外接上/下变频、探头/暗室；MT8000A 本体不一定直接覆盖 28/39 GHz。
- OTA 校准暗室损耗、探头增益、极化/方位；EIRP/EIS 与传导口径不同。
- 波束对准、阵列增益、位置误差影响大，测试时间更长。

## 7. 自动化接入

- 优先 LAN；确认端口、防火墙、VISA/驱动版本。
- 封装语义 API：配小区、等注册、跑吞吐、读结果；测试层不拼 SCPI。
- 记录机型、固件、选件、端口、路径损耗、小区配置、DUT 状态。
- 断链/超时保存现场，再重连；不要静默重试。

## 8. 限制与常见坑

| 限制/坑 | 说明 | 处理 |
|---|---|---|
| 不是频谱仪 | 频谱类动态范围/带宽有限 | 外接频谱仪 |
| 毫米波外设 | 变频/暗室/探头 | 按 OTA 方案校准 |
| 选件绑定 | 带宽/MIMO/CA 分开授权 | 查询选件 |
| 端口一致性 | 多端口幅度/相位差异 | 逐口校准/验证 |
| 固件差异 | 同型号不同版本行为不同 | 固定版本并记录 |
| 信令慢 | 建链/状态迁移耗时 | 非信令做射频 |
