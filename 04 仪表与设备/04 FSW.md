# R&S FSW 信号与频谱分析仪

> 定位：高端信号与频谱分析仪，研发与认证预扫的主力。除了看频谱，它还能当矢量信号分析仪、相噪仪、噪声系数仪、脉冲分析仪用——取决于装了哪些选件。
> 边界：本文只讲 FSW 这台机器怎么用、怎么设置、哪里踩坑。频谱测量的通用设置（参考电平、RBW、平均、检波器）见 [测量基础与校准](<../02 测试指标/01 测量基础与校准.md>) 与 [频谱类指标](<../02 测试指标/03 频谱类指标.md>)。
> 指标数字均为量级参考，具体以机型标签、选件表与数据表为准。

## 1. 它能回答什么

| 问题 | 用什么看 | 对应指标 |
|---|---|---|
| 带外漏多少、漏成什么形状 | 扫频 + SEM / ACLR 测量 | SEM、ACLR、OBW |
| 杂散、谐波、互调在哪 | 宽扫 + 分段扫 | 杂散发射、发射互调 |
| 信号本身失不失真 | 解调选件（VSA） | EVM、频率误差、IQ 不平衡 |
| 本振干不干净 | 相噪选件 | 相位噪声 |
| 接收机底噪多低 | 噪声系数选件 + 噪声源 | 噪声系数 |
| 包络、脉冲、瞬态 | 零跨度 / 脉冲选件 | 时域包络、脉宽、占空比 |

FSW 与本库的关系：**它是「读数的来源」**，判定标准和限值在 [测试指标索引](<../02 测试指标/00 测试指标索引.md>) 与 3GPP 原文里。仪表再准，也替代不了参考平面和不确定度的讨论。

## 2. 架构：为什么看指标要看前端

超外差前端（衰减器 → 预放 → 混频 → 中频放大 → ADC → FFT/检波）决定三件事：

- **能测多小的信号**：显示平均噪声电平（DANL），受前端与预放限制。
- **能扛多大的信号**：1 dB 压缩点、三阶截点（TOI），决定大信号下测带外会不会自产物。
- **能看多宽的信号**：分析带宽由中频与数字化链路决定，是选件，不是软件开关。

| 项 | 量级参考（1 GHz 附近，具体以数据表为准） | 影响 |
|---|---|---|
| DANL | 约 −150 ~ −160 dBm/Hz，开预放更低 | 能否测到小杂散、邻道底噪 |
| TOI | 约 +20 ~ +25 dBm 量级 | 大信号下的互调与 ACLR 可信度 |
| 1 dB 压缩 | 约 +10 dBm 量级 | 参考电平设太高会压缩 |
| 相噪 | 约 −135 ~ −140 dBc/Hz @ 10 kHz 偏移 | EVM 下限、近端邻道 |
| 频率上限 | 按机型：13.6 / 26.5 / 43.5 / 50 / 67 / 85 GHz 等档 | 能否覆盖谐波与规范要求的杂散频段 |

## 3. 主要工作模式

| 模式 | 干什么 | 什么时候用 |
|---|---|---|
| 扫频（Sweep） | 频谱、SEM、杂散 | 最常用，快且直观 |
| 零跨度（Zero Span） | 时域功率包络 | 看 burst、开关瞬态、门控测量 |
| IQ 分析 | 采宽带 IQ，后处理 | 信号超出解调选件能力、需要自定义分析 |
| 多标准（MSRA） | 一路信号同时做功率与解调 | 认证预扫、边测边解调 |
| 解调选件 | LTE / NR / WLAN 等的 EVM 与星座 | 调制质量、与综测仪交叉验证 |
| 相噪选件 | 单边带相位噪声 vs 偏移 | 本振评估、EVM 归因 |
| 噪声系数选件 | Y 因子法测 NF | 接收链路、LNA 评估 |
| 脉冲选件 | 脉宽、周期、占空比、峰值功率 | 雷达/脉冲体制、TDD 瞬态 |

分析带宽是分档的（常见 160 MHz 起，选件到 500 MHz / 1 GHz / 2 GHz 量级）。**NR 单载波 100 MHz 至少要 160 MHz 档**；要做 CA 或宽带信号直接采 IQ，就得往上买。

## 4. 常用测量怎么设

### 4.1 SEM / ACLR / OBW

1. 中心频率对准载波，跨度覆盖到最远的偏移点。
2. 参考电平按峰值留 5–10 dB 余量：太低会压缩，太高会抬底噪。
3. 打开对应的测量功能（SEM/ACLR），让仪表用标准内的信道滤波器与偏移定义，别自己摆 marker 凑。
4. 平均次数按限值余量定：余量小就多平均，别用单次扫频下结论。
5. 若 DUT 是 TDD 或 burst，开**门控扫频**或触发同步，否则测到的是开关瞬态。

### 4.2 杂散与谐波

- 分段扫：先宽扫找可疑点，再窄扫（小 RBW）+ 预放确认。
- 判「是不是 DUT 的」：断开 DUT 看是否还在、换频点看是否跟着走、加衰减看是否线性变化。
- 最容易误判的是**仪表自身产物**：混频谐波、本振泄漏、电源与时钟的杂散。认证预扫前先扫一遍空载。

### 4.3 相噪

- 载波功率先校准（相噪是相对值，载波读数错就全错）。
- 偏移范围与 RBW% 决定近端分辨力；远端看噪声底是否被仪表底噪限制。
- 参考源本身的相噪是下限，别用「相噪差的源」去验「相噪好的 DUT」。

### 4.4 EVM（解调选件）

- 解调带宽、均衡方式、同步方式要与综测仪口径一致，否则两台机器的 EVM 差 1–2 dB 很正常。
- 参考电平同样要留余量；压缩会让 EVM 假性变好或变差，取决于失真类型。
- 结论要写清「用什么仪表、什么选件、什么解调设置」，否则不可比。

## 5. SCPI 骨架

```python
import pyvisa

rm = pyvisa.ResourceManager()
sa = rm.open_resource("TCPIP0::192.0.2.20::inst0::INSTR")
sa.timeout = 30_000

sa.write("*RST")
sa.write("FREQ:CENT 1.95e9")
sa.write("FREQ:SPAN 100e6")
sa.write("BAND:RES 100e3")            # RBW
sa.write("BAND:VID 300e3")            # VBW
sa.write("DISP:TRAC:Y:RLEV 0")        # 参考电平，按峰值留余量
sa.write("INIT:CONT OFF")
sa.write("AVER:COUN 20")
sa.write("INIT:IMM")
sa.query("*OPC?")                      # 等扫描结束
sa.write("CALC:MARK1:MAX")             # 峰值搜索
print(sa.query("CALC:MARK1:Y?").strip())
print(sa.query("SYST:ERR?").strip())
```

要点：

- **先 `INIT:CONT OFF` 再单次扫**，否则读到的是上一次扫描的残留。
- `*OPC?` 只表示命令执行完与扫描结束，不代表平均收敛；平均类测量要查测量状态。
- 大跨度 + 小 RBW 的扫描时间会很长（`SWE:TIME` 可看/可设），脚本超时要按最坏情况给。
- 解调类测量（EVM、SEM）用仪表的测量功能而不是自己写 marker 逻辑，口径才和规范一致。

## 6. 十个坑

1. **参考电平不当**：过高抬底噪、过低压缩，读数两头都不对。
2. **RBW / VBW / 检波器混用**：同一信号三个读数，先统一口径再比。
3. **平均不足就下结论**：贴着限值时，单次扫频没有判据价值。
4. **扫速超过中频建立时间**：幅度偏低、频率偏移，尤其大跨度小 RBW。
5. **把仪表自产物当 DUT 杂散**：断开 DUT / 换频点 / 加衰减三条验证。
6. **相噪没归一**：dBc/Hz 与 dBc 混用，差一个 RBW 的账。
7. **IQ 记录太短**：抓不到完整帧或突发，后处理才发现。
8. **参考时钟没接**：频率误差与相噪都会「看起来很差」。
9. **与综测仪 EVM 口径不同**：均衡、同步、带宽不同，差 1–2 dB 属正常，别直接判 DUT 坏。
10. **温度与校准过期**：整批同向偏移，先查证书与环境，再查 DUT。

## 7. 选型与验收

- [ ] 频率上限覆盖目标 band 的谐波与规范要求的杂散频段。
- [ ] 分析带宽 ≥ 被测信号带宽（NR 100 MHz 起，CA 更大）。
- [ ] DANL 与 TOI 能同时满足「小信号测得到、大信号不失真」。
- [ ] 相噪能否支撑你的 EVM 目标（先算预算，再选件）。
- [ ] 需要的测量功能是不是选件：SEM/ACLR、解调、相噪、NF、脉冲、EMI 检波器。
- [ ] 前置放大器、外部参考、IQ 输出（流盘）是否配套。
- [ ] 校准周期与证书；校准件、线缆、转接头单独管。
- [ ] 与现有自动化栈的接口：LAN + VXI-11/HiSLIP，SCPI 覆盖所需功能。
