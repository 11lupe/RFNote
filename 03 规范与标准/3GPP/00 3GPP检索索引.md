# 3GPP 规范库 · 检索索引

> 所属：[规范与标准索引](<../00 规范与标准索引.md>) ｜ 数据来源：3GPP 官方归档

> 用途：干射频自动化测试时，**任何一个测试项，都能在 3 秒内找到「怎么测」和「限值是多少」的原文位置**。
> 维护：本文件手写；`检索总表.csv` 与各规范目录下的 `章节索引.csv` 由 `tools/index_3gpp.py` 自动生成，行数与规范清单由 `tools/check_repo.py` 校验。
> 更新日期：2026-11-22（新增 WCDMA 四份规范）

## 一、先记住这五条对应关系

| 想知道… | 看哪个规范 |
|---|---|
| 这个指标**怎么测**（步骤、仪表设置、判定） | LTE → **36.521-1**；NR → **38.521-1**；WCDMA → **34.121-1**；GSM → **51.010-1** |
| 这个指标的**限值**是多少 | LTE → **36.101**；NR → **38.101-1**；WCDMA → **25.101**；NSA/EN-DC → **38.101-3** |
| 手机同时开 LTE+NR 时怎么测 | **38.521-3**（测试方法）+ **38.101-3**（限值） |
| 测试用哪个信道、什么环境、参考测量信道 RMC | LTE → **36.508**；NR → **38.508-1**；WCDMA → **34.108** |
| 这条用例我这台机器要不要测 | LTE → **36.521-2**（ICS 能力声明表） |

**一句话**：`.521` 系列是「怎么测」，`.101` 系列是「限值多少」。这两个永远成对出现。

> **WCDMA 是个例外，编号对不上**：它没有 25.521，测试方法在 **34.121-1**（`5.x` 发射机 / `6.x` 接收机 / `7.x` 解调性能 / `8.x` RRM），限值在 **25.101**（`6.x` 发射机 / `7.x` 接收机）。**同一条指标，两边章号差 1**（例：最大功率 = 34.121-1 的 5.2，但 25.101 的 6.2），查的时候别混。

### 4.4 NSA / EN-DC（限值 38.101-3 / 测试方法 38.521-3）

- **限值**：38.101-3 按「DC 组合」组织（`5.5 Configuration`、`6.3 Output power dynamics` 等），用 `检索总表.csv` 搜 `EN-DC` 定位到具体 band 组合。
- **测试方法**：38.521-3 `6.2 Transmitter power`、`6.3`、`6.4`、`6.5`、`7.x`；关键技术点在 `4.6~4.8`（E-UTRA anchor 配置），这是 NSA 测试和 SA 最大区别所在。

### 4.5 每个测试项的固定骨架（背下来，查文档提速 10 倍）

36.521-1 / 38.521-1 里每个测试项都长这样：

```
6.x.y     <指标名>
  6.x.y.1  Test purpose            测它干什么
  6.x.y.2  Test applicability      哪些 band/配置要测
  6.x.y.3  Minimum conformance requirements   3GPP 原始限值表
  6.x.y.4  Test description        测试步骤（仪表怎么配、样机怎么控）
  6.x.y.5  Test requirement        判定用限值（= 6.x.y.3 + 测试容差）
```

> 脚本里那些魔法数字，**八成来自 6.x.y.4 和 6.x.y.5**。对不上就翻这两节。

## 五、怎么检索（三种方法，按场景选）

**1）查「某个词在哪一章」—— 用总表**

Excel 打开 `检索总表.csv`（11412 行），A 列筛选规范、D 列搜索关键词。例如筛选「36.521-1」+ 搜索「Power」。

**2）命令行搜全文（最准，能搜到正文里的限值表）**

```bash
# 先按条款定位到文件（读总表），或者直接全文搜：
python - <<'PY'
import docx

path = "03 规范与标准/3GPP/36.521-1/docs/36521-1-j30_s06a-s06b4.docx"
for p in docx.Document(path).paragraphs:
    if "MPR" in p.text:
        print(p.text)
PY
```

> 需 `python-docx`（`pip install python-docx`）。路径相对仓库根目录，换机器不用改。

**3）想知道「这个测试项为什么被跳过」**

查 `36.521-2`（ICS 表）对应行，看 band 与特性组合是否声明支持。
