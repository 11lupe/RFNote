# 射频前端与天线

> 射频前端（RFFE）是基带到天线之间的最后一段模拟链路：发射把信号放大到空口，接收把微弱信号从噪声里捞出来，中间还要滤、切、配、双工。
> 本文给前端拓扑、各器件职责、关键指标与常见失效；链路预算的算法见 [噪声与链路预算](<04 噪声与链路预算.md>)，具体测量见 [测试指标](<../02 测试指标/00 测试指标索引.md>)。

## 1. 拓扑

```text
                    ┌── 天线 tuner ── 天线
                    │
   TX: 基带/收发机 ── PA ── 滤波器 ── 开关/双工器 ──┘
   RX: 基带/收发机 ── LNA ── 滤波器 ── 开关/双工器 ──┘
                    │
                    └── 耦合器/功率检测、SRS 切换
```

四个关键词：

- **放大**：PA 把 TX 抬到目标功率；LNA 把 RX 微弱信号抬到可解调。
- **滤波**：SAW/BAW/LC 滤掉带外、谐波、邻道，避免自己干扰别人、也避免被别人干扰。
- **切换**：开关/双工器在 band、TX/RX、天线之间选路；FDD 用双工器，TDD 用开关。
- **匹配**：天线 tuner/匹配网络把天线阻抗拉到 50 Ω，兼顾效率与带宽。

## 2. 发射链

| 器件 | 作用 | 关键指标 | 常见问题 |
|---|---|---|---|
| 收发机 DAC/混频 | 产生调制信号 | EVM、杂散、IQ 不平衡 | 镜像、LO 泄漏、DAC 非线性 |
| 驱动放大器 | 预放大 | 增益、线性度 | 压缩、谐波 |
| PA | 功率放大 | Pout、增益、效率、ACLR、EVM、谐波 | 饱和、热漂移、负载失配 |
| 滤波器 | 抑制谐波/杂散 | 插入损耗、抑制、功率容量 | 损耗大、带内纹波 |
| 开关/双工器 | 收发/band 切换 | 插入损耗、隔离、功率容量 | 隔离不足、切换损耗 |
| 耦合器 | 功率检测/闭环 | 耦合度、方向性 | 检测偏差、温漂 |
| 天线 tuner | 阻抗匹配 | 效率、带宽、线性度 | 失配、SAR 降功率 |

PA 是 TX 的核心矛盾：**效率 vs 线性**。效率高（省电、少发热）通常意味着更靠近压缩点，ACLR/EVM 变差；线性好则效率低。DPD/ET/APT 就是在这对矛盾里找平衡。

## 3. 接收链

| 器件 | 作用 | 关键指标 | 常见问题 |
|---|---|---|---|
| 天线/匹配 | 接收电磁波 | 效率、带宽、隔离 | 失配、手握、SAR |
| 开关/双工器 | 选路/双工 | 插入损耗、隔离 | 损耗直接吃灵敏度 |
| 滤波器 | 抑制带外/邻道 | 插入损耗、抑制、群时延 | 边沿陡、温漂 |
| LNA | 低噪声放大 | NF、增益、IIP3、稳定性 | 增益压缩、阻塞、失稳 |
| 混频器/ADC | 下变频/采样 | NF、IIP3、时钟相噪 | 镜像、采样时钟杂散 |

接收链的噪声系数近似 Friis：

```text
NF_total = NF1 + (NF2−1)/G1 + (NF3−1)/(G1G2) + ...
```

第一级 LNA 的 NF 和增益决定整机灵敏度；滤波器插在 LNA 前面会直接增加 NF，所以「滤波器抑制」与「灵敏度」要折中。

## 4. 双工、切换与共存

- **FDD**：TX/RX 同时工作，双工器靠频率隔离；TX 泄漏会 desense RX。
- **TDD**：TX/RX 分时，开关切换；切换时间、隔离、瞬态会影响 EVM/ACLR。
- **CA/EN-DC**：多载波同时收发，互调、谐波、ACLR 会落到别的 band；前端要按组合设计。
- **SRS 切换**：多天线发射探测，开关/走线要一致，否则基站侧波束赋形会偏。
- **共存**：Wi-Fi/BT/GNSS/充电/摄像头与蜂窝共享天线/电源/地，desense 往往来自这里，不是 3GPP 指标本身。

## 5. 天线

| 维度 | 说明 | 影响 |
|---|---|---|
| 效率 | 辐射功率/输入功率 | 直接决定 EIRP 与 EIS |
| 带宽 | 覆盖 band 的驻波/效率 | 低频难做宽，调谐受限 |
| 隔离 | 多天线之间耦合 | MIMO 相关、TX 泄漏、desense |
| 极化 | 与基站/暗室探头匹配 | OTA 测量与现网性能 |
| SAR | 人体吸收限制 | 降功率，影响最大发射 |
| 调谐 | tuner/开关/匹配 | 手握、频段、模式切换 |

天线不是「无源件就不出问题」：手握、壳体、金属边框、电池、屏蔽罩都会改变阻抗与效率；OTA 与传导结果差异，常常就是天线/壳体带来的。

## 6. 测试点

| 测试点 | 能测什么 | 注意 |
|---|---|---|
| 天线口（传导） | 前端到端口的功率/灵敏度 | 需要夹具/探针，参考平面清楚 |
| 耦合板/暗室 | 整机 EIRP/EIS | 校准暗室损耗与位置 |
| 耦合器检测口 | 功率检测/闭环 | 耦合度与方向性要校 |
| 电源/地 | 噪声、desense | 探头/近场扫描，注意安全 |

## 7. 常见失效

| 现象 | 前端根因 | 验证 |
|---|---|---|
| 最大功率不足 | PA 压缩/负载失配/供电跌落 | 查 PA 输入、负载拉移、电压 |
| ACLR 差 | PA 线性度/DPD/滤波器 | 降功率看是否改善；查 DPD 配置 |
| EVM 差 | PA 压缩/LO 相噪/IQ 失配 | 分段测收发机 vs 前端 |
| 灵敏度差 | LNA NF/滤波器损耗/开关损耗 | 查第一级 NF、旁路、匹配 |
| 某 band 差 | 滤波器边沿/匹配/tuner | 对比同平台、查 S 参数 |
| TX 时 RX desense | 双工器隔离/PA 谐波/地耦合 | 关 TX/换信道/加滤波 |
| OTA 差 | 天线效率/失配/手握 | 对比传导、暗室扫方位 |
