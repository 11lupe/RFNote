# 噪声与链路预算

> 链路预算回答两个问题：**最远/最差能工作到哪**，以及**每一段损耗/增益怎么分配**。它把发射功率、天线增益、路径损耗、噪声系数、解调门限和各项余量折成一个 dB 账本。
> 前端器件与拓扑见 [射频前端与天线](<03 射频前端与天线.md>)；测量方法见 [接收类指标](<../02 测试指标/05 接收类指标.md>)。

## 1. 先统一单位

| 量 | 单位 | 说明 |
|---|---|---|
| 功率 | dBm | 相对 1 mW；`0 dBm = 1 mW`，`30 dBm = 1 W` |
| 增益/损耗 | dB | 相乘变相加；`+3 dB = ×2`，`−3 dB = ÷2` |
| 功率谱密度 | dBm/Hz | 噪声底常用 |
| 场强 | dBμV/m | OTA/EMC 用，和 dBm 换算要看天线因子 |

链路预算只做加减法；错误通常不是公式，而是**漏项/重复计**：线损算两次、天线增益方向搞反、把 dB 当 dBm。

## 2. 噪声底

电阻热噪声：

```text
N0 = kTB
k = 1.38×10^-23 J/K
T = 290 K
N0(dBm/Hz) = −174 dBm/Hz
```

接收机噪声底：

```text
N(dBm) = −174 + 10log10(B) + NF
```

示例：带宽 20 MHz、NF = 7 dB：

```text
10log10(20×10^6) ≈ 73 dB
N = −174 + 73 + 7 = −94 dBm
```

这就是「20 MHz 带宽、NF 7 dB 时，噪声底大约 −94 dBm」的来历。带宽翻倍，噪声底 +3 dB；NF 每降 1 dB，灵敏度理论上好 1 dB。

## 3. 灵敏度

数字通信的灵敏度不是「噪声底」，而是「噪声底 + 解调所需 SNR」：

```text
Sensitivity(dBm) = −174 + 10log10(B) + NF + SNR_req + Margin
```

| 项 | 含义 | 典型来源 |
|---|---|---|
| B | 占用带宽 | 制式/配置 |
| NF | 接收机噪声系数 | LNA/滤波器/开关/线损 |
| SNR_req | 达到目标误块率/吞吐所需 SNR | 调制/MCS/编码/算法 |
| Margin | 实现/老化/温漂余量 | 设计约定，不是规范值 |

注意：

- 3GPP 的 REFSENS 是**测试条件+吞吐判据**，不是这条公式的直接输出；公式用来做设计预估和归因。
- 高阶调制（256QAM）需要更高 SNR，灵敏度会变差；低阶/重复编码可以更低。
- 接收分集/MIMO 有阵列/合并增益，但会受相关性和天线效率影响。

## 4. 链路预算方程

单向链路：

```text
Prx = Ptx + Gtx − Lpath + Grx − Lrx
```

| 符号 | 含义 | 注意 |
|---|---|---|
| Ptx | 发射功率（含 PA 输出/天线口） | 传导/OTA 口径要统一 |
| Gtx | 发射天线增益 | 含方向/极化；dBi |
| Lpath | 路径损耗 | 自由空间/模型/实测 |
| Grx | 接收天线增益 | 与来波方向/极化匹配 |
| Lrx | 接收端线损/滤波/开关 | 进 LNA 之前都算 |

判决：

```text
Prx ≥ Sensitivity + Margin
```

余量 `Margin` 覆盖：人体/手握、壳体、建筑穿透、雨衰、干扰、老化、角度失配。

## 5. 自由空间路径损耗

```text
FSPL(dB) = 32.45 + 20log10(f_MHz) + 20log10(d_km)
```

示例：2.6 GHz、1 km：

```text
32.45 + 20log10(2600) + 0 = 32.45 + 68.3 ≈ 100.8 dB
```

自由空间只适合视距/卫星/短距参考；地面/室内要用对应模型（Okumura-Hata、COST 231、ITU-R P.1238 等），并留模型误差余量。

## 6. 一张示例账本

假设：Band n78、3.5 GHz、100 MHz、PA 输出 23 dBm、TX 天线增益 0 dBi、RX 天线增益 0 dBi、接收 NF 7 dB、所需 SNR 0 dB、余量 10 dB。

| 项 | 值 | 说明 |
|---|---|---|
| TX 功率 | +23 dBm | 天线口 |
| TX 线损/滤波 | −2 dB | 例 |
| TX 天线增益 | 0 dBi | 例 |
| 路径损耗（1 km，FSPL） | −108 dB | 3.5 GHz 示例 |
| RX 天线增益 | 0 dBi | 例 |
| RX 线损/滤波 | −2 dB | 例 |
| 到达接收机 | −89 dBm | 23−2−108−2 |
| 噪声底（100 MHz，NF 7） | −87 dBm | −174+80+7 |
| 所需 SNR | 0 dB | 例 |
| 灵敏度 | −87 dBm | 噪声底+SNR |
| 余量 | −2 dB | −89−(−87) = −2，不足 |

这个例子说明：**高频宽带宽下，23 dBm 也可能不够 1 km**；实际要靠天线增益、波束赋形、更近站点或更低 MCS。数字只是演示，不是现网预算。

## 7. 上行与下行

- 下行：基站大功率 → 手机接收，通常不是瓶颈（覆盖受上行限制）。
- 上行：手机小功率 → 基站接收，手机发射能力和基站灵敏度决定覆盖。
- 链路平衡：上下行余量差太多时，要么降功率/调天馈，要么靠小区规划；手机侧改不了基站。
- 最大耦合损耗（MCL）：OTA 里常用的指标，等于「发射 EIRP − 接收灵敏度」允许的总损耗，用来比较整机能力。

## 8. 余量怎么留

| 余量 | 典型考虑 | 注意 |
|---|---|---|
| 人体/手握 | 手、头、壳体吸收 | 与持握方式强相关 |
| 建筑穿透 | 墙体/玻璃/楼层 | 室内分布另算 |
| 雨衰/植被 | 高频/室外 | 3.5 GHz 以上更明显 |
| 干扰 | 邻区/共存 | 不能只用热噪声 |
| 老化/温漂 | PA/滤波器/天线 | 量产一致性 |
| 极化/角度 | 天线失配 | OTA 方位扫描 |

余量不是越大越好：留太多会过度设计（成本/功耗），留太少会现场掉话。按产品定位、频段、场景定。

## 9. 常见错误

| 错误 | 后果 | 修正 |
|---|---|---|
| dB 与 dBm 混用 | 结果差几十 dB | 功率用 dBm，比值用 dB |
| 线损重复计 | 灵敏度预估过差 | 画清楚参考平面，只算一次 |
| 天线增益方向反 | 预算偏乐观/悲观 | 确认 dBi 与来波方向 |
| 忽略带宽 | 宽带灵敏度算错 | 噪声底随 10logB 变 |
| 用 FSPL 算室内 | 覆盖预估过于乐观 | 换室内模型 + 穿透余量 |
| 只算下行 | 误判覆盖 | 上下行都算，取瓶颈 |
