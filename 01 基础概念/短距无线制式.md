# 短距无线制式

> 定位：手机射频里 3GPP 之外的"另一半"——Wi-Fi、蓝牙、星闪。**同一条射频链、同一套指标语言，但是另一套标准体系、另一套测试维度。**
> 分工：蜂窝制式与代际演进读 [射频基础知识](射频基础知识.md)；指标怎么判定读 [02 测试指标](<../02 测试指标/00 测试指标索引.md>)；本文只讲短距怎么组测试。
> 限值：文中数字都是**量级参考**，判定以规范原文表格 + 平台/客户配置为准；短距的规范原文本库暂未收录，只给入口。

## 1. 为什么单列

先回答"是不是射频"：**是**。[射频基础知识 §1](射频基础知识.md) 那条链（BB → TRX → PA → 滤波/开关 → 天线）原样适用，TX/RX 指标也几乎一一对应：

| 蜂窝的叫法 | 短距的叫法 | 是否同一件事 |
|---|---|---|
| 最大输出功率 / 功率控制 | 输出功率 / 功率等级 / 功率控制 | 是 |
| EVM | EVM（逐 MCS 或逐调制） | 是 |
| SEM（频谱发射模板） | 频谱模板（dBr 拐点） | 是，但判据形式不同 |
| ACLR | 邻道功率（ACP，蓝牙）/ 模板（Wi-Fi） | 概念同、测法不同 |
| 参考灵敏度 | 接收灵敏度（per MCS / per PHY） | 是 |
| 杂散 / 谐波 | 杂散 / 谐波（受法规约束更多） | 是 |

但**不能并进 GSM→WCDMA→LTE→NR 那条链**，原因有三：

1. **标准组织不同**。蜂窝是 3GPP 的 `TS xx.101 / xx.521` 体系；Wi-Fi 是 IEEE 802.11，蓝牙是 Bluetooth SIG 的 Core Spec + RF.TS，星闪是国标 GB/T 48336 系列。规范号、条款结构、测试项编号全不通用。
2. **不是代际演进**。[射频基础知识 §5](射频基础知识.md) 那张表的列是"这一代在补上一代的什么短板"，Wi-Fi 不是 LTE 的补丁，星闪也不是 NR 的演进，硬填进去这张表就失去解释力了。
3. **测试维度换了**。蜂窝按 `band × 带宽 × RB × 调制` 组矩阵；短距按 `信道 × 带宽 × MCS/PHY × 天线流数` 组，再叠一个蜂窝没有的维度：**共存**。

> 一句话：**同一条射频链，不同的频谱规则**。蜂窝在授权频谱里和"网内"打架，短距在免许可频谱里和"所有人"打架。

## 2. 三家对照

| 项目 | Wi-Fi | 蓝牙 | 星闪（SparkLink） |
|---|---|---|---|
| 标准组织 | IEEE 802.11 + Wi-Fi Alliance 认证 | Bluetooth SIG | 国际星闪联盟 → 国标 GB/T 48336 系列 |
| 频段 | 2.4 / 5 / 6 GHz（60 GHz 另有 11ad/ay） | 2.4 GHz ISM | 2.4 GHz ISM |
| 信道 | 信道号（2.4G 的 1–13；5G 的 36–165） | 79 × 1 MHz（BR/EDR）/ 40 × 2 MHz（LE） | 联盟/国标定义，按 SLB、SLE 分别规定 |
| 带宽 | 20 / 40 / 80 / 160 / 320 MHz | 1 MHz / 2 MHz（LE Coded 更窄） | SLB 单载波 20 MHz；SLE 1/2/4 MHz |
| 接入 | CSMA/CA，TDD | 跳频 + TDD 时隙 | SLB 同步调度；SLE 同步低功耗 |
| 调制 | OFDM/OFDMA，BPSK–4096QAM | GFSK（BR/LE）、π/4-DQPSK、8DPSK（EDR） | SLB 为 OFDM/1024QAM 级；SLE 为 GFSK/8PSK |
| 峰值速率（量级） | 11b 11 Mbps → 11be 数十 Gbps | 1–3 Mbps（BR/EDR）、1–2 Mbps（LE） | SLB 千兆级；SLE 十兆级 |
| 功率量级 | 传导 15–20 dBm，法规按 EIRP 限 | Class 1/1.5/2/3 = 20/10/4/0 dBm | 以国标/法规为准 |
| 认证 | Wi-Fi CERTIFIED + SRRC/CE/FCC | Bluetooth Qualification + SRRC/CE/FCC | 国标 + SRRC |

> 读法：**横向看组织与规范，纵向看"我怎么组测试"**。三家共同点是免许可 + TDD + 突发，这三条决定了后面所有的测法差异。

## 3. Wi-Fi（IEEE 802.11）

### 3.1 代际与 PHY

| 代际 | 标准 | 频段 | 带宽 | 最高调制 | 峰值（量级） | 关键新东西 |
|---|---|---|---|---|---|---|
| — | 802.11b | 2.4 GHz | 20 MHz | DSSS/CCK | 11 Mbps | 直扩，抗窄带干扰 |
| — | 802.11a/g | 5 / 2.4 GHz | 20 MHz | 64QAM | 54 Mbps | OFDM（52 子载波，SCS 312.5 kHz） |
| Wi-Fi 4 | 802.11n | 2.4/5 GHz | 20/40 MHz | 64QAM | 600 Mbps | MIMO（最多 4 流） |
| Wi-Fi 5 | 802.11ac | 5 GHz | 20–160 MHz | 256QAM | 6.9 Gbps | 8 流、下行 MU-MIMO |
| Wi-Fi 6 / 6E | 802.11ax | 2.4/5/6 GHz | 20–160 MHz | 1024QAM | 9.6 Gbps | OFDMA（RU）、TWT、上下行 MU-MIMO |
| Wi-Fi 7 | 802.11be | 2.4/5/6 GHz | 20–320 MHz | 4096QAM | 数十 Gbps | MLO 多链路、16 流 |
| — | 802.11ad/ay | 60 GHz | 2.16 GHz | — | 7 / 100 Gbps | 毫米波短距 |

两条容易忽略的：

- **SCS 变过**：11a/n/ac 是 312.5 kHz（符号 3.2 µs + GI 0.8 µs），11ax/be 是 78.125 kHz（符号 12.8 µs，GI 0.8/1.6/3.2 µs）。带宽不变、SCS 变，仪表解调配置必须跟着选。
- **11b 不是 OFDM**：它是 DSSS/CCK，频谱模板、EVM 定义（用峰值 EVM）都和 OFDM 模式不同，测试时要单独一套配置。

### 3.2 信道与频段

| 频段 | 范围 | 信道 | 注意 |
|---|---|---|---|
| 2.4 GHz | 2400–2483.5 MHz | 1–13（14 仅日本） | 5 MHz 间隔，只有 1/6/11 互不重叠 |
| 5 GHz | 5150–5850 MHz | 36–165 | U-NII-1/2A/2C/3 四段；52–144 需 DFS |
| 6 GHz | 5925–7125 MHz | 1–233 | Wi-Fi 6E/7，国内开放情况以法规为准 |
| 60 GHz | 57–71 GHz | — | 802.11ad/ay，只做短距高速 |

> 测试上最容易翻车的是 **5 GHz 带边信道**：靠近 U-NII 段边界时，滤波器滚降 + 法规限值同时收紧。低/中/高信道各选一个还不够，带边要单独补点。

### 3.3 发射侧测什么

| 指标 | 测什么 | 入口（条款号以 802.11-2020 原文为准） |
|---|---|---|
| 最大输出功率 | 各带宽/速率下的功率上限与容差 | Clause 17（OFDM PHY）/ Clause 27（HE PHY）发射机指标 |
| 功率谱密度 | 每 MHz 功率，2.4 GHz 法规常卡这一项 | 同上 + 各国法规 |
| 频谱模板 | **dBr 拐点**（相对载波功率的衰减），不是邻道比 | 各 PHY 的 Transmit spectrum mask |
| EVM | **逐 MCS** 给门限，高阶调制最紧 | 各 PHY 的 Transmit modulation accuracy |
| 中心频率误差 | ppm/Hz | 同上 |
| 载波泄漏 / LO 泄漏 | 零中频本振泄漏，落在 DC 子载波 | 同上（Center frequency leakage） |
| IQ 不平衡 | 镜像抑制 | 同上 |

EVM 的量级（只为建立直觉，**判定看原文表**）：BPSK −5 dB、QPSK −10～−13 dB、16QAM −16～−19 dB、64QAM −19～−27 dB、256QAM −30～−32 dB、1024QAM −35 dB、4096QAM −38 dB。规律和蜂窝一样：阶数越高越紧，紧到 PA 线性度与相位噪声都吃不住。

### 3.4 接收侧测什么

| 指标 | 测什么 |
|---|---|
| 灵敏度 | 指定 MCS/带宽下、指定误包率（常见 10%）的最小接收功率 |
| 邻道抑制 | 邻道有强信号时的接收能力 |
| 阻塞 / 杂散响应 | 带外强信号、镜像频点的抗扰 |
| 最大输入电平 | 近距强信号不饱和 |
| RSSI 精度 | 上报功率误差（影响速率自适应与漫游） |

### 3.5 矩阵怎么组

| 维 | 取值 | 为什么这么选 |
|---|---|---|
| 信道 | 2.4G 的 1/6/11；5G 低/中/高 + 一个带边 | 带边最容易掉功率、超模板 |
| 带宽 | 20/40/80/160（+320 仅 Wi-Fi 7） | 宽带看 PAPR 与滤波器滚降 |
| MCS | 最低档 + 最高档各一 | 最低档测功率能力，最高档测 EVM 余量 |
| 天线 | 单流 vs 多流、逐链 | MIMO 各链独立校准，不能只测一根 |
| 模式 | 11b/g/n/ac/ax 各跑一遍 | 老模式兼容性是"回归项"，最容易被漏 |

### 3.6 仪表与方法

- **信令**：AP 模拟器（如 CMW270、MT8862A、IQxel 系列）——认证、互操作、吞吐相关项走这条。
- **非信令**：矢量信号源回放波形 + 频谱仪/VSA 解调，或综测仪的 WLAN 测量选件——产线校准、快速回归走这条，速度快、不需要关联流程。
- 仪表生态与选型见 [射频常用仪表](<../04 仪表与设备/01 射频常用仪表.md>)。

## 4. 蓝牙（Bluetooth SIG）

> 最大的一口坑：**BR/EDR 和 LE 是两套物理层、两套测试规范**，同一颗芯片两种模式都要过，但测试项、信道、带宽全不同。

### 4.1 BR/EDR 与 LE

| 项目 | BR/EDR（经典） | LE（低功耗） |
|---|---|---|
| 信道 | 79 × 1 MHz（2402–2480 MHz） | 40 × 2 MHz；广播信道 37/38/39 |
| 跳频 | 1600 hop/s，时隙 625 µs | 数据信道自适应跳频 |
| 调制 | GFSK（BR）、π/4-DQPSK / 8DPSK（EDR） | GFSK（LE 1M / LE 2M）、LE Coded |
| 速率 | 1 / 2 / 3 Mbps | 1 / 2 Mbps；Coded 500 / 125 kbps |
| 典型用途 | 音频、传统外设 | 可穿戴、传感器、IoT |

### 4.2 发射侧（TRM/CA 系列）

| 测试项 | 内容 |
|---|---|
| TRM/CA/01/C | 输出功率 |
| TRM/CA/02/C | 功率密度 |
| TRM/CA/03/C | 功率控制 |
| TRM/CA/05/C | 20 dB 带宽 |
| TRM/CA/06/C | 邻道功率（ACP） |
| TRM/CA/07/C | 调制特性（Δf1avg / Δf2max，GFSK 的"频偏够不够"） |
| TRM/CA/08/C | 载波频率漂移 |
| TRM/CA/09/C | 载波频率偏移 |
| TRM/CA/10/C | EDR 的 EVM / 频率稳定度 |

### 4.3 接收侧（RCT/CA 系列）

| 测试项 | 内容 |
|---|---|
| RCT/CA/01/C | 灵敏度（BER 0.1% 量级） |
| RCT/CA/02/C | 载干比 C/I |
| RCT/CA/03/C | 阻塞 |
| RCT/CA/04/C | 互调 |
| RCT/CA/05/C | 最大输入电平 |

> 编号以 RF.TS（BR/EDR）与 RF-PHY.TS（LE）原文为准：规范改版时编号会增删，**别把编号当永久契约**，用编号定位章节、用章节确认限值。

### 4.4 功率等级

| 等级 | 最大输出 | 典型用途 |
|---|---|---|
| Class 1 | 20 dBm（100 mW） | 远距（USB dongle、车载） |
| Class 1.5 | 10 dBm | 中间档 |
| Class 2 | 4 dBm（2.5 mW） | 手机、耳机最常见 |
| Class 3 | 0 dBm（1 mW） | 极短距 |

### 4.5 仪表与方法

- **非信令（DTM）**：芯片进测试模式，综测仪逐信道/逐功率发命令——产线与研发主力。
- **信令**：CMW270、MT8852B 一类蓝牙综测仪，跑连接态测试与协议相关项。
- LE 还要特别看 **广播信道 37/38/39**：它们刻意错开 Wi-Fi 的 1/6/11，测共存时这三条是重点。

## 5. 星闪（SparkLink）

### 5.1 标准现状

- 组织：**国际星闪联盟**（SparkLink Alliance，2020 年成立），标准原为联盟团体标准。
- 国标：**2026-09-28 发布《星闪无线通信系统》系列国家标准 GB/T 48336.101—2026 等，2027-04-01 实施**（发布/实施日期见[国家标准全文公开系统](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=23BF2EF5DD12DD1B8150A9ED0C566A81)）。
- 分册（量级）：`.101` 架构和通用要求；`.201` SLB 空口技术要求；`.202` SLB 设备技术要求和测试方法；`.203` 起为 SLE 相关。**具体分册号与范围以国标公告/全文为准。**

### 5.2 SLB 与 SLE

| 项目 | SLB（同步低时延宽带） | SLE（同步低功耗） |
|---|---|---|
| 对标 | Wi-Fi | BLE |
| 波形 | OFDM | GFSK（部分模式 8PSK） |
| 带宽 | 单载波 20 MHz，可聚合到 320 MHz | 1 / 2 / 4 MHz |
| 速率 | 千兆级 | 12 / 16 Mbps 量级 |
| 时延 | 空口单向 < 20.833 µs | 时隙 125 µs 量级 |
| 场景 | 高清投屏、无线 VR、工业 | 耳机、可穿戴、车钥匙 |

### 5.3 射频上关注什么

- **SLB 借 Wi-Fi 的经验**：OFDM + 高阶 QAM，指标就是功率、EVM（逐 MCS）、频谱模板、CFO；测量方法几乎照搬 11ax。
- **SLE 借 BLE 的经验**：GFSK 看调制特性（频偏）、载波漂移、ACP、灵敏度，测试项与 TRM/RCT 系列同构。
- **现状**：通用综测仪还没有成熟的星闪选件，实际做法是"矢量信号源回放波形 + VSA 解调"，或等仪表厂跟进；遇到了先按上面两条经验迁移，别等现成方案。
- 频段只有 2.4 GHz ISM，所以**共存压力和蓝牙完全一样**（见 §6）。

## 6. 共存：短距测试真正的难点

短距的 FAIL 有很大比例不是 DUT 坏了，是**被自己或邻居干扰**。四类：

| 场景 | 现象 | 怎么测 |
|---|---|---|
| 同芯片 TDM 共存 | WLAN 与 BT 共用天线/前端，一路工作时另一路灵敏度退化 | 两路同时工作，测灵敏度退化量（不是测绝对值） |
| 2.4 GHz 拥塞 | BT 跳频打到 Wi-Fi 信道；Wi-Fi 满功率压制 BT | 带内共存：对端加干扰源，扫频偏与功率 |
| 5 GHz DFS | 雷达误检 → 信道避让/掉线 | 灌雷达脉冲序列，看避让时间与恢复（这是"功能"不是"指标"，最容易被当成偶发） |
| 蜂窝 + WLAN | EN-DC/LAA 与 WLAN 的谐波、互调落点；WLAN 工作时 LTE 灵敏度退化 | 3GPP 的 in-device coexistence（IDC）思路：两制式同时在线，测退化 |

> 记住一条：**共存测试的判定量是"退化量"**（ΔSensitivity、ΔEVM），不是门限本身。所以基线必须先测干净——基线脏了，退化量全是噪声。

## 7. 常见误区

1. **在 Android 里找 WLAN/BT 的网络类型**：`TelephonyManager.NETWORK_TYPE_*` 只覆盖蜂窝（见 [射频基础知识 §10](射频基础知识.md)）。WLAN 走 `WifiManager`，BT 走 `BluetoothAdapter`，不存在"WIFI 的 RAT 枚举值"。
2. **拿 ACLR 套 Wi-Fi**：Wi-Fi 用的是 **dBr 频谱模板**（相对载波功率的拐点），积分区间和判据都不同；蓝牙才是 ACP（邻道功率）。三者别互套。
3. **把 band 当信道**：band 号是 3GPP 概念，短距是"信道号 + 带宽"，两者不能互推，也不能拿 B1/n78 的思维去推 Wi-Fi 信道规划。
4. **只看传导功率**：短距法规限值多数是 **EIRP**（含天线增益与方向性）。传导 18 dBm 合格，加上 3 dBi 天线可能就超了。
5. **EVM 用单一门限**：Wi-Fi 逐 MCS、蓝牙分 BR/EDR 与 LE，门限差好几个 dB；用蜂窝 3% 的习惯去判 1024QAM 必错。
6. **忽略突发与占空**：短距是突发业务，功率/频谱要用**门控（gated）测量**或正确触发，否则平均值被空闲期拉低，看起来"功率不够"。

## 8. 规范入口

| 系统 | 规范 | 查什么 |
|---|---|---|
| Wi-Fi | IEEE 802.11-2020（及 11ax/be 修订） | PHY 发射/接收指标、频谱模板、EVM 表 |
| Wi-Fi 认证 | Wi-Fi Alliance 测试计划 | 认证项与互操作 |
| 蓝牙 | Bluetooth Core Spec（Vol 2 Part A：BR/EDR Radio；Vol 6 Part A：LE Radio） | 射频要求 |
| 蓝牙测试 | RF.TS（BR/EDR）、RF-PHY.TS（LE） | 测试项编号与限值 |
| 星闪 | GB/T 48336.101 / 201 / 202 / 203—2026 | 架构、SLB/SLE 空口与设备测试方法 |
| 法规 | SRRC 型号核准、CE RED、FCC Part 15 | 功率/EIRP、杂散、DFS、占用时间 |

> 本库的规范库目前只收 3GPP（见 [规范与标准索引](<../03 规范与标准/00 规范与标准索引.md>)）。要收 IEEE / Bluetooth SIG / 星闪国标，按"新增标准组织"流程另建目录，别混进 3GPP。
