## 1. 射频是什么

**射频（RF）= 频率高到能以电磁波形式有效辐射的交流信号**，粗略覆盖 9 kHz–300 GHz。手机实际工作在两段：FR1（约 410 MHz–7.125 GHz）和 FR2（24.25–52.6 GHz，毫米波）。

一条完整的收发链路：

```
发射：基带(BB) → DAC → 调制/上变频 → PA → 滤波器 → 开关/双工器 → 天线
接收：天线 → 开关/双工器 → 滤波器 → LNA → 下变频 → ADC → 基带
```

| 环节 | 作用 | 测试关注点 |
|---|---|---|
| 基带 BB | 生成/解析数字信号 | 调制方式、RB 分配、编码 |
| 收发机 TRX | 上下变频、模数转换 | 频率误差、EVM、IQ 不平衡、载波泄漏 |
| PA / LNA | 发射放大 / 接收低噪放 | 最大功率、线性度（ACLR）、噪声系数 |
| 滤波器 | 抑制带外与杂散 | 插损、带外抑制、谐波 |
| 开关/双工器 | 收发切换、FDD 隔离 | 插损、隔离度 |
| 天线 | 电↔磁波转换 | 效率、方向图、TRP/TIS |

两种测法：

- **传导测试（Conducted）**：通过射频测试座/天线口直接连仪表，排除天线，测的是"电路本身"。
- **OTA 测试**：整机在暗室里辐射，测 TRP（总辐射功率）/TIS（总全向灵敏度），测的是"整机含天线的实际能力"。

> 一句话：射频测试就是**在规定的条件下，证明 TX 该发的功率/频谱/质量都发对了，RX 该收的弱信号收得到**。

## 2. 单位与常用量

| 单位 | 含义 | 例子 |
|---|---|---|
| dB | 两个功率的比值（10·lg） | 线损 3 dB = 功率减半 |
| dBm | 相对 1 mW 的绝对功率 | 23 dBm ≈ 200 mW |
| dBc | 相对载波的比值 | ACLR 用 dBc 表示邻道功率 |
| dBm/Hz | 功率谱密度 | 噪声底常用 |
| % / dB | EVM 两种表示 | EVM 3% ≈ −30 dB |
| ppm | 百万分之一，频率误差常按 ppm 算 | 2 GHz 上 1 ppm = 2 kHz |

功率换算（背下来能省很多事）：

| dBm | −10 | 0 | 10 | 20 | 23 | 30 | 33 | 43 |
|---|---|---|---|---|---|---|---|---|
| mW | 0.1 | 1 | 10 | 100 | ≈200 | 1000 | ≈2000 | 20000 |

两个关键概念：

- **dBm 相加减 = 功率相乘除**：23 dBm 经过 3 dB 线损 = 20 dBm。链路预算就是这么算的。
- **阻抗 50 Ω** 是射频系统的默认约定；VSWR 2:1 对应回波损耗约 9.5 dB，意思是约 11% 的功率被反射回来。

> 为什么线损必须先校准：仪表读数是在仪表端口，DUT 是在天线口，中间隔着线缆、接头、开关。不校准，你测的每一个数都偏，而且偏得"看起来很稳定"，最难查。

## 3. 频谱与频段

### 3.1 频谱划分

| 波段 | 频率范围 | 典型用途 |
|---|---|---|
| VHF | 30–300 MHz | 广播、对讲 |
| UHF | 300 MHz–3 GHz | 手机主力频段、Wi-Fi、GPS |
| SHF | 3–30 GHz | 5G 3.5G/4.9G、卫星、雷达 |
| EHF | 30–300 GHz | 毫米波、回传 |

频率越高：带宽越大（速率高）、天线越小，但路径损耗和遮挡越严重——这就是 5G 要高低频搭配的原因。

### 3.2 3GPP 的 band 号

- LTE 用 `B1…B…`，NR 用 `n1…n…`，编号对应一段**上行/下行频率范围**。
- band 号是"频率范围编号"，**不是制式编号**：同一个频率上 LTE B1 和 NR n1 是两套空口，参数不能混用。
- 每个 band 都有自己的功率等级、杂散要求、测试信道（低/中/高），所以 band 是测试矩阵里膨胀最快的一维。

### 3.3 双工方式

| 方式 | 频谱 | 优点 | 缺点 | 代表 |
|---|---|---|---|---|
| FDD | 上下行成对、不同频率 | 上下行互不干扰、时延稳定 | 需要成对频谱、双工器 | GSM900、WCDMA B1、LTE B1/B3 |
| TDD | 上下行同频、分时隙 | 频谱利用率高、可按业务配比 | 需要保护间隔、同步要求高 | TD-SCDMA、LTE B41、NR n41/n78/n79 |
| 半双工 | 同频、收发不同时 | 成本低 | 时延大 | LTE-M、部分 IoT |

### 3.4 国内常见频段（量级参考，以现网为准）

| 运营商 | 主要制式 | 常见 band |
|---|---|---|
| 移动 | GSM / LTE / NR | GSM900/1800、LTE B38/B39/B40/B41、NR n41/n28/n79 |
| 联通 | GSM / WCDMA / LTE / NR | GSM900/1800、WCDMA B1、LTE B1/B3、NR n1/n78/n8 |
| 电信 | CDMA / LTE / NR | CDMA 800、LTE B1/B3/B5、NR n1/n78/n5 |
| 广电 | NR | 700 MHz（n28） |

## 4. 空口基础

### 4.1 多址方式：怎么把一份频谱分给多个人

| 多址 | 区分用户靠什么 | 代表制式 | 特点 |
|---|---|---|---|
| FDMA | 频率 | 第一代模拟 | 简单、频谱利用率低 |
| TDMA | 时间（时隙） | GSM | 需要严格同步，burst 结构 |
| CDMA | 码字（扩频） | WCDMA、CDMA2000 | 抗干扰、有远近效应，需功控 |
| OFDMA | 子载波（正交） | LTE/5G 下行 | 频谱效率高、调度灵活，但 PAPR 高 |
| SC-FDMA | 子载波 + 单载波特性 | LTE 上行 | PAPR 低，省终端功耗 |

> 一句话串起来：**CDMA 靠码区分人，OFDMA 靠子载波区分人**。前者要解决远近效应（所以功控是命门），后者要解决 PAPR（所以上行改用 SC-FDMA）。

### 4.2 调制：每个符号带几个比特

| 调制 | bit/符号 | 频谱效率 | 抗噪能力 | PAPR |
|---|---|---|---|---|
| QPSK | 2 | 低 | 强 | 低 |
| 16QAM | 4 | 中 | 中 | 中 |
| 64QAM | 6 | 较高 | 较弱 | 较高 |
| 256QAM | 8 | 高 | 弱 | 高 |

阶数越高 → 速率越高、对 EVM 和信噪比要求越苛刻 → 越容易触发 MPR（降功率换频谱质量），见 [D01](<../02 测试指标/D01 最大功率与MPR.md>)。

### 4.3 帧结构与资源单位

| | LTE | NR |
|---|---|---|
| 无线帧 | 10 ms | 10 ms |
| 子帧 | 1 ms（固定） | 1 ms（固定，仅作时间参考） |
| 时隙 | 0.5 ms，7 符号（常规 CP） | 14 符号，长度随 SCS 变 |
| SCS | 15 kHz | 15/30/60/120 kHz |
| 每帧时隙数 | 20 | 10/20/40/80 |

资源单位：

- **RE（Resource Element）** = 1 个子载波 × 1 个符号，最小颗粒。
- **RB（Resource Block）** = 12 个子载波。LTE 的 RB = 180 kHz；NR 的 RB 宽度随 SCS 变（12 × SCS）。
- 带宽 ↔ RB 数：LTE 1.4/3/5/10/15/20 MHz = 6/15/25/50/75/100 RB；NR 100 MHz @30 kHz = 273 RB。

> 注意：1RB 放带边和满 RB 是两个测试极端——前者容易触发 MPR，后者测的才是最大能力。设计测试矩阵时这两个点都不能漏。

### 4.4 其它必须知道的名词

- **CP（循环前缀）**：对抗多径，常规 CP vs 扩展 CP。
- **SCS（子载波间隔）**：NR 的灵活性来源，SCS 越大符号越短、越抗相位噪声，但覆盖越差。
- **BWP（带宽部分）**：NR 里给 UE 配的一段带宽，省电、灵活。
- **SSB / 波束**：NR 的同步块，FR2 靠波束扫描覆盖。
- **编码**：LTE 数据用 Turbo，5G 数据用 LDPC、控制用 Polar。
- **MIMO**：多层传输、波束赋形；FR2 以模拟波束为主。

## 5. 制式全景

每一代不是在推翻上一代，而是在补上一代的短板：

| 代际 | 制式 | 要解决的问题 | 关键技术 | 国内状态 |
|---|---|---|---|---|
| 2G | GSM / GPRS / EDGE | 语音数字化、可漫游 | TDMA、GMSK、8PSK(EDGE) | 仍在用（IoT、语音回落） |
| 3G | WCDMA / HSPA、TD-SCDMA、CDMA2000 | 移动数据 | CDMA、5 MHz、HSPA | 基本退网 |
| 4G | LTE / LTE-A | 全 IP 宽带、低时延 | OFDMA、MIMO、CA | 主力 |
| 5G | NR（SA/NSA）、RedCap、NTN | eMBB / uRLLC / mMTC | 大带宽、SCS 可变、波束、网络切片 | 主力 |

规范地图（测什么查哪份）：

| 制式 | 限值 | 测试方法 | 测试环境/信道 |
|---|---|---|---|
| GSM | TS 45.005 | TS 51.010-1（一个文件全包） | — |
| WCDMA | TS 25.101 | TS 34.121 | — |
| LTE | TS 36.101 | TS 36.521-1 | TS 36.508 |
| NR | TS 38.101-1（FR1）、38.101-3（NSA） | TS 38.521-1 | TS 38.508-1 |

## 6. 四种主力制式

> 顺序按**代际演进**排（GSM → WCDMA → LTE → NR），不按字母、也不按提问顺序。理由：后一代的每个关键参数，都是对前一代某个具体问题的回应，顺着读才记得住"为什么是这样"。

### 6.1 GSM —— 2G

| 项目 | 内容 |
|---|---|
| 全称 | Global System for Mobile Communications（全球移动通信系统） |
| 多址/双工 | TDMA + FDMA，FDD |
| 载波/帧 | 200 kHz 载波；TDMA 帧 4.615 ms，8 个时隙 |
| 调制 | GMSK（EDGE 用 8PSK） |
| 功率 | GSM900 33 dBm（class 4）、DCS1800 30 dBm（class 1） |
| 频段 | 850 / 900 / 1800 / 1900 MHz |
| 射频关注 | burst 的功率-时间模板（上升/下降沿、时隙间功率）、调制谱/开关谱、频率误差、EDGE 的 EVM、多时隙 GPRS 的功率回退 |

### 6.2 WCDMA —— 3G

| 项目 | 内容 |
|---|---|
| 全称 | Wideband Code Division Multiple Access（宽带码分多址），UMTS 的 FDD 空口 |
| 多址/双工 | CDMA，FDD |
| 码片/带宽 | 3.84 Mcps，5 MHz |
| 帧结构 | 10 ms 帧 = 15 时隙；扩频因子 UL 4–256、DL 4–512 |
| 调制 | QPSK；HSPA 引入 16QAM / 64QAM |
| 功率 | PC3 24 dBm 为主 |
| 频段 | B1 2100、B2 1900、B5 850、B8 900 |
| 射频关注 | 参考测量信道（RMC）、最大功率、ACLR、EVM、内环功控、HSDPA 的 CQI/ACK 时序 |

### 6.3 LTE —— 4G

| 项目 | 内容 |
|---|---|
| 全称 | Long Term Evolution（长期演进），空口叫 E-UTRA |
| 多址/双工 | 下行 OFDMA / 上行 SC-FDMA；FDD 与 TDD |
| 帧结构 | 10 ms 帧 = 10 子帧 = 20 时隙；常规 CP 每时隙 7 符号；SCS 15 kHz |
| 带宽 | 1.4–20 MHz，对应 6–100 RB |
| 调制 | QPSK / 16QAM / 64QAM / 256QAM |
| 功率 | PC3 23 dBm（±2 dB） |
| 频段 | 国内 B1/B3/B5/B8/B34/B39/B40/B41 |
| 射频关注 | RB 分配（1RB 最低/最高/满 RB）、MPR 触发条件、ACLR/SEM、EVM、带内杂散 |

### 6.4 NR —— 5G

| 项目 | 内容 |
|---|---|
| 全称 | New Radio（新空口） |
| 多址/双工 | CP-OFDM（上行可选 DFT-s-OFDM）；FDD / TDD，支持 SUL/SDL |
| 帧结构 | 10 ms 帧；每时隙 14 符号；SCS 15/30/60 kHz（FR1）、60/120 kHz（FR2） |
| 带宽 | FR1 单载波 ≤100 MHz；FR2 ≤400 MHz |
| 调制 | QPSK–256QAM（低 PAPR 场景用 π/2 BPSK） |
| 功率 | PC3 23 dBm、PC2 26 dBm（n41/n77/n78/n79 等）、PC1.5 29 dBm |
| 频段 | 国内 n1/n3/n5/n8/n28/n41/n77/n78/n79 |
| 射频关注 | SA vs NSA、SCS × 带宽组合、SSB/波束（FR2 的 EIRP 与球面覆盖）、SEM/ACLR、256QAM 的 EVM、功率等级 |

## 7. 制式与特性

| 名称 | 属于 | 本质 | 射频上怎么处理 |
|---|---|---|---|
| GPRS / EDGE | GSM | 分组数据 / 8PSK 增强 | 多时隙、功率回退、EDGE EVM |
| HSPA / HSPA+ | WCDMA | 高速分组 | 16/64QAM、CQI 反馈 |
| CA（载波聚合） | LTE / NR | 多载波捆绑 | 多小区配置、带内/带间、谐波与互调 |
| EN-DC / NE-DC / NGEN-DC | LTE + NR | 双连接（NSA 的实现方式） | 两制式同时在线，功率/杂散按组合测 |
| NB-IoT | LTE 家族 | 180 kHz 窄带 | 独立 band、功率等级、带内/保护带/独立部署 |
| LTE-M（Cat-M1 / eMTC） | LTE 家族 | 1.4 MHz 带宽 | 覆盖增强（重复）、半双工 |
| RedCap | NR | 裁剪版 5G | 带宽/天线数裁剪，测试项子集 |
| NTN | NR | 卫星非地面网络 | 多普勒、大时延、定时提前 |
| Sidelink / V2X | LTE / NR | 终端直连 | 38.521-1 有专门章节 |

判断口诀：**能单独占一段频谱、有独立 band 号和独立射频指标表的，测试上当制式对待；只是"同一空口的能力增强"的，归为特性。**

## 8. 射频测试基础

### 8.1 测试分类

- **按路径**：传导（天线口/测试座）vs OTA（暗室辐射）。
- **按方向**：TX（发射）vs RX（接收）。
- **按阶段**：研发验证（全项）→ 认证（按规范全项）→ 产线（抽关键项，追求节拍）。

### 8.2 TX 侧常见指标

| 指标 | 测什么 | 典型失败原因 |
|---|---|---|
| 最大输出功率 | 指定配置下的功率能力 | 未到最大功率档、线损没校准、PA 饱和 |
| 功率控制 | 不同命令下的功率步进 | 校准表错、温补失效 |
| 频率误差 | 实际载波与标称的偏差 | 晶振/温补、锁相环 |
| EVM | 调制质量 | PA 非线性、IQ 不平衡、相位噪声 |
| 载波泄漏 / IQ 不平衡 | 零中频镜像与直流 | 校准/本振泄漏 |
| 频谱模板（SEM） | 信道外能量分布 | 滤波器、PA 线性度 |
| ACLR | 邻道功率比 | PA 线性度、削峰不足 |
| 占用带宽（OBW） | 99% 能量所占带宽 | 带宽配置、滤波 |
| 杂散 / 谐波 | 带外非期望发射 | 混频产物、滤波器抑制不足 |

### 8.3 RX 侧常见指标

| 指标 | 测什么 |
|---|---|
| 参考灵敏度（REFSENS） | 给定吞吐/误块率下能收到的最弱信号 |
| 邻道选择性（ACS） | 有强邻道干扰时收弱信号的能力 |
| 阻塞 | 带外强信号下的接收能力 |
| 互调 | 两个干扰信号产生的三阶产物 |
| 杂散响应 | 镜像/中频等特定频点的抗扰 |

### 8.4 测试系统与校准

典型连接：**综测仪 → 衰减器/功分器 → 射频线 → 屏蔽箱 → DUT**。

- 综测仪：CMW500（多制式）、CMX500（5G）、SP9500（国产 5G）、MT8821C 等。
- 必做校准：**线损（cable loss）**，用功率计或仪表内置的校准功能；温度变化大时要重校。
- 屏蔽：避免外部信号污染灵敏度测试；OTA 需要暗室与转台。

### 8.5 常见"假失败"

1. 线损没校准或用了旧值 → 功率整体偏低/偏高。
2. 功率控制没拉到最大档 → 最大功率项 FAIL。
3. RB/调制配置与测试项不对应 → MPR 判据用错。
4. 屏蔽不好 → 灵敏度、杂散项偶发 FAIL。
5. 用错 band 的测试信道（低/中/高）→ 带边功率下降被当成故障。

### 8.6 判定与不确定度

限值来自**规范原文表格 + 平台/客户配置**，不是记忆里的数字。测量不确定度要留余量：贴着限值的读数，先怀疑系统误差，再怀疑 DUT。

## 10. 代码与枚举

**Android `TelephonyManager.NETWORK_TYPE_*`**（最常被问到的"代码"）：

| 制式 | 常量 | 值 |
|---|---|---|
| GPRS / EDGE | NETWORK_TYPE_GPRS / EDGE | 1 / 2 |
| WCDMA | NETWORK_TYPE_UMTS | 3 |
| HSPA 族 | HSDPA / HSUPA / HSPA / HSPAP | 8 / 9 / 10 / 15 |
| LTE | NETWORK_TYPE_LTE | 13 |
| LTE CA | NETWORK_TYPE_LTE_CA | 19 |
| NR | NETWORK_TYPE_NR | 20 |
| TD-SCDMA | NETWORK_TYPE_TD_SCDMA | 17 |
| CDMA / EVDO / 1xRTT | CDMA / EVDO_0 / EVDO_A / EVDO_B / 1xRTT | 4 / 5 / 6 / 12 / 7 |
| GSM | NETWORK_TYPE_GSM | 16 |

注意三点：

1. 这套是"**网络类型**"不是"制式"——LTE CA 有独立值，而 WCDMA 没有独立常量（用 UMTS/HSPA 表达）。
2. 3GPP 侧**不按数字码区分制式**，靠规范号 + band 号（`B`/`n` 前缀）+ 测试配置定位。
3. QMI、GTP 等协议栈各有自己的 RAT 枚举，**不要跨栈背数字**，用的时候查对应规范。

## 11. 速查表

### 11.1 制式

| 制式 | 代际 | 多址 | 双工 | 带宽 | 调制 | 功率 | 规范 |
|---|---|---|---|---|---|---|---|
| GSM | 2G | TDMA/FDMA | FDD | 200 kHz | GMSK / 8PSK | 33 / 30 dBm | 45.005 / 51.010-1 |
| WCDMA | 3G | CDMA | FDD | 5 MHz | QPSK / 16 / 64QAM | 24 dBm | 25.101 / 34.121 |
| LTE | 4G | OFDMA / SC-FDMA | FDD / TDD | 1.4–20 MHz | QPSK–256QAM | 23 dBm | 36.101 / 36.521-1 |
| NR | 5G | CP-OFDM | FDD / TDD | ≤100 MHz（FR1）/ ≤400 MHz（FR2） | QPSK–256QAM | 23 / 26 / 29 dBm | 38.101-1 / 38.521-1 |

### 11.2 公式

```
dBm = 10·lg(P/1mW)
级联：P_out(dBm) = P_in(dBm) − 线损 + 增益
EVM(dB) = 20·lg(EVM%)
```
