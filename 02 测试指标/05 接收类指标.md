# 接收类指标

> 覆盖：参考灵敏度（REFSENS）、最大输入电平、邻道选择性（ACS）、阻塞、杂散响应、接收互调、接收杂散发射，以及 desense / OTA EIS 的工程视角。
> 与发射类的根本区别：发射测「发得对不对」，接收测「在噪声和干扰里还能不能解调」。接收指标大多不是读一个功率值，而是让 DUT 在给定误块率/吞吐门限下工作，再反推它能承受的最差条件。
> 测量链、路径损耗、同步与通用归因见 [测量基础与校准](<01 测量基础与校准.md>)；发射侧指标见 [功率类](<02 功率类指标.md>)、[频谱类](<03 频谱类指标.md>)、[调制质量类](<04 调制质量类指标.md>)。

## 1. 这一类指标的坐标

| 指标 | 回答的问题 | 关键条件 | 典型判据 | LTE 方法 / 限值 | NR 方法 / 限值 |
|---|---|---|---|---|---|
| 参考灵敏度 REFSENS | 最弱能收到多少 | 带宽、RB、调制、天线数、传播条件 | 吞吐 ≥ 最大吞吐的 95% | 36.521-1 7.3 / 36.101 7.3 | 38.521-1 7.3 / 38.101-1 7.3 |
| 最大输入电平 | 最强能扛多少 | 最大下行功率、调制 | 吞吐 ≥ 95% | 36.521-1 7.4 / 36.101 7.4 | 38.521-1 7.4 / 38.101-1 7.4 |
| 邻道选择性 ACS | 邻道强干扰下能否收 | 有用信号比灵敏度高约 3 dB，邻道干扰 | 吞吐 ≥ 95% | 36.521-1 7.5 / 36.101 7.5 | 38.521-1 7.5 / 38.101-1 7.5 |
| 阻塞 | 带外强干扰下能否收 | CW 干扰在指定频偏/功率 | 吞吐 ≥ 95% | 36.521-1 7.6 / 36.101 7.6 | 38.521-1 7.6 / 38.101-1 7.6 |
| 杂散响应 | 特定频点干扰是否被混入 | 连续波逐点扫描 | 不出现不可接受的响应 | 36.521-1 7.7 / 36.101 7.7 | 38.521-1 7.7 / 38.101-1 7.7 |
| 接收互调 | 两个强干扰是否产生落入带内的产物 | 双音/双干扰频偏与功率 | 吞吐 ≥ 95% | 36.521-1 7.8 / 36.101 7.8 | 38.521-1 7.8 / 38.101-1 7.8 |
| 接收杂散发射 | 接收机自己是否向外漏 | 接收态、扫描范围、RBW | 低于限值 | 36.521-1 7.9 / 36.101 7.9 | 38.521-1 7.9 / 38.101-1 7.9 |
| OTA EIS / TIS | 整机含天线能收到多弱 | 暗室、探头、方位、极化 | EIS 达标、TIS 积分 | 36.521-3 / 38.521-3 | 同左 |

WCDMA 的接收指标在 TS 34.121-1 与 TS 25.101 的第 7 章，章号与 LTE 类似但条件不同；GSM 的接收指标在 TS 51.010-1 的对应节。引用具体限值时，以当前收录版本的表格为准。

## 2. 共同测量链路

接收测试的最小闭环：

```text
综测仪 / 信号源（下行）
        │  有用信号 + 干扰（合路后）
        ▼
      DUT ──→ 上报 BLER / 吞吐 / ACK / CQI
        ▲
        └── 测试态、band/信道/带宽/调制、天线配置
```

四个必须固定的量：

1. **参考平面**：限值定义在 DUT 天线端口。传导测试要校准到端口；OTA 测试要校准到暗室参考点。
2. **下行功率**：不是「信号源设多少」，而是 DUT 端口实际收到多少；路径损耗、合路器、衰减器、线缆都要算进去。
3. **干扰功率**：同样要校准到 DUT 端口；干扰源与有用信号合路后的互调、隔离、相位噪声会直接污染结果。
4. **DUT 状态**：band、信道、带宽、RB、MCS、天线数、接收分集、测试模式必须与测试方法一致；否则吞吐门限不可比。

判据通常不是「读一个数」，而是「在某个功率点，吞吐/BLER 是否过门限」。因此接收测试本质上是**统计测试**：要跑够块数，才能把随机波动和真实劣化分开。

## 3. 参考灵敏度（REFSENS）

定义：在指定信道、带宽、RB、调制、天线配置下，使 DUT 达到最小吞吐要求（通常为最大吞吐的 95%）所需的最小下行功率。

测试步骤（传导）：

1. 综测仪建链，配置 band、信道、带宽、RB、MCS、天线数。
2. 先在高功率下确认吞吐正常，排除建链/配置问题。
3. 按步长降低下行功率，每个功率点等待统计稳定，记录吞吐/BLER。
4. 找到吞吐首次跌破门限的功率点，按测试方法取判定值。
5. 换信道（低/中/高）、换 band、换天线配置重复。

关键理解：

- REFSENS 不是「能不能注册」，而是「最弱条件下吞吐是否还够」；注册成功但吞吐掉到 0，不算通过。
- 带宽越宽，噪声带宽越大，灵敏度通常越差；不同带宽的限值不能直接比较。
- 接收分集、高阶接收机、LNA 增益模式会改变结果；测试配置必须写清楚。
- 传导灵敏度好，不代表整机 OTA 好；天线效率、失配、壳体损耗会再吃掉几个 dB。

常见失败：

| 现象 | 先查什么 | 常见根因 |
|---|---|---|
| 所有信道都差 3–6 dB | 路径损耗校准、合路器/衰减器、参考平面 | 线损没算、校准文件过期、接头坏 |
| 只有高信道差 | 信道/本振、滤波器边沿、band 校准 | 接收滤波器抑制、本振泄漏、校准表 |
| 只有某个带宽差 | 噪声带宽、RB 配置、AGC 设置 | 配置错、AGC 增益表、邻道泄漏 |
| 吞吐波动大、时好时坏 | 干扰源、屏蔽、电源、温度 | 环境干扰、USB/时钟谐波、供电噪声 |
| 传导正常、OTA 差 | 天线效率、失配、壳体、手握 | 天线设计、匹配、SAR 降功率 |

## 4. 最大输入电平

定义：DUT 在强下行信号下仍能满足吞吐要求的能力，考察接收机是否饱和/阻塞。

测试思路：把下行功率升到测试方法规定的最大值，确认吞吐仍达标；再检查 AGC、LNA 旁路、ADC 是否进入非线性。

常见失败：强信号下 EVM/吞吐变差、AGC 环路失锁、DC 偏移、二阶/三阶失真。与「阻塞」不同：最大输入是**同频有用信号**很强，阻塞是**带外干扰**很强。

## 5. 邻道选择性（ACS）

定义：有用信号在邻道存在强干扰时，接收机抑制邻道干扰、仍能解调有用信号的能力。

条件要点：

- 有用信号通常比 REFSENS 高约 3 dB；
- 干扰信号在相邻信道，功率按测试方法；
- 有用信号与干扰同时存在，测吞吐；
- 干扰源的相位噪声、宽带噪声要足够低，否则测到的是干扰源而不是 DUT。

失败归因：

- 邻道滤波器抑制不足、接收机线性度不够、混频器/ADC 阻塞；
- 干扰源本身相噪差，导致「假失败」；
- 合路器隔离不够，干扰泄漏到有用信号路径。

## 6. 阻塞

定义：在有用信号存在时，带外（或指定频偏）的强干扰使接收机吞吐下降的程度。

测试方法通常用 CW 干扰，在指定频偏范围内扫描，找到 DUT 仍能满足吞吐的干扰电平；分为带内阻塞与带外阻塞。

工程要点：

- 阻塞测试对干扰源的频谱纯度、谐波、开关速度要求高；
- 扫描步长太粗会漏掉窄带响应；
- DUT 的 SAW/BAW 滤波器、LNA 线性度、混频器输入范围决定结果；
- 与「杂散响应」区别：阻塞看强干扰造成的增益压缩/饱和，杂散响应看特定频点被混频/谐波搬进带内。

## 7. 杂散响应

定义：在特定干扰频点上，接收机因混频、谐波、镜像等机制产生不可接受的响应。

测试通常用 CW 干扰逐点扫描，记录哪些频点会让吞吐跌破门限；这些频点往往对应：

- 本振的谐波/镜像；
- 接收机中频、时钟、ADC 采样率的谐波；
- 双工器/滤波器的寄生通带；
- 电源 DC-DC 开关频率及其谐波。

排查时先把干扰源关掉/换频，确认不是测试系统自身响应；再检查 DUT 的时钟、电源、屏蔽。

## 8. 接收互调

定义：两个强干扰信号（或一个有用信号 + 两个干扰）在接收机非线性器件上产生三阶互调，产物落入有用信道，导致吞吐下降。

条件要点：

- 两个干扰的频偏、功率按测试方法；
- 干扰源之间的隔离与合路方式会影响结果；
- 测试系统自身互调要足够低，否则测到的是仪器/合路器；
- DUT 的 LNA、混频器、ADC 线性度是主因。

与发射互调的区别：发射互调测 DUT 发射时产生的产物；接收互调测外部干扰在 DUT 接收链路里产生的产物。

## 9. 接收杂散发射

定义：DUT 处于接收态时，自身向外辐射/传导的非期望信号。

测试要点：

- DUT 接收态、天线端口接匹配负载/频谱仪；
- 扫描范围、RBW、检波器按测试方法；
- 区分 DUT 杂散与环境干扰：断开 DUT、换屏蔽箱、换电源；
- 接收杂散常来自本振泄漏、时钟/DC-DC 谐波、数字接口。

## 10. Desense 与共存

Desense（灵敏度劣化）不是 3GPP 的单一测试项，而是整机工程里最常见的接收问题：

- 自身发射（TX 泄漏、谐波、互调）抬高接收底噪；
- Wi-Fi/BT/GNSS/充电/摄像头/屏幕等共存干扰；
- 天线耦合、壳体电流、接地不良；
- 电源/时钟噪声通过共用电源/地串入接收链路。

排查顺序：

1. 关掉所有非必要功能，测基线灵敏度；
2. 逐个打开功能（TX、Wi-Fi、BT、充电、屏幕、摄像头），看灵敏度变化；
3. 变化出现时，先确认是传导还是辐射：换屏蔽、换天线、加磁珠/滤波；
4. 最后再动 DUT 的匹配/滤波/屏蔽，避免把测试系统问题当成设计问题。

## 11. OTA EIS / TIS

OTA 接收测试把天线、壳体、手握、方位都算进去：

- **EIS**：等效全向灵敏度，某个方位/极化下达到吞吐门限的最小功率；
- **TIS**：全向灵敏度积分，反映整机平均接收能力；
- 暗室、探头、转台、参考天线、路径损耗校准决定可信度；
- 与传导 REFSENS 的差值，就是天线/壳体/失配带来的总损耗。

毫米波 OTA 还要考虑波束、阵列增益、极化与位置误差，测试时间和校准复杂度都更高。

## 12. 判定与统计

接收指标是统计量，不能用一个瞬间的吞吐下结论：

- 每个功率点要跑够块数，让吞吐置信区间落在门限之外；
- 边界点附近增加样本，避免「刚好 95%」的偶然通过；
- 先跑高功率基线，再降功率；出现异常先复测基线；
- 记录原始吞吐、BLER、MCS、CQI、RSRP/RSRQ/SINR，便于复盘；
- 测试顺序会影响温度/电量，长时间测试要记录并控制。

## 13. 失败归因速查

| 现象 | 优先怀疑 | 验证动作 |
|---|---|---|
| 全 band 灵敏度差 | 路径损耗/校准/夹具 | 功率计校到 DUT 端口；换已知好线 |
| 某 band 差 | 滤波器/双工器/匹配 | 换信道、看滤波器边沿、对比同平台 |
| ACS/阻塞差 | 接收线性度、滤波抑制 | 降低干扰源功率看是否线性；换干扰源 |
| 杂散响应点固定 | 本振/时钟/DC-DC 谐波 | 改时钟频率、屏蔽、加滤波 |
| 接收互调差 | LNA/混频器线性度 | 降低干扰功率、换合路器、查隔离 |
| 只有 OTA 差 | 天线/壳体/手握 | 对比传导、换方位、查匹配 |
| 时好时坏 | 环境/电源/连接 | 换屏蔽箱、电池供电、重新插拔 |
