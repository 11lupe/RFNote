# 测试指标索引

> 共 **5** 篇。定位：指标层的「测什么 → 条件为什么这么定 → 怎么测 → 失败怎么归因」。
> 限值、测试条件、判定容差以 3GPP 原文表格 + 平台/客户配置为准；本库数字只作量级参考。
> 当前范围：**发射（TX）+ 接收（RX）**。接收指标依赖吞吐/BLER 统计，测试链和判定方式与发射不同，先看接收类文档的「共同测量链路」。

## 体系

| 层 | 文档 | 回答的问题 | 主要指标 |
|---|---|---|---|
| 测量基础 | [测量基础与校准](<01 测量基础与校准.md>) | 读数为什么可信：参考平面、参考电平、同步、路径损耗、重复性、归因 | 全部指标的共用方法 |
| 功率类 | [功率类指标](<02 功率类指标.md>) | 发多大、多小、关得干不干净、控得准不准 | MOP、MPR/A-MPR、最小功率、TX OFF、TPC |
| 频谱类 | [频谱类指标](<03 频谱类指标.md>) | 带外漏多少、漏成什么形状、杂散从哪来 | OBW、SEM、ACLR、杂散、发射互调 |
| 调制质量类 | [调制质量类指标](<04 调制质量类指标.md>) | 信号本身是否失真、本振是否偏 | 频率误差、EVM、载波泄漏、IQ 不平衡 |
| 接收类 | [接收类指标](<05 接收类指标.md>) | 能收到多弱、抗干扰多强 | REFSENS、最大输入、ACS、阻塞、杂散响应、接收互调、RX 杂散 |

分类逻辑：先有「可信的测量」，再按「功率 → 频谱 → 调制质量」看发射链路。功率是前提，频谱看带外，调制质量看带内；三者不是并列清单，而是从「发得对」到「发得干净」再到「发得准」。

仪表与链路怎么搭（综测仪、信号源、频谱仪、VNA、功率计、附件与屏蔽）见 [射频常用仪表](<../04 仪表与设备/01 射频常用仪表.md>)。

## 阅读路径

- **第一次建立体系**：测量基础 → 功率类 → 频谱类 → 调制质量类 → 接收类。先看每篇的「坐标表」，知道这一类在回答什么问题，再看条件与失败。
- **查单个指标**：从上面的总表进对应章节；先看定义与判决式，再看条件矩阵，最后看失败归因。
- **查限值/条款**：[3GPP 检索索引](<../03 规范与标准/3GPP/00 3GPP检索索引.md>) §4。测试方法在 `.521`，限值在 `.101`；WCDMA/GSM 的编号规则不同，按索引里的对照表走。
- **排障**：先跑 [测量基础与校准](<01 测量基础与校准.md>) §6 的四步法，再用各文档的「失败归因速查」缩小范围。先排除测量系统，再归因 DUT。
- **写测试/脚本**：同步看 [测量基础与校准](<01 测量基础与校准.md>) §3，校准看 §4；功率类的实测流程看 [功率类指标](<02 功率类指标.md>) §2.4。

## 限值与条款出处

- **LTE**：测试方法 TS 36.521-1；限值 TS 36.101。MOP 6.2.2、MPR 6.2.3、A-MPR 6.2.4、最小功率 6.3.2、关闭功率 6.3.3、TPC 6.3.5、频率误差 6.5.1、EVM 6.5.2.1、OBW 6.6.1、SEM 6.6.2.1、ACLR 6.6.2.3、杂散 6.6.3、发射互调 6.7。
- **NR**：测试方法 TS 38.521-1；限值 TS 38.101-1。MOP 6.2.1、MPR 6.2.2、A-MPR 6.2.3、最小功率 6.3.1、关闭功率 6.3.2、TPC 6.3.4、频率误差 6.4.1、EVM 6.4.2.1、OBW 6.5.1、SEM 6.5.2.2、ACLR 6.5.2.4、杂散 6.5.3、发射互调 6.5.4。
- **WCDMA**：测试方法 TS 34.121-1；限值 TS 25.101。测试方法 5.x 对应限值 6.x，章号通常差 1；功率控制、最小功率、ON/OFF、OBW、SEM、ACLR、杂散、互调、调制都有独立节。
- **GSM**：TS 51.010-1 覆盖测试方法；限值条款按该规范内的对应节。
- **接收类**：LTE 见 TS 36.521-1 / 36.101 第 7 章（7.3–7.9）；NR 见 TS 38.521-1 / 38.101-1 第 7 章；WCDMA 见 TS 34.121-1 / 25.101 第 7 章。具体条件与限值按 band/带宽/天线配置查表。
- 条款号会随 release/版本变化；正式判定前用 [3GPP 检索索引](<../03 规范与标准/3GPP/00 3GPP检索索引.md>) 核对当前收录版本，不要凭记忆写节号。

## 维护

- **归类**：新指标先归入「测量基础 / 功率 / 频谱 / 调制质量 / 接收」五类之一；确实是新一类再新建文档，并在本索引「体系」表登记。
- **扩写优先**：优先补齐现有文档的坐标表、条件、失败归因；单篇超过约 300 行或出现独立主题时再拆，拆完两边互链。
- **计数同步**：新增/删除/改名后，更新本页「共 N 篇」、指标总表，以及 [README](<../README.md>) 的目录表与总篇数；跑 `python tools/repo/check.py`。
- **知识边界**：知识文档只写知识本身。自测、追问链、回答话术、学习计划、进度与面试材料放本地 `_local/`，不写进这里；也不跨文件复制同一段正文。
- **限值引用**：引用限值必须标规范号 + 节号；平台/客户配置另写版本与生效范围，数字只作量级参考。
