# 测量基础与校准

> 定位：发射指标共用的测量链与数据可信方法。功率、频谱、调制质量分别在 [功率类指标](<02 功率类指标.md>)、[频谱类指标](<03 频谱类指标.md>)、[调制质量类指标](<04 调制质量类指标.md>)；本文只回答「这个读数凭什么可信」。
> 适用：传导测试（DUT 射频口 → 线缆/夹具 → 综测仪）。OTA 的链路与判定不同，见 §8。
> 限值：本文不给判定门限；限值与条款查 [3GPP 检索索引](<../03 规范与标准/3GPP/00 3GPP检索索引.md>) 的「指标 → 条款定位表」。

## 1. 测量链与参考平面

```
DUT 射频口 ── 射频线 / 夹具 / 衰减器 ── 综测仪射频口
   ↑ 参考平面（判定点）                    ↑ 仪表读数点
```

- 仪表读到的是**仪表口**功率；规范判定的是**DUT 口**功率。两者之差就是路径损耗（线缆、接头、衰减器、功分器、夹具都算）。
- 路径损耗不是常数：随频率、线缆弯折与磨损、接头状态、温度变化。用一条线、一个频点的校准值套全部 band，是功率类误判的常见来源。
- 功率类指标对链路最敏感：整批同向偏移时，先查链路与校准，不要先改 DUT。

## 2. 仪表设置：四个互相牵制的量

| 设置 | 作用 | 设得偏高 | 设得偏低 | 主要影响 |
|---|---|---|---|---|
| 参考电平（Reference Level） | 仪表期望的输入功率，决定衰减与量程 | 衰减变大、噪声底抬高，小信号被淹没 | 前端过载/削顶，大信号失真 | 高：最小功率、关闭功率、杂散；低：MOP、ACLR、SEM |
| 输入衰减（Attenuation） | 防过载，兼顾噪声底 | 噪声底抬高 | 前端压缩 | 同上 |
| RBW / VBW / 检波器 | 频谱分辨率、噪声带宽、迹线处理 | RBW 大：噪声底高，弱杂散被淹没 | RBW 小：扫描慢，节拍变长 | SEM、ACLR、杂散 |
| 平均 / 触发 / 测量窗口 | 抑制随机波动，保证测到目标时段 | 平均多：节拍慢；窗口偏：测到瞬态或空档 | 平均少：波动大；触发错：读到上一 burst | 全部指标 |

一句话记法：**参考电平高了伤小信号，低了伤大信号**。

设置口径：

- 参考电平以「该测试项预期的最大瞬时功率」为基准加余量，平台模板常用 5–10 dB；具体以平台/仪表配置模板为准，不要用 nominal 功率直接拍。
- 测最小功率、关闭功率、杂散时，参考电平要单独下调或换量程，不能沿用 MOP 的设置；下调后仍要确认前端不过载。
- 每次改参考电平、衰减、RBW、平均次数，都写进配置快照；否则数据不可复现。

## 3. 同步：write 返回不等于测量完成

SCPI 的 `write` 只保证命令进了仪表缓冲/队列；`query` 只保证有响应。两者都不等于「测量完成、数据已刷新」。

- `*CLS`：清状态与错误队列，放在每次测量开始时。
- `INIT`：启动测量。
- `*OPC?`：查询未完成操作是否结束；返回 `1` 才继续取数。仪表要设超时，不能无限等。
- `SYST:ERR?`：读错误队列。仪表报错通常不会抛异常，不查就会把上一次的旧数据当成本次结果。
- 稳定时间（settle）：DUT 的功率控制环、AGC、滤波器、温度都需要时间；`*OPC?` 只覆盖仪表，不覆盖 DUT。固定延时之外，还要确认 DUT 已进入目标状态。

```python
def measure_once(inst, cfg):
    inst.write("*CLS")
    inst.write(cfg.instrument_setup)      # 制式/信道/带宽/参考电平/触发
    inst.write(cfg.dut_setup)             # band/信道/RB/功率档/天线
    time.sleep(cfg.settle_s)              # 固定延时
    inst.write("INIT")
    if inst.query("*OPC?").strip() != "1":
        raise InstrumentTimeout(cfg)
    value = float(inst.query(cfg.fetch_command))
    error = inst.query("SYST:ERR?").strip()
    return value, error, snapshot(cfg)
```

`snapshot(cfg)` 至少记录：仪表型号与固件、band、信道、带宽、RB、调制、功率档、天线、参考电平、衰减、RBW/VBW、平均次数、触发源、窗口偏移、路径损耗、校准日期、时间戳。

厂商私有命令头（CMW500、SP9500 等）随固件变化；能通用的部分走 IEEE 488.2 公共命令，差异收敛在驱动层，不要让测试逻辑依赖某个私有头。

## 4. 路径损耗校准

目的：把仪表口读数换算回 DUT 口，让判定发生在参考平面。

步骤：

1. DUT 进入固定测试模式，输出连续波或稳定 burst；band、信道、功率档固定。
2. 功率计经同一夹具/线缆接到 DUT 口，读实际功率 `P_meter`；功率计自身的校准因子要计入。
3. 保持 DUT 设置不变，把同一路径接到综测仪，读 `P_inst`。
4. `Loss = P_meter − P_inst`（dB）。补偿时 `P_DUT ≈ P_inst + Loss`，不要把 Loss 再减一次；若中间有衰减器/功分器，按实际链路逐段确认。
5. 每个 band 至少测低、中、高信道；宽带按频率点建表或分段插值。
6. 记录日期、band、信道/频率、损耗值、线缆与夹具编号、仪表型号、温度。

需要重校的触发条件：

- 换线、换夹具、换接头、加减衰减器；
- 线缆明显弯折、移动、被压；
- 温度大幅变化，或长时间连续测试后机箱/线缆发热；
- 读数整批偏移，且 golden sample 也同向偏移；
- 到达平台规定的周期（按班次/周/月，以平台文件为准）。

不要用仪表内部自校准替代路径校准：它校的是仪表自己的前端，不是仪表到 DUT 的这段链路。

常见错误：

- 只校一个 band，套到全部频段；
- 换线后沿用旧损耗；
- 用规范里的「标称线损」代替实测；
- 校准时功率计接在衰减器之后，却把衰减量重复计入；
- 只在低功率校准，却把结果直接用于高功率（先确认链路是线性的）。

## 5. 重复性与测量不确定度

重复性来源，按影响排序：

1. 连接与接头：拧紧力矩、重复插拔、磨损、中心针状态；
2. 线缆与夹具：弯曲、损耗漂移、屏蔽；
3. 仪表设置：参考电平、RBW、平均次数、触发与窗口；
4. DUT 状态：功率档、温度、软件/校准表状态；
5. 环境：外部干扰、温度、供电；
6. 校准值本身：功率计、标准件、校准证书的不确定度。

量化方法：

- 同一配置重复 N 次（常用 10 次），算均值 `x̄` 与标准差 `s`；重复性可用 `2s` 或 `3s` 估计。
- 若 `|x̄ − 限值|` 小于测量不确定度 `U`，读数处于灰区，不能直接判 PASS/FAIL；先复测、换系统或查校准。
- 不确定度预算按「来源 / 类型（A 类重复测量、B 类证书与经验）/ 典型量级 / 处理方式」列，不要只报一个总数。

| 来源 | 类型 | 典型量级（仅示意） | 处理 |
|---|---|---|---|
| 接头重复性 | A | 0.1–0.3 dB | 多次连接取均值，固定力矩 |
| 线缆/夹具漂移 | B | 0.2–0.5 dB | 定期重校，固定走线 |
| 功率计 | B | 0.1–0.2 dB | 校准证书，计入校准因子 |
| 仪表幅度 | B | 0.1–0.3 dB | 仪表校准 |
| 环境/干扰 | B | 视场景 | 屏蔽、换频、断开 DUT 对比 |

成功率口径：

- 分母要先定义：是「有效测试次数」，还是「包含超时/掉线的总尝试次数」？两种口径不能混。
- 失败要先分类，再算成功率；否则脚本问题会把指标问题淹没。

| 分类 | 典型现象 | 处理 |
|---|---|---|
| 脚本/通信 | 超时、ADB 掉线、仪表无响应、取到空数据 | 修脚本、加重试与超时 |
| 样机状态 | 未进测试态、功率档残留、天线未切换 | 复位、状态确认 |
| 测量系统 | 线损旧值、接头磨损、参考电平错、窗口偏 | 重校、换线、改设置 |
| 真失效 | 换 golden sample 与换工位后仍超限 | 判 FAIL、返修/分析 |

## 6. 失败归因四步法

1. **换样机**：同一位置、同一配置换 golden sample。换后正常 → 原 DUT 问题；仍异常 → 测量系统问题。
2. **换通道/工位**：换线、换仪表口、换夹具。异常跟着线走 → 链路问题；不跟 → 仪表或 DUT。
3. **看原始数据与配置快照**：不要只看 FAIL。看波形、星座、频谱、RB/调制/功率档、参考电平、窗口；确认测的是不是目标 case。
4. **查基准与校准**：路径损耗、功率计、仪表校准、MPR/A-MPR 表版本、限值表版本。

证据标准：能复现的步骤 + 更换前后的数值 + 排除项 + 结论。例如「换线后由 −1.2 dB 变为 −0.1 dB，偏差跟着线走」是证据；「感觉线有问题」不是。

| 现象 | 优先检查 | 常见原因 |
|---|---|---|
| 整批同向偏移（所有样机、所有信道） | 路径损耗、参考电平、校准 | 系统误差是常数 |
| 只有带边信道异常 | 前端滤波、插损、匹配 | DUT 频率特性 |
| 只有部分 RB 异常 | MPR/A-MPR、RB 配置 | 合法回退或配置错 |
| 同一台重复性差 | 接头、线缆、settle、供电/发热 | 随机误差 |
| 小信号指标异常（最小功率、关闭功率、杂散） | 参考电平是否过高、屏蔽 | 噪声底或环境干扰 |
| 大信号指标异常（MOP、ACLR、SEM） | 参考电平是否过低、衰减 | 前端压缩/削顶 |

这张表只给排查顺序，不替代直接证据；具体指标的专项检查见 02–04 的「失败归因」。

## 7. 通用测量骨架

```
配置仪表（制式/信道/带宽/参考电平/触发）
  → 样机进测试态（band/信道/RB/功率档/天线）
  → 等稳定（固定延时 + 状态确认）
  → 触发测量
  → 同步等完成（*OPC? / 状态位）
  → 取平均（次数固定、可配置）
  → 判定（规范限值 × 平台/客户配置 × 该配置的 MPR/A-MPR）
  → 存原始数据 + 配置快照 + 校准值 + 时间戳
  → 复位样机与仪表（失败也复位）
```

| 环节 | 典型错误 | 后果 |
|---|---|---|
| 配置仪表 | 带宽/信道/RB 与用例不一致 | 测的不是目标 case |
| 样机进测试态 | 功率档没拉到最大、天线没切 | 最大功率项测成低功率 |
| 等稳定 | 只 sleep，不确认状态 | 读数偏低或波动 |
| 触发与同步 | 没等 `*OPC?`、没查错误队列 | 读到上一次结果或空数据 |
| 取平均 | 次数太少/每次不同 | 随机 FAIL，无法复现 |
| 判定 | 漏掉 MPR/A-MPR、用错表版本 | 合法回退被判 FAIL |
| 存快照 | 只存最终值 | 出了问题无法复现 |
| 复位 | 失败后不复位 | 污染下一项测试 |

## 8. 传导与 OTA 的边界

- **传导**：参考平面在 DUT 射频口，用路径损耗把仪表读数换算回 DUT 口；测的是 DUT 射频前端的发射/接收能力，不包含天线。
- **OTA**：在暗室测 EIRP/TRP、接收灵敏度、desense 等，链路包含天线增益、空间路径损耗、转台位置与暗室校准；结果不能直接与传导限值互换。
- 同一个指标在传导与 OTA 下的测试方法、限值、不确定度都可能不同；判定前先确认测试方法写的是哪一种。
- 本库 02–04 的指标以传导 TX 为主；OTA 只在指标边界处提示，不展开暗室校准。
