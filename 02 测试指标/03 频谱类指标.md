# 频谱类指标

> 覆盖：占用带宽（OBW）、频谱发射模板（SEM）、邻道泄漏比（ACLR/ACPR）、杂散发射、发射互调。
> 共同点：回答「发射信号在频域上漏到哪里、漏多少」；区别在测量位置、积分带宽和判定形态（绝对上限还是相对比值）。
> 测量链、参考电平、RBW/检波、校准与通用归因见 [测量基础与校准](<01 测量基础与校准.md>)。

## 1. 这一类指标的坐标

| 指标 | 测什么 | 判定形态 | 关键设置 | LTE（方法 / 限值） | NR（方法 / 限值） |
|---|---|---|---|---|---|
| 占用带宽 OBW | 包含 99% 总平均功率的带宽 | 上限 | 积分带宽、RBW、扫描范围 | 36.521-1 6.6.1 / 36.101 6.6.1 | 38.521-1 6.5.1 / 38.101-1 6.5.1 |
| 频谱模板 SEM | 各偏移段的绝对/相对功率上限 | 模板（逐段） | 偏移点、测量带宽、RBW、检波 | 36.521-1 6.6.2.1 / 36.101 6.6.2.1 | 38.521-1 6.5.2.2 / 38.101-1 6.5.2.2 |
| 邻道泄漏比 ACLR | 主信道功率 / 邻道功率 | 下限（dBc） | 信道带宽、邻道偏移、测量滤波器、平均 | 36.521-1 6.6.2.3 / 36.101 6.6.2.3 | 38.521-1 6.5.2.4 / 38.101-1 6.5.2.4 |
| 杂散发射 | 远离载波的宽带非期望发射 | 绝对上限 | 扫描范围、RBW、检波、屏蔽 | 36.521-1 6.6.3 / 36.101 6.6.3 | 38.521-1 6.5.3 / 38.101-1 6.5.3 |
| 发射互调 | 双音产生的互调产物 | 绝对上限 | 双音电平/频偏、隔离、测量带宽 | 36.521-1 6.7 / 36.101 6.7 | 38.521-1 6.5.4 / 38.101-1 6.5.4 |

一句话区分：**SEM 管「每个偏移段绝对不许超」，ACLR 管「邻道相对主信道有多脏」，OBW 管「信号本身占多宽」，杂散管「远离载波的单点/宽带泄漏」**。四者相关，但判据不等价。

## 2. 占用带宽（OBW）

定义：包含发射信号总平均功率 99% 的带宽。它描述信号本身的频率占用，不直接描述邻道泄漏。

测量要点：

- 扫描范围要覆盖完整信号，span 太窄会把带外功率截掉，积分结果偏小；
- RBW 相对信道带宽要足够小，否则积分分辨率不够；
- 用 RMS 检波/平均功率积分，不用峰值检波代替；
- 在最大功率、最宽带宽、最高调制下测，信号展宽最明显。

OBW 通常不是最容易失败的项，但它是很好的**诊断量**：

- OBW 正常、SEM/ACLR 差 → 信号主体没展宽，问题在带外泄漏（滤波、PA 线性度、互调）；
- OBW 展宽、SEM/ACLR 同时差 → 信号本身失真或配置错误（带宽/调制/时钟/滤波器）；
- OBW 异常窄 → 信号没完全加载或功率不足，先确认 DUT 状态。

条款：LTE 36.521-1 6.6.1 / 36.101 6.6.1；NR 38.521-1 6.5.1 / 38.101-1 6.5.1。

## 3. 频谱发射模板（SEM）

定义：在载波两侧多个偏移段上，规定允许的最大发射功率；每个偏移段有自己的测量带宽和限值，可能是绝对功率（dBm）或相对功率（dBc）。

关键设置：

- **偏移点与测量带宽**：每个段不同；用错测量带宽，读数不可比。
- **RBW/VBW/检波**：按测试方法；噪声类信号用 RMS 平均，不能只抓峰值。
- **参考电平/衰减**：太高会抬高噪声底，弱发射被淹没；太低会让前端压缩，整个模板上翘。
- **测量功率点**：最大功率、规定调制/RB；功率回退后 SEM 会改善，测最大功率才有意义。

失败排序：

1. 外部干扰：换频、屏蔽、断开 DUT 对比；干扰不随 DUT 状态变化。
2. 参考电平/RBW/测量带宽设置错：整条曲线平移或噪声底异常。
3. 路径损耗/校准漂移：整个模板同向偏移，golden sample 也偏。
4. 真失效：PA 非线性、滤波器抑制不足、互调产物。

SEM 与 ACLR 的关系：

- SEM 是**绝对**模板，保护相邻频段/其他系统；ACLR 是**相对**比值，衡量邻道脏的程度。
- SEM 差、ACLR 正常：可能是绝对限值紧、参考电平/噪声底问题，或某一段的测量带宽用错。
- ACLR 差、SEM 正常：可能是邻道比值差但绝对功率仍低于模板，或两者的测量滤波器/带宽不同。
- 不要把两者的限值互相换算；各自按各自条款判。

条款：LTE 36.521-1 6.6.2.1 / 36.101 6.6.2.1；NR 38.521-1 6.5.2.2 / 38.101-1 6.5.2.2。

## 4. 邻道泄漏比（ACLR / ACPR）

定义：主信道功率与邻道功率之比，通常用 dBc 表示。邻道功率不是在频谱上随便读一个峰值，而是用测试方法规定的测量滤波器/积分带宽对邻道功率积分；WCDMA 常用 RRC 滤波器，LTE/NR 按各自测试方法执行。

四个必须对齐的设置：

1. **邻道偏移**：第一邻道、第二邻道的位置不同，限值也不同；
2. **信道带宽/积分带宽**：主信道与邻道的积分带宽要按方法；
3. **测量滤波器**：RRC/矩形/其他，按制式；
4. **平均/检波**：ACLR 是统计量，平均次数不足会跳。

功率依赖：ACLR 随输出功率升高而恶化（PA 进入压缩，频谱再生变强）。因此：

- 在最大功率点测最有意义；
- 如果在最大功率和回退后 ACLR 几乎一样，先怀疑测量（噪声底、滤波器、平均、没真的到最大功率），不要急着下「PA 很好」的结论；
- 回退能改善 ACLR，但会牺牲效率；测试矩阵要同时看 MOP 与 ACLR，找边界。

失败排序：

1. PA 压缩/DPD 不足（最大功率点最明显）；
2. 仪表设置：参考电平、衰减、测量滤波器、积分带宽、平均；
3. 路径损耗/校准；
4. 真失效：滤波器、匹配、隔离。

ACLR 与 ACPR 是同一类量的不同叫法；写报告时注明制式与测量方法，避免和 SEM 的「邻道段」混淆。

条款：LTE 36.521-1 6.6.2.3 / 36.101 6.6.2.3；NR 38.521-1 6.5.2.4 / 38.101-1 6.5.2.4。

## 5. 杂散发射

定义：远离必要带宽的非期望发射，通常在很宽的频率范围内扫描，按绝对功率限值判定。它和 SEM/ACLR 的频段、测量带宽、限值形态都不同。

测量要点：

- 扫描范围、起始/终止频率、RBW、检波方式按测试方法；
- 仪表噪声底要低于限值；不够时用预放、减小衰减或 FFT，但要注意预放会不会压缩；
- 用限值线辅助判读，但最终按测试方法的测量带宽换算；
- 记录每个可疑点的频率、功率、DUT 状态。

最大的坑：**把环境干扰当成 DUT 杂散**。排查方法：

1. 断开 DUT（或接匹配负载），同一频点复测；干扰仍在 → 环境/仪表。
2. 改变 DUT 的信道/band，观察杂散频点是否跟着搬移；固定不动 → 外部。
3. 屏蔽、换暗室/屏蔽箱、换方位；用定向天线找干扰源。
4. 用陷波器/滤波器辅助判断，但注意不要改变 DUT 端口的匹配。

杂散来源：谐波、混频产物、时钟/本振泄漏、PA 非线性、电源/DC-DC 开关。单点凸起更像时钟/谐波/混频；宽带抬高更像 PA/噪声/校准。

条款：LTE 36.521-1 6.6.3 / 36.101 6.6.3；NR 38.521-1 6.5.3 / 38.101-1 6.5.3。

## 6. 发射互调

定义：在 DUT 天线端口同时加两个信号（双音），测量规定频点上的互调产物；用来验 PA/前端线性度与隔离。

要点：

- 双音功率、频率间隔、测量频点按测试方法；互调产物通常落在 `2f1−f2`、`2f2−f1` 等位置；
- 合路器/隔离器/衰减器要避免测试系统自己产生互调；先接负载或直通，确认系统底；
- 测的是 DUT 端口，路径损耗与校准同样适用；
- 失败多指向 PA 线性度、双工器/滤波器隔离、连接器/匹配。

条款：LTE 36.521-1 6.7 / 36.101 6.7；NR 38.521-1 6.5.4 / 38.101-1 6.5.4。

## 7. 指标间关系与排查顺序

推荐顺序：**OBW → SEM → ACLR → 杂散**。先确认信号本身是否正常，再看带外模板，再看邻道比值，最后扫远端杂散。

| 现象 | 可能原因 | 下一步 |
|---|---|---|
| OBW 展宽 + SEM/ACLR 差 | 信号失真、配置错、PA 压缩 | 查带宽/调制/时钟/PA |
| OBW 正常 + SEM/ACLR 差 | 带外泄漏、滤波、PA 线性度 | 看频谱形状与功率依赖 |
| SEM 差、ACLR 正常 | 绝对限值/参考电平/测量带宽 | 查该段设置与环境 |
| ACLR 差、SEM 正常 | 邻道比值/测量滤波器/平均 | 查 ACLR 设置与功率点 |
| 杂散单点凸起 | 时钟/谐波/混频/外部干扰 | 断开 DUT、换频对比 |
| 杂散宽带抬高 | PA 噪声/校准/参考电平 | 查校准与仪表设置 |

这张表给的是假设顺序，不是判据；最终仍要回到原始频谱、配置快照和校准记录。

## 8. 失败归因速查

| 现象 | 优先检查 |
|---|---|
| 全频段整体抬高 | 参考电平、衰减、路径损耗、校准 |
| 单点凸起且不随 DUT 频率移动 | 外部干扰、仪表本振/时钟 |
| 单点凸起随 DUT 信道搬移 | DUT 谐波/混频/时钟 |
| 只有最大功率点差 | PA 压缩、DPD、供电 |
| 只有带边信道差 | 滤波器、匹配、插损 |
| 断开 DUT 后仍存在 | 环境/仪表，不是 DUT |
| SEM 与 ACLR 结论矛盾 | 测量带宽/滤波器/参考电平设置不同，分别复核 |

通用四步法（换样机 → 换通道 → 看原始数据 → 查基准）见 [测量基础与校准](<01 测量基础与校准.md>) §6。
