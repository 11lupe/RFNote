# A 类深挖：射频测量原理与指标（可执行学习清单）

本文覆盖 A 类指标（A1–A7）的深挖清单。
阅读方式：每个指标按「概念 → 测试条件 → 实测流程 → 失败归因 → 追问链」展开。

> 数字说明：本文出现的限值均为**量级参考**，用于建立直觉，不作为判定依据。实际判定以 3GPP 原文表格 + 客户/平台配置为准（很多厂会在规范基础上放宽或收紧）。回答时正确说法是"以规范表为准，我们平台配的是 X"，而不是背一个数字。

## 1. 总表：先建立全局坐标

| 指标 | 测什么 | 最关键的一个测试条件 | 失败头号原因（经验排序） | 常见程度 |
|---|---|---|---|---|
| A1.1 最大功率 | 上限能力 | RB 配置 + MPR 条件 | 线损/校准漂移；样机没进满功率态 | ★★★★★ |
| A1.2 最小功率 | 下限泄漏 | 功率控制命令压到最低 | 样机关不干净；窗口截错 | ★★★ |
| A1.3 关闭功率 | 关断期泄漏 | 测量窗口要避开开关瞬态 | 时序没对齐，窗口截到瞬态 | ★★★★ |
| A1.4 功率控制 | 步进精度 | TPC 命令序列与累积规则 | 命令没真正下发；状态机没同步 | ★★ |
| A2.1 SEM | 带外模板 | 偏移点 + 测量带宽 + RBW | 参考电平/RBW 设错；环境干扰 | ★★★★ |
| A2.2 ACLR | 邻道泄漏 | 信道带宽 + 邻道偏移 | 仪表滤波/平均设置；DUT 功放压缩 | ★★★★ |
| A2.3 杂散 | 宽带杂散 | 扫描范围与检波方式 | 把环境干扰当成 DUT 杂散 | ★★★ |
| A2.4 OBW | 占用带宽 | 99% 功率积分方式 | 一般不易失败，多用于辅助判断 | ★★ |
| A3 EVM / 频偏 | 调制质量 | 解调参考信号与均衡 | 相位噪声、PA 压缩、IQ 不平衡 | ★★★ |
| A5 重复性/不确定度 | 数据可信度 | 平均次数与稳定等待 | 没等稳定就读；接头重复性差 | ★★★★★（隐形考点） |
| A6 路径损耗校准 | 测量基准 | 校准平面与频点 | 校一次用一年；换线不重校 | ★★★★★ |

## 2. 逐指标深挖

### A1.1 最大输出功率（MOP）

**概念**：UE 在指定信道、带宽、RB 配置下能发出的最大功率。判定是一个**区间**（名义值 + 容差），不是"越大越好"。功率等级（Power Class）决定名义值，手机常见 PC3，名义 23 dBm 量级。

**测试条件为什么这么定**（这段是拉开差距的地方）：
- **信道位置**（低/中/高）——不同频点的前端插损与滤波器响应不同，边缘信道最容易掉功率。
- **RB 数与位置**——满 RB 与部分 RB（partial RB）的功率谱密度不同；部分 RB 会触发 MPR，**规范允许你在这些配置下降功率**。所以"partial RB 下测得低"未必是缺陷。
- **调制方式**——高阶调制（64QAM/256QAM）对线性度要求更高，MPR 更大。
- **MPR / A-MPR**——这是最容易被追问的点：**为什么不达标却判 PASS？因为规范允许在该配置下回退**。答不出 MPR，就等于没做过功率测试。

**实测流程（非信令）**：
1. 仪表选制式与应用，设信道/带宽，参考电平按预期功率 + 余量设（太高会压缩前端，太低会削顶）。
2. 样机经 ADB/AT 进入测试模式，指定 band、信道、带宽、RB 配置、功率控制为最大。
3. **等稳定**（settle），再触发测量；不要发完配置立刻读。
4. 用 `*OPC?` 或状态位确认测量完成，取 burst 平均功率（不是瞬时峰值）。
5. 判定：名义值 ± 容差，且结合该配置的 MPR 判断是否合法。
6. 存原始读数 + 配置快照（信道/RB/调制/参考电平/校准值），否则失败无法复现。

**失败归因树（按顺序查，命中即停）**：
- 同一位置换 golden sample 也低 → **测量系统问题**（线缆/接头/校准/参考电平）
- 只有边缘信道低 → 前端滤波/插损（DUT 特性，属正常范围则放过）
- 只有部分 RB 低 → 先查该配置的 MPR 允许值，再判
- 同一台样机连测波动大 → 稳定等待不足 / 接头松动 / 供电不稳
- 全部偏低一个固定值（如 1.5 dB）→ **校准值过期或换线未重校**（最高频的坑）

**追问链**：
1. 你怎么测最大功率？→ 2. 为什么要在 partial RB 下测？→ 3. MPR 是什么、为什么允许降功率？→ 4. 读数偏低 0.5 dB 你怎么查？→ 5. 怎么证明不是脚本的问题？→ 6. 客户限值比 3GPP 更严，你怎么处理？

### A1.2 最小输出功率

**概念**：把功率压到最低时，UE 是否还能"干净地低"，量级在 -40 dBm 以下。

**关键条件**：功率控制命令要真的下发到最低档；确认样机确实进入最低功率态（很多失败是"以为压下去了，其实没有"）。

**失败归因**：样机没进最低态（状态残留）> 窗口/平均设置 > DUT 真实漏泄。

**追问**：为什么要测这个？—— 因为发射机在低功率时的泄漏与杂散特性，直接影响相邻信道与共存。

---

### A1.3 关闭功率（Transmit OFF Power）

**概念**：UE 不该发射的时段（关断期），残余功率必须足够低。考的是**开断瞬态与漏泄**。

**最容易踩的坑**：**测量窗口要避开开关瞬态**。规范给了瞬态过渡期豁免，如果脚本把窗口放在瞬态上，读到的是开关过程的功率，必然超标。所以这题的正确答案里必须出现"窗口位置相对 burst 边界的偏移量"。

**失败归因**：
- 窗口截到瞬态 → 调窗口偏移（最常见）
- 样机关断不彻底（状态残留、没退出测试模式）
- 触发源不对，测的是上一轮的尾巴
- 真的是 DUT 漏泄（换 golden sample 交叉验证）

**追问**：关闭功率测的是哪段时间？为什么这段时间重要？窗口怎么定的、偏移多少、为什么是这个值？

---

### A1.4 功率控制（TPC）

**概念**：按命令调整功率，考察步进精度与累积/绝对两种模式是否按规范执行。

**关键**：命令序列的真实下发与状态机同步——仪表的 TPC 命令、样机的响应、脚本的等待必须三者对齐。

**追问**：累积模式和绝对模式的区别？测这个能发现什么问题？（→ 发现功控环路的偏差，影响网络侧调度与邻区干扰）

---

### A2.1 SEM（频谱发射模板）

**概念**：在载波两侧若干偏移区间内，功率不得超过模板值。它给的是**绝对上限**（相对载波或绝对 dBm，看规范条目）。

**关键条件**：
- **偏移点与测量带宽**：每个偏移区间有自己的测量带宽与 RBW，用错带宽结果直接不可比。
- **参考电平/衰减**：设太高看不到真实值，设太低仪表自身压缩。
- **RBW/VBW 与检波器**：宽带噪声类测量用 RMS 平均更稳。

**失败归因**：
- 环境干扰（邻工位、WiFi、基站信号）→ 屏蔽/换频点复测
- 参考电平或 RBW 设错
- 校准漂移导致整体抬高
- 真失效：功放非线性、滤波不足

**追问**：SEM 和 ACLR 的区别？（→ 一个是绝对模板，一个是邻道比值；SEM 管"绝对不许超"，ACLR 管"相对干净程度"）SEM 不过你怎么判断是 DUT 还是环境？

---

### A2.2 ACLR / ACPR

**概念**：主信道功率 ÷ 相邻信道功率（指定偏移与带宽，通常用 RRC 滤波参考）。

**关键**：邻道偏移、信道带宽、平均方式、是否用 RRC 参考滤波——四个设置里错一个，数字就不可比。

**失败归因**：功放压缩（功率越大 ACLR 越差，这是物理规律，可作为加分点）> 仪表设置 > 校准/线损。

**加分说法**："ACLR 随输出功率升高而恶化，所以在最大功率点测 ACLR 才有意义；如果最大功率点和回退点的 ACLR 差不多，反而说明测错了。"

---

### A2.3 杂散发射（Spurious）

**概念**：远离载波的宽带杂散，绝对限值，扫描范围可到 GHz 级。

**最容易犯的错**：**把环境干扰当成 DUT 杂散**。正确做法：断开 DUT 复测一次（或换屏蔽环境），对比是否存在——这两次对比就是你回答时的"我怎么排除环境"。

**追问**：怎么区分 DUT 杂散和环境信号？（→ 断开 DUT 对比 / 换频点 / 看是否随 DUT 状态变化）

---

### A2.4 OBW（占用带宽）

**概念**：含 99% 积分功率的带宽。一般不易失败，主要作为辅助指标（判断信号是否异常展宽）。

**用途**：当 SEM/ACLR 异常时，OBW 是否正常能快速区分"信号本身坏了"还是"带外泄漏大"。

---

### A3 EVM / 频率误差

**概念**：EVM 衡量调制质量（星座点偏离理想位置的程度）；频率误差是本振偏差（ppm 量级）。

**失败归因**：相位噪声 > PA 非线性（压缩使星座外扩）> IQ 不平衡 > 解调设置（均衡/参考信号选错）。

**追问**：EVM 差说明什么？为什么高阶调制对 EVM 要求更严？（→ 星座点间距变小，同样的绝对误差占比更大）

---

### A5 重复性与测量不确定度（隐形考点，最容易被问倒）

**这是成功率类指标（如 70%→95%）的底座**，必须能拆。

**不确定度来源清单（按贡献排序）**：
1. 接头/线缆的重复性（每次插拔差 0.1–0.3 dB 很常见）
2. 校准有效期与温漂
3. 仪表自身精度与参考电平设置
4. 样机发热导致的功率漂移（连测越久越明显）
5. 稳定等待不足（settle time 不够就读）
6. 平均次数不够（单次读数波动大）

**必须能回答的三问**：
- "成功率"的分母是什么？（用例数？工位数×轮次？）—— 定义不同，数字差一倍。
- 剩下 5% 是什么？—— 要能分成：脚本/通信超时、仪表未响应、样机状态残留、真失效。**分类比数字重要**。
- 同一台机连测三次差 0.3 dB，正常吗？—— 正常范围要先给结论，再给判断方法（多次测量看标准差 vs 规范容差占比）。

---

### A6 路径损耗校准（最高频的实战考点）

**概念**：从 DUT 天线端口到仪表端口的损耗。所有功率判定的基准，校错则全部结论作废。

**怎么做（能讲清这套就是掌握）**：
1. 用**外接功率计/功率探头**直接测 DUT 端口的实际输出（而不是让综测仪自己测自己）。
2. 同一频点、同一线缆路径下，比较"功率计读数"与"综测仪读数"，差值即路径损耗。
3. 每个 band 至少校中心频点，宽带系统要校低/中/高；换线、换夹具、换接头、长期使用后**必须重校**。
4. 校准值落到配置表/平台参数里，并记录校准时间与操作人。

**追问**：为什么用功率计而不是综测仪自己？多久校一次？换了一根线要不要重校？温漂怎么处理？

## 3. 通用测量骨架（写脚本的模板，也是「怎么保证数据可信」的答案）

```
配置仪表（制式/信道/带宽/参考电平/触发）
  → 样机进测试态（ADB/AT：band、信道、RB、功率档、天线）
  → 等待稳定 settle（固定延时 + 状态确认，不要只靠 sleep）
  → 触发测量
  → 同步等待完成（*OPC? / 状态位轮询），禁止盲读
  → 取平均值（次数固定、可配置）
  → 判定（规范限值 × 客户放宽系数 × 该配置的 MPR）
  → 存原始数据 + 配置快照 + 校准值 + 时间戳
  → 复位样机与仪表（失败也要复位，否则污染下一条用例）
```

**这套骨架的每一行都能被追问**：
- settle 为什么是固定延时？能不能用状态位代替？（能，但要看仪表支持）
- 平均次数为什么是 N？改大改小分别影响什么？
- 失败也要复位——不复位会怎样？（状态残留污染后续用例，这就是"成功率虚低"的常见来源）

## 4. 失败归因四步法（把这段背下来，任何指标都能套）

1. **换样机**：同位置换 golden sample。仍然失败 → 测量系统；通过 → DUT 问题。
2. **换通道**：换线缆/接头/工位。变化 → 硬件链路；不变 → 脚本/仪表设置。
3. **看原始数据**：窗口位置、波形、平均次数、参考电平是否合理。数据本身不合理 → 测量配置错。
4. **查基准**：校准是否在有效期、校准平面是否对、是否换过线。

**结论必须落到"可执行动作"**：不是"我觉得是线缆问题"，而是"换线后复测，偏差从 1.2 dB 降到 0.1 dB，确认是接头磨损"。

## 5. 落地前必须确认的 10 件事（平台/公司配置，不是规范）

1. 我们的参考电平是怎么设的？有没有统一的余量规则？
2. 平均次数配多少？为什么是这个数？
3. 判定用的是 3GPP 原限值，还是客户放宽/收紧后的值？放宽系数多少？
4. 路径损耗多久校准一次？校准数据存在哪？谁负责？
5. 样机进测试态用的是 AT 还是 ADB？有没有封装好的库？
6. 失败重试几次？重试后仍失败怎么标记？谁来判"真失效"？
7. 原始数据（波形/读数）保存多久？失败现场会不会自动截图/存日志？
8. 一个测试项从需求到上线，谁给需求、谁验收？
9. 现在的平台上，仪表驱动是自己写的还是买的？抽象层在哪？
10. 产线节拍要求是多少秒一站？我们现在实际多少？

> 这 10 个问题问完，对系统的理解就从「会用」变成「知道边界在哪」。
