# 调制质量类指标

> 覆盖：频率误差、EVM、载波泄漏、IQ 不平衡。
> 共同点：不再只看功率大小，而看「信号本身是否失真、本振是否偏」；是高阶调制（64QAM/256QAM）能否成立的前提。
> 测量链、同步、参考电平与通用归因见 [测量基础与校准](<01 测量基础与校准.md>)。

## 1. 这一类指标的坐标

| 指标 | 测什么 | 单位 | 主要来源 | LTE（方法 / 限值） | NR（方法 / 限值） |
|---|---|---|---|---|---|
| 频率误差 | 实际载波与分配频率的偏差 | ppm / Hz | 参考时钟、本振、温漂 | 36.521-1 6.5.1 / 36.101 6.5.1 | 38.521-1 6.4.1 / 38.101-1 6.4.1 |
| EVM | 星座点误差矢量的均方根 | % / dB | 相位噪声、PA 压缩、IQ 不平衡、解调设置 | 36.521-1 6.5.2.1 / 36.101 6.5.2.1 | 38.521-1 6.4.2.1 / 38.101-1 6.4.2.1 |
| 载波泄漏 | 本振泄漏/直流分量在中心的功率 | dBc | LO 泄漏、DC 偏置、调制器偏置 | 常通过 EVM/频谱评估 | 同左 |
| IQ 不平衡 | I/Q 增益与相位失配 | dB / % | 调制器、本振相位、校准 | 常通过 EVM/镜像评估 | 同左 |

3GPP 把频率误差、EVM 等放在「Transmitter modulation quality」下（LTE 6.5、NR 6.4）；载波泄漏与 IQ 不平衡在多数发射测试中不是独立的通用判决项，常作为 EVM、频谱或星座的损伤机制出现。是否有独立限值，要看具体制式、band 与测试方法，不能一概而论。

## 2. 频率误差

定义：实际发射载波频率与分配频率的偏差，常用 ppm 表示：

```
频率误差(ppm) = (f_实际 − f_分配) / f_分配 × 10^6
```

来源：

- 参考时钟（TCXO/OCXO/晶振）的初始精度、温漂、老化；
- 本振合成/锁相环的稳态误差；
- 校准表与温度补偿；
- 小区搜索/同步后的频率跟踪（终端侧）。

测量：解调 burst，估计载波频偏，在有效符号上平均；确认解调锁定了正确的小区/信号，参考信号与测量带宽按测试方法。频率误差太大时，星座会旋转，EVM 也会被拖差，所以通常先看频偏，再看 EVM。

失败判断：

- **固定偏移**：参考时钟校准、初始频偏、校准表；
- **随温度漂移**：TCXO 温补、晶振负载、发热；
- **随机抖动**：相位噪声、锁相环带宽、供电；
- **只在某些 band/信道差**：本振合成、band 校准表。

常见量级：蜂窝终端常见 0.1 ppm 量级；不同制式、band、基站/终端类型不同，以 36.101 / 38.101-1 对应表为准。不要拿一个 ppm 数套所有场景。

影响：频偏在 OFDM 中产生子载波间干扰（ICI），在单载波中表现为星座旋转；它既自己是一项指标，也会通过 EVM 表现出来。

## 3. EVM

定义：误差矢量幅度，衡量实测星座点与理想参考点的偏差：

```
EVM(%) = sqrt( mean(|误差矢量|²) / mean(|参考矢量|²) ) × 100%
EVM(dB) = 20 × log10(EVM(%) / 100)
```

换算示例：10% → −20 dB；3.5% → 约 −29.1 dB；1% → −40 dB。

门限量级（仅示意，按制式/band/带宽的表为准）：

| 调制 | EVM 限值（量级） | 典型场景 |
|---|---|---|
| QPSK | 17.5% | 低阶、鲁棒 |
| 16QAM | 12.5% | 中阶 |
| 64QAM | 8% | 高阶 |
| 256QAM | 3.5% | 最高阶，最苛刻 |

来源排序（从大到小，工程经验）：

1. **相位噪声**：本振/锁相环，高阶调制最敏感；
2. **PA 非线性/压缩**：功率越大越明显，常与 ACLR 同源；
3. **IQ 不平衡/载波泄漏**：镜像、中心谱线、星座偏移；
4. **解调/测量设置**：均衡器、信道估计、参考信号、符号定时、平均次数。

测量设置必须固定并与测试方法一致：

- 参考信号/星座图、测量带宽、RB 分配；
- 均衡器与信道估计方式（不同设置下 EVM 不可比）；
- 符号定时与频率同步；
- 平均次数与统计口径（RMS）。

EVM 与功率的关系：低功率时相位噪声/IQ/DC 占主导，高功率时 PA 压缩/非线性占主导，中间常有一个「甜点」。所以：

- 只在最大功率测 EVM，可能把压缩当成全部原因；
- 只看一个功率点，无法区分相位噪声与压缩；
- 测试矩阵至少覆盖最大功率与一个回退点，看趋势。

EVM 与 ACLR 的关系：两者都受 PA 非线性影响，但 EVM 看带内星座误差，ACLR 看邻道频谱再生；同源不等于可以互相替代。DPD 通常同时改善两者，但优化目标与代价不同，不能只用 ACLR 推断 EVM。

失败排序：

1. 功率回退后 EVM 明显改善 → PA 压缩/非线性；
2. 低功率也差 → 相位噪声、IQ、载波泄漏；
3. 只有高阶调制差 → 相位噪声/线性度/均衡；
4. 星座整体旋转 → 频率误差/相位跟踪；
5. 只有某些 RB 差 → 信道估计/均衡/参考信号配置。

条款：LTE 36.521-1 6.5.2.1 / 36.101 6.5.2.1；NR 38.521-1 6.4.2.1 / 38.101-1 6.4.2.1。

## 4. 载波泄漏与 IQ 不平衡

这两个通常不是独立的通用判决项，而是解释 EVM/频谱异常的损伤机制。

**载波泄漏（Carrier Leakage / LO Leakage）**

- 现象：频谱中心出现凸起（DC/本振频点），星座整体偏移；
- 来源：本振泄漏到发射路径、IQ 调制器 DC 偏置、DAC 偏置；
- 诊断：看中心谱线与 EVM 星座的公共偏移；调整 IQ offset/DC 校准后复测；
- 影响：低 RB/中心 RB 配置更明显；也可能落到邻道，影响 SEM/ACLR。

**IQ 不平衡（IQ Imbalance）**

- 现象：频谱出现镜像/不对称，EVM 变差，高阶调制更敏感；
- 来源：I/Q 两路增益不一致、本振 90° 相位误差、混频器/滤波器失配；
- 诊断：看镜像抑制与星座的椭圆化；做 IQ 增益/相位校准后复测；
- 影响：镜像可能落在带内或邻道，既拖 EVM 也可能拖 ACLR。

排查顺序：先看频率误差（星座旋转会伪装成 EVM），再看中心谱线（载波泄漏），再看镜像/不对称（IQ 不平衡），最后才归因到相位噪声或 PA。顺序反了，容易把校准问题当成器件问题。

## 5. 失败归因速查

| 现象 | 优先检查 |
|---|---|
| 频率误差固定偏 | 参考时钟、初始校准、校准表 |
| 频率误差随温度漂移 | TCXO 温补、晶振、发热 |
| EVM 随功率升高变差 | PA 压缩、DPD、供电 |
| 低功率 EVM 也差 | 相位噪声、IQ 不平衡、载波泄漏 |
| 只有高阶调制 EVM 差 | 相位噪声、线性度、均衡/信道估计 |
| 星座整体旋转 | 频率误差、相位跟踪 |
| 频谱中心凸起 | 载波泄漏、DC 偏置 |
| 频谱出现镜像/不对称 | IQ 增益/相位不平衡 |
| 只有部分 RB 差 | 信道估计、参考信号、RB 配置 |
| 同一台重复性差 | 同步/触发、平均、温度、连接 |

通用四步法（换样机 → 换通道 → 看原始数据 → 查基准）见 [测量基础与校准](<01 测量基础与校准.md>) §6；EVM 的原始数据至少保留星座图、频谱、频偏估计与解调设置。
