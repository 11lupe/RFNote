# 功率类指标

> 覆盖：最大输出功率（MOP）、MPR/A-MPR、最小输出功率、关闭功率（TX OFF）、功率控制（TPC）。
> 共同点：回答「发射功率在指定时刻、指定配置下应该是多少」；判定多为区间或上限。
> 测量链、参考电平、同步、校准与通用归因见 [测量基础与校准](<01 测量基础与校准.md>)；本文只写功率类特有的条件与判据。

## 2. 最大输出功率（MOP）

### 2.1 定义与判决

定义：在指定配置（band、信道、带宽、RB、调制、功率档、天线）下，DUT 能输出的最大**平均**功率。测的是 ON 期的平均功率，不是峰值、不是整帧平均、也不是最后一次读数。

判决式：

```
上限 = 名义功率 + 容差 − MPR − A-MPR
下限 = 名义功率 − 容差
PASS ⇔ 下限 ≤ 实测 ON 期平均功率 ≤ 上限
```

两个容易写错的地方：

- MPR/A-MPR 只**压低上限**，不影响下限。回退是允许「少发」，不是允许「多发」。
- 下限仍然按名义功率减容差算。不能因为加了 MPR，就把下限也往下挪。

功率等级（量级参考）：

| 等级 | 名义功率（量级） | 常见场景 |
|---|---|---|
| PC3 | 23 dBm | 多数 FR1 手机 |
| PC2 | 26 dBm | n41/n77/n78/n79 等 |
| PC1.5 | 29 dBm | 特定 band/场景 |

容差：FR1 PC3 常见 ±2 dB，LTE 常见 ±2 dB；不同 band、功率等级、带宽的容差可能不同，以 36.101 / 38.101-1 对应表为准。上表数字只作量级参考。

测量对象再强调一次：**ON 期平均**。用 burst 内去掉上升/下降沿的窗口，平均次数固定；用峰值会把 PAPR 算进去，用整帧平均会把 OFF 期拉低，都会改变结论。

### 2.2 测试条件矩阵

| 维度 | 取值 | 为什么 |
|---|---|---|
| 信道 | 低 / 中 / 高 | 前端滤波、匹配、插损随频率变 |
| 带宽 | 最宽 + 最窄 | 最宽考验 PA/DPD 与功率集中度，最窄考验配置切换 |
| RB | 1RB 最低 / 1RB 最高 / 满 RB | 局部功率密度与 MPR 触发不同 |
| 调制 | 最低阶 + 最高阶 | PAPR、EVM、ACLR 约束不同 |
| 天线 | 每根 Tx | 每根通道的链路、校准、隔离独立 |
| 功率控制 | 最大档 | 其他档测不出最大能力 |

这六个维度做笛卡尔积会迅速膨胀。工程上用等价类裁剪：同 band 的中信道作参考；窄带宽只测 1RB 最低/最高；平台已知最坏 case 可以优先，但要在用例里写清裁剪理由，不能静默少测。

例如 15 个 band × 3 信道 × 2 带宽 × 3 RB × 2 调制 × 4 天线，已经是上千个 case；脚本应自动生成并给每个 case 打标签（band/信道/带宽/RB/调制/天线/MPR），而不是手工枚举。

### 2.3 MPR 与 A-MPR

机制：高阶调制 → PAPR 大 → PA 更容易压缩 → 为了同时满足 ACLR/EVM，允许把最大功率回退一点。MPR 就是这份「合法回退」。

| 调制 | MPR（量级） | 原因（PAPR） |
|---|---|---|
| π/2 BPSK | 0 dB | 低 PAPR |
| QPSK | 0 dB | 低 PAPR |
| 16QAM | 1 dB | 中 PAPR |
| 64QAM | 2 dB | 较高 PAPR |
| 256QAM | 2–3 dB | 高 PAPR |

这张表只给量级。精确值取决于 3GPP 表、band、RB、网络配置；代码不能把某个数字写死，要带「表版本 + band + 调制 + RB」一起读。

MPR 与 A-MPR 的区别：

- **MPR**：看调制、RB 等发射配置，是通用回退。
- **A-MPR**：看 band 与部署/网络配置（例如 LTE/NR 的 NS_xx），是额外回退。
- 两者都从上限里减；不要重复减，也不要漏掉 A-MPR。表里的 `NS_xx` 必须和网络配置/平台配置对得上。

判决伪代码：

```python
def judge_mop(meas, nominal, tol, mpr, ampr):
    upper = nominal + tol - mpr - ampr
    lower = nominal - tol
    return lower <= meas <= upper, (lower, upper)
```

反例：`abs(meas - nominal) <= tol`。这把 MPR 当成了对称容差，合法的功率回退会被判 FAIL；也会漏掉「上限被 MPR 压低」的情况。

算例：64QAM、部分 RB、MPR=2 dB、A-MPR=0、名义功率 23 dBm、容差 2 dB：

```
上限 = 23 + 2 − 2 − 0 = 23 dBm
下限 = 23 − 2 = 21 dBm
判定区间 = [21, 23] dBm
实测 21.5 dBm → PASS
实测 22.5 dBm → PASS
实测 20.8 dBm → FAIL（低于下限）
实测 23.2 dBm → FAIL（高于上限）
```

「测得低」不一定是缺陷：在 `[下限, 上限]` 内、且有合法 MPR 时，低是允许的。低于下限才要查功率控制、校准、PA。

### 2.4 非信令实测流程

1. 仪表：选制式/band/信道/带宽；参考电平按预期最大功率加余量；触发对齐 burst。
2. DUT：通过 ADB/AT 进测试模式，设置 band、信道、带宽、RB、调制、最大功率档、天线；读回确认状态。
3. 等稳定：固定 settle + 状态确认；`INIT` 后用 `*OPC?` 等测量完成。
4. 取 ON 期平均功率；按该 case 的 MPR/A-MPR 算区间并判定。
5. 存原始值、配置快照、MPR 表版本；失败也复位 DUT 与仪表。

同步细节见 [测量基础与校准](<01 测量基础与校准.md>) §3，这里不重复代码。最容易被忽略的是第 2 步的**读回确认**：DUT 没接受 RB/功率档设置时，后面测到的数再漂亮也不是目标 case。

### 2.5 关键参数与来源

| 参数 | 物理量 | 典型设置（示意） | 来源 | 改大的后果 | 改小的后果 |
|---|---|---|---|---|---|
| 参考电平 | 仪表期望输入功率 | 预期最大功率 + 5–10 dB | 平台模板/仪表手册 | 噪声底抬高，小信号差 | 前端压缩，大信号差 |
| 输入衰减 | 防过载 | 自动或按参考电平 | 仪表 | 噪声底抬高 | 过载/削顶 |
| 触发源 | 对齐 burst | 外部触发或 IF 功率触发 | 测试方法/平台 | 触发晚，漏掉前沿 | 触发早，测到瞬态 |
| 测量窗口 | 只覆盖 ON 期 | 去掉前/后沿（如 20 µs，示意） | 测试方法/平台 | 含瞬态，功率偏高/波动 | 样本不足，波动大 |
| 平均次数 | 抑制随机误差 | 10 次（示意） | 平台 | 节拍慢 | 波动大、偶发 FAIL |
| Settle | 等 DUT 稳定 | 300 ms（示意） | 平台/实验 | 节拍慢 | 读数未稳定 |
| 路径损耗 | DUT 口 ↔ 仪表口 | 实测，按 band/信道 | 校准 | 判定整体偏移 | 同上 |
| MPR/A-MPR 表 | 允许回退 | 按规范版本/band | 3GPP 表 | 判据错 | 判据错 |

表中的数值是示例，不是通用推荐；真正要固定的是「来源」和「记录」。参考电平的坑见 [测量基础与校准](<01 测量基础与校准.md>) §2：高了伤小信号，低了伤大信号。

### 2.6 失败归因

按顺序排：

1. 同位置换 golden sample 也低 → 测量系统：线损、参考电平、衰减、校准。
2. 只有带边信道低 → 前端滤波/匹配/插损，不是 MPR。
3. 只有部分 RB 低 → 查 MPR/A-MPR 表、RB 配置、功率档是否真的最大。
4. 同一台重复性差 → 接头、线缆、settle、供电/发热。
5. 固定偏移 → 路径损耗、校准、接头磨损。
6. 高频段更差 → 线缆损耗随频率、连接器、匹配。

证据标准见 [测量基础与校准](<01 测量基础与校准.md>) §6：更换前后的数值 + 可复现步骤 + 排除项，才算归因。

## 3. 最小输出功率

定义：DUT 在最低功率控制档的输出功率；判定为**上限**，即「能压到多低」。

它和关闭功率的区别：最小功率是「开着，但尽量小」；关闭功率是「关断期的残余」。两者测的不是同一段时间。

条件与步骤：

- TPC 命令拉到最低档，读回确认 DUT 真的在最低档；
- 测量带宽、窗口、平均次数按测试方法固定；
- 参考电平不能沿用 MOP 的高设置，否则噪声底把小信号淹掉。

失败排序：

1. 没到最低档（命令没生效/状态残留）→ 读数偏高，假失败。
2. 窗口、平均、参考电平不对 → 噪声底或瞬态污染。
3. 真残余高：PA/射频开关隔离不足、低端校准表错、本振/时钟泄漏。

「最小功率越低越好」也不对：远低于预期可能说明链路断了或校准严重偏移，先确认读数合理，再谈 PASS。

条款：LTE 36.521-1 6.3.2 / 36.101 6.3.2；NR 38.521-1 6.3.1 / 38.101-1 6.3.1。

## 4. 关闭功率（TX OFF）

定义：发射关断期内的残余输出功率；判定为上限。关键是**窗口要避开开关瞬态**。

```
功率
 │   ┌────┐                  ┌────┐
 │   │ ON │                  │ ON │
 │───┘    └──────────────────┘    └──→ 时间
 │            ↑
 │      关断测量窗口（避开前后沿）
```

窗口偏移（offset）是核心参数：太靠前会压到下降沿，太靠后会碰到下一个上升沿，都会把瞬态功率当成残余，造成假 FAIL。

失败排序：

1. 窗口压在瞬态上（最常见）→ 用零 span/时域看波形，调整 offset。
2. DUT 没真正关断或状态残留 → 查 TX 使能、开关、命令。
3. 触发错位（上一 burst 尾巴/下一 burst 前沿）→ 看触发标记与实际窗口。
4. 真泄漏 → golden sample 对比；断开 DUT，确认不是环境干扰。

测量要点：门控触发 + 固定 offset + 平均；先用时域确认窗口位置，再看功率值。只盯最终数字，很容易把触发问题当成 DUT 问题。

条款：LTE 36.521-1 6.3.3 / 36.101 6.3.3；NR 38.521-1 6.3.2 / 38.101-1 6.3.2。ON/OFF 时间模板：LTE 6.3.4；NR 38.521-1 6.3.3。

## 5. 功率控制（TPC）

功率控制验的是「命令 → 响应 → 测量」三者是否对齐，不是单点功率。

两种基本模式：

- **绝对（absolute）**：每条命令给绝对目标功率，误差不累积。
- **累积（accumulated）**：每条命令给相对步长，误差会沿序列累积。

测试方法：发一串 TPC 命令，每一步在 DUT 响应并稳定后测功率，和期望目标比较；步长、容差、等待时间按测试方法。

三者对齐：

1. 仪表/脚本发出的命令序列；
2. DUT 实际响应（读回/状态；命令丢失或状态机没跟上）；
3. 测量窗口与等待时间（必须在响应之后测，不能测到过渡过程）。

任何一处错位，都会表现为「步进不准」，但根因不在 PA。

失败排序：

- 校准表错 → 固定步长偏差或压缩；
- 温补失效 → 随温度漂移；
- 状态机/命令丢失 → 随机跳变；
- 窗口在过渡期 → 读到中间值。

条款：LTE 36.521-1 6.3.5 / 36.101 6.3.5；NR 38.521-1 6.3.4 / 38.101-1 6.3.4；WCDMA 34.121-1 5.4（开环 5.4.1、闭环 5.4.2、最小功率 5.4.3）。

## 6. 判定分层与限值

判定分三层，缺一层就不可追溯：

1. **规范限值**：测试方法在 `.521`，限值在 `.101`；引用时写规范号 + 节号。
2. **平台/客户配置**：可能在规范上放宽或收紧，也可能加 guard band；配置要有版本和生效范围。
3. **本次判定**：判定函数的输入（nominal、tol、MPR、A-MPR）全部来自可追溯的表；输出 PASS/FAIL/灰区。

工程口径：以规范表为准，平台配置写明「放宽/收紧多少、依据是什么」，客户要求单独记录。不要用「我记得是 23 dBm」当判据。

不确定度：`|实测 − 限值|` 小于测量不确定度时，标灰区并复测/换系统，不要直接 PASS。方法见 [测量基础与校准](<01 测量基础与校准.md>) §5。

## 7. 失败归因速查

| 现象 | 优先检查 | 涉及指标 |
|---|---|---|
| 整批偏低/偏高一个固定值 | 路径损耗、校准、接头 | MOP、ACLR、SEM |
| 只有带边信道低 | 前端滤波、插损、匹配 | MOP |
| 只有部分 RB 低 | MPR/A-MPR、RB 配置、功率档 | MOP |
| 最小功率/关闭功率异常 | 参考电平过高、窗口/触发 | 最小功率、TX OFF |
| 功控步进错或跳变 | 命令序列、状态机、校准表、窗口 | TPC |
| 高频段更差 | 线缆/接头/匹配 | 全部功率类 |

通用四步法（换样机 → 换通道 → 看原始数据 → 查基准）见 [测量基础与校准](<01 测量基础与校准.md>) §6。
